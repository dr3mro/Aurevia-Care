## Lessons for workers

Collected once per distinct rule; the repeated occurrences in the source notes are merged.

- One clean verification pass is enough. If local gates are green but CI is blocked by a label, PR size or environment artifact, record the single exact trusted next step and stop — another notes-only pass cannot publish a task or change a label.
- Classify a stuck PR before changing code: (1) real in-scope defect — fix it; (2) pre-existing red on `main` — owner fixes it; (3) PR-mechanics blocker such as `needs-fix`/`needs-human` — maintainer clears it. Most of this day's loops were class (3).
- When a story is re-dispatched, survey `main` and all prior notes first: keep the feature and acceptance tests that already landed, contribute only the missing slice, and drop duplicate tests at conflict resolution.
- In cloud workers `opencode.json` is the CI profile under `skip-worktree`: confirm with `git ls-files -v opencode.json` (`S`) and use `git show HEAD:opencode.json` for HEAD truth. Never regenerate or commit it.
- Do not run `scripts/check.sh`, `apps/api/check.sh` (full `mvn verify`), `scripts/coverage-check.sh` or `scripts/docs.sh` as a worker. Run targeted `-Dtest=...` suites plus standalone JaCoCo, SpotBugs and the policy scripts; the integrator/Delivery own the full gate.
- Reset `apps/api/target/jacoco.exec` before a coverage batch, include every test class touching the changed code, and re-derive 100% numbers from `jacoco.xml` instead of trusting an older note.
- Install locked dependencies in all three frontend modules and the root before root `npm run typecheck`, and never run two frontend gates in parallel — each performs its own `npm ci`. Omit optional keys with rest destructuring or `?? null` under `exactOptionalPropertyTypes`, and always paste the `tsc --noEmit` final lines.
- A 100%-covered page does not prove the installed shell supplies its inputs; trace from `App`/`RootNavigator` through the shell in an installed-component test.
- For React 19 press flows use `await fireEvent.press(...)` then `await waitFor(...)`; compute mount-time `useState` values as plain `const` after early returns (a `useMemo` after `if (signedOut)` is a conditional hook); remount with `key={reloadCount}` rather than a lint-rejected `useCallback` dependency; test unreachable guards by mocking the presentational boundary and invoking its callback twice in one `act`.
- jsdom cannot measure pixels: assert classes, attributes and structure, and leave painted size/reflow/zoom to the Playwright `RESP-E2E-*` tasks. Reuse one `matchMedia` state object per query string; in Vitest use `dirname(fileURLToPath(import.meta.url))` instead of `new URL(...)` with `import.meta.url`.
- A new public route must be declared where the parity test can see it, and drift/parity gates must be re-run against a fresh merge after a contract change on `main`; a byte-identical copy from a previous pass is not evidence for this pass.
- Check `git show HEAD:<path>` before treating `git grep` conflict markers as merge fallout; check the PR file count before adding yet another notes file.
- In Python tooling work, bootstrap `pip` from the bundled wheel, set `COVERAGE_FILE` to a temporary path (or restore `.coverage`), and filter `coverage json` to your line range rather than trusting a shared script percentage.
