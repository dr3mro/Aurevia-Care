## Lessons for workers

- Before citing a requirement ID in a new Markdown page, check it against `check-docs.py`'s `spec_ids` definition, not just the raw specification text: IDs written as `- **PAT-02** ...` are not in the defined set, and a literal mention turns the docs gate red.
- A red repo-wide docs check is not automatically a defect of your page: filter the output for your file first, record the exit code and total count verbatim, and never repair out-of-scope files just to turn it green.
- For a large package, inventory controllers, `ActionPolicy` classes, `CREATE TABLE` lines in migrations and `@Test` counts before drafting; the entry-point/role and table tables then write themselves with accurate citations.
