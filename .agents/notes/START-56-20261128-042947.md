## Lessons for workers

- A replay response can differ in the per-request correlation id even when the domain returns the same
  committed fact; assert stable fact fields and store counts, not full-body equality.
- Seed the peer-tenant caller's active membership and role before asserting a tenant-scoped 404, or the
  role guard returns 403 earlier and masks the concealment branch.
- `InMemoryServiceProfileStore.latestVersion` takes the max over all statuses; use separate stores per
  leg when asserting an exact version.
- Cloud workers may hit HTTP 429 from Maven Central; a scratch settings file under `/tmp` with a
  mirror avoids changing the repository, and the pinned dependency version stays intact.
- Fill `Test evidence`, `Coverage` and `Review verdicts` before requesting post-code reviews; reviewers
  read the notes when they run and an empty section produces a NO-GO about stale notes.
