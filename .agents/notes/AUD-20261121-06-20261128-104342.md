## Findings

- **Spec/traceability mismatch (tool):** task `tasks/00027000-AUD-20261121-06.md` declares PAT-02, but `PROJECT_V1_SPEC.md` PAT-02 is released-report download authorization and patient appointments are PAT-01. The worker must not edit `tasks/`; orchestrator correction is requested. Both IDs are reported in this note as declared.
- **Inert push boundary (reviewer + plan):** no APNs/FCM provider exists in this scope. The production `PushGateway` bean is a documented local-only boundary carrying the generic, clinical-detail-free notice; it records `..._SENT` audit facts without an external delivery. Debt: audit semantics do not prove delivery until a real provider adapter lands. No PHI or token value is logged.
- **Wiring baseline entries resolved (tool, to be recorded, not edited):** `controller-builds` on `PatientAppointmentController.java` and `store-without-durable` on `DeviceTokenStore.java` / `PatientAppointmentStore.java` become stale after this change. `scripts/wiring-baseline.json` is protected and out of scope; the trusted integrator regenerates it.
- **Out-of-scope caller (tool):** `UseGenericPushNotificationsRetrieveFullContentTest.java:97` constructs `new PatientAppointmentController(clock)`. It is kept compiling through the documented fail-closed compatibility constructor; no reflection seam or in-memory fallback in `src/main`.
- **No durable appointment verified-link table (tool):** V103 adds appointment/device projections only; the verified link is re-derived from the existing V33 `patient_link_active` fold, so a revoked link ends access on the next request.
- **Scope exception — two documentation links (tool):** moving `SyntheticPatientAppointmentPorts.java` to `src/test` broke links in `docs/spec/clauses/product/self-access.md` and `docs/spec/clauses/product/verified-adult-patients-see-appointments-released-reports.md`; `python3 -I scripts/check-docs.py` failed until each link's `src/main` segment was changed to `src/test` (two path-only edits, no prose changed). Those two files are outside the declared task scope; the edit was necessary to keep a mandatory gate green and is flagged for owner review. The surrounding clause prose is a historical gap snapshot and still describes the pre-fix state; reconciling that prose needs an owner decision and is requested via task-requests below.
- **Java bean shape (tool):** Spring CGLIB-advises the new `@Repository`/`@Component` beans, so those classes cannot be `final`; the domain service and controller were likewise left non-final. Constructor validation is absent, so no `CT_CONSTRUCTOR_THROW` risk. `TransactionOperations` is injected instead of the concrete `TransactionTemplate` in the link adapter and audit appender to avoid `EI_EXPOSE_REP2`; SpotBugs reports zero findings after compile.
- **Device uniqueness decision (tool):** V103 does not add `UNIQUE(organization_id, token)`. Re-registering the same provider token for a new device id is legitimate; a unique constraint turned that into a spurious 409 in the HTTP suite. Tenant isolation is enforced by the composite key and FORCE RLS.
