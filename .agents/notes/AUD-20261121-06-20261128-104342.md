- **Scope exception — two documentation links (tool):** moving `SyntheticPatientAppointmentPorts.java` to `src/test` broke links in `docs/spec/clauses/product/self-access.md` and `docs/spec/clauses/product/verified-adult-patients-see-appointments-released-reports.md`; `python3 -I scripts/check-docs.py` failed until each link's `src/main` segment was changed to `src/test` (two path-only edits, no prose changed). - **Java bean shape (tool):** Spring CGLIB-advises the new `@Repository`/`@Component` beans, so those classes cannot be `final`; the domain service and controller were likewise left non-final. Re-registering the same provider token for a new device id is legitimate; a unique constraint turned that into a spurious 409 in the HTTP suite. Tenant isolation is enforced by the composite key and FORCE RLS.
