## Lessons for workers

- `scripts/check-constraints.py` rejects even a test-only
  `@SuppressWarnings("unchecked")`: use an untyped `any()` with a mocked
  synchronous `TransactionTemplate` instead of a raw
  `any(TransactionCallback.class)` cast.
- When the clause is already implemented, proof tests are expected to pass
  first run; do not manufacture a red phase. Story step 3 requires `@Disabled`
  only when the behaviour is actually missing.
- To prove an authorization-before-state guard, make the negative a *mutating*
  command with a matching version, so a 403/404 cannot be explained by the
  version check and is clearly distinct from the 409 closed-thread refusal.
- `worker-check.sh` stops at `check-pack.py` on the CI-profile `opencode.json`;
  confirm once with `git ls-files -v` and `git show HEAD:opencode.json`, then run
  the remaining stages individually instead of editing that protected file.
