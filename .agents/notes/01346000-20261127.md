## Findings
Eight issue-monitor runs failed with `refusing to run in a dirty workspace` before the agent
started. The quoted `##[error]` text in the 25k-line log was inert and did not set the exit code.
D's archive-test fix was cherry-picked so the full suite is green on this branch.

## Lessons for workers
Any artifact downloaded into the checkout before a `require_clean_worktree` profile is a
start-up failure; use `runner.temp` and pass an explicit path, as the daily-notes profile already does.
