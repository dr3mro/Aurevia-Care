## Lessons for workers

- Reuse `useBreakpoint()` and the query-keyed `matchMedia` stand-in from existing responsive tests; jsdom caches one
  snapshot per query, so install answers before a fresh render instead of mutating them mid-test.
- In jsdom a numeric zero style may normalise to `'0'` or `'0px'`; assert both rather than changing the component.
- When a scope contains only a new primitive, state plainly that component-level coverage is not an end-to-end
  request path and use a `task-requests` block for the owning screen/E2E work instead of editing out-of-scope files.
- A coverage auditor asks for a discriminating assertion on **both** sides of each generated branch, not just
  execution: assert the desktop composer is not sticky and that a selected detail on desktop renders no Back action.
