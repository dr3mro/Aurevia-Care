## Lessons for workers

- Before writing a negative-path test class named by a task, grep the whole test tree: a class whose branches are all taken is duplicative, so extend the owning test instead.
- A targeted `mvn ... test` runs under the JaCoCo agent but emits no fresh report (report/check bind to `verify`); do not run standalone `jacoco:check` on partial exec data, and do not run full `mvn verify` as a worker.
