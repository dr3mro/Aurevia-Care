## Lessons for workers

- When the gate fails on `test_check_pack.py`, `gen-opencode.py --check` or `check-pack.py`, compare `git show HEAD:opencode.json` with the worktree copy before treating it as your own regression — in cloud workers the worktree file is the CI profile under skip-worktree.
