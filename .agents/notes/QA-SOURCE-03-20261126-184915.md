## Lessons for workers

- When an empty-state branch owns the primary action, search the repo for an existing "empty notice beside a live screen" pattern before inventing structure: `apps/staff-web/src/features/radworklist/RadWorklistPage.tsx:223-247` already had the exact one-fragment solution.
- An assertion like `queryByRole('table') === null` can encode the defect rather than the invariant. When a story intentionally mounts a worklist shell for its controls, assert the user-visible invariant instead (no `rowheader`, controls present) and state the behaviour change in notes.
- On async UI tests, never use a fixed `mock.calls[index]` or a synchronous `getBy*` immediately after a state-changing click. Use `findBy*`/`waitFor`, `.find(...)` plus the local `required<T>()` helper, and prove a follow-up request by slicing calls after the command index.
- Background reviewers read the notes at the time they run. Fill `Test evidence`, `Coverage` and `Review verdicts` before requesting the post-code pass; otherwise a NO-GO is about stale notes, not the code, and a second pass is needed.
- `scripts/check.sh` was deliberately not run: it delegates to the full `mvn verify`, which AGENTS.md forbids for swarm workers. The canonical frontend gate `bash apps/staff-web/check.sh` was used instead.
