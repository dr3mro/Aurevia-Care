## Lessons for workers

- Read `OpenApiContractDriftTest` before editing `contracts/openapi.yaml`: the packaged mirror at `apps/api/src/main/resources/contract/openapi.yaml` must be refreshed byte-for-byte in the same change, even when an old task scope omits it. Refresh it with `cp`, then prove parity with `cmp -s` and matching sha256 and run the targeted Java drift test.
- `expectTypeOf(...).toMatchTypeOf(...)` is deprecated under the staff-web ESLint policy; use `toExtend(...)` for a compile-time "extends" assertion. Keep type-level assertions at module scope and pair them with runtime `expect(...)` assertions so the test itself can go red.
- Put route-parity tests in `apps/staff-web/src/api`, slice the contract by `operationId` and the generated file by the operation key, and assert the exact non-optional generated header line. This catches both YAML drift and a forgotten `npm run gen:api` without a YAML dependency.
- When a plan reviewer reports a Required out-of-scope dependency, check whether it is a derived artifact with a documented exception and precedent; record the exception and proof in Findings rather than silently crossing the scope boundary.
