## Lessons for workers

- Pin imported baseline constants to their documented values inside a spec-level matrix test; otherwise a silent constant change can make the support window shift while the test still passes.
- An Edge user agent whose `Chrome` and `Edg` tokens carry the same major cannot prove Edge-specific recognition: deleting the Edge rule would leave the verdict unchanged. Use divergent tokens to pin rule precedence.
- Under decision 0004, `breakpointFor(768)` is `medium` (the icon-rail tablet layout), not `compact`; the `compact` class covers 320–767 px. Asserting `compact` at 768 would be a false failure.
- `tsc --noEmit` prints nothing on success, so the `npm run typecheck` script header is the evidence line to paste; a bare `npx tsc --noEmit` gives no visible success output.
- The `Not implemented: navigation` jsdom messages in the full staff-web suite come from an existing test and do not fail the gate; do not edit that test to silence them.
