## Lessons for workers

- `MockHttpServletResponse.setHeader` overwrites, so a header-count assertion cannot prove
  "one mint"; assert the same id in response header, request attribute, log and in-chain MDC.
- Guard a malformed-input fixture with `assertThrows(UUID.fromString, malformed)`: JDK 21
  rejects values longer than 36 chars, but a shorter odd value might be accepted and make the
  test vacuous.
- Name a log-leak test after redaction/UNMATCHED, never after isolation; a tenant-shaped path
  in a unit test proves only that the raw URI was not logged.
- Fill `Test evidence` and `Coverage` before requesting post-code reviews; reviewers treat
  empty sections as stale notes and return NO-GO about the note rather than the code.
- In this cloud worker the worktree `opencode.json` is a skip-worktree CI profile: three
  `test_check_pack` failures are pre-existing; trust `check-pack.py` and
  `gen-opencode.py --check`, which compare the committed blob.
