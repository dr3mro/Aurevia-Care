## Findings

- The wrapper is exported but has no production caller: `messenger/MessengerPanel.tsx` (which hardcodes `data-breakpoint="expanded"`) and `mail/MailScreen.tsx` own their own selection state and sit outside the reserved `layout/` scope. A wiring story with a caller-level integration test is requested below. Until it lands, neither panel should claim WEB-07/UX-01 or the 768 px rule for itself.
- Keyboard evidence is a DOM/stylesheet check, not painted proof. The composer now has `position: sticky`, `inset-block-end: 0`, an opaque surface background and exact `max(8px, var(--safe-block-end, 0px))` padding, and the section declares `scroll-padding-block-end: var(--sc-space-8, 32px)` following the `Form`/`NoteEditor` pattern. Caveat (code reviewer, Optional): `.page` is not itself a scroll container in the current app, so that reservation is inert until a scroller is established; the test asserts the declaration only. There is no component-owned field `scroll-margin-block-end`; `.field:focus-visible` supplies it only when callers use that class. A browser virtual-keyboard case is requested below.
- Reviewer-found defects fixed in this pass: (1) `overflowX: 'hidden'` on the grid and section made each a block-axis scroll container, which trapped the sticky composer against a non-scrolling scrollport and could clip non-wrapping content — removed; `minmax(0, 1fr)` tracks, `minInlineSize: 0` and `overflowWrap: anywhere` are the real no-scroll guards. (2) The docked composer lacked scroll-space reservation and an opaque background — both added. (3) The `compact && detailOpen` guard had no wider-band assertion — a regression test now covers it. No other reproducible in-scope defect was found.
- The initial trigger is likely the documented PR-mechanics/environment pattern (all gates were green at the start), but the quality loop still found and fixed real defects; this is not a no-op verification pass.
- No dependency, contract, migration, authorization or audit event changed.

## Lessons for workers

- One clean verification pass is enough: when local gates are green and the only blocker is a stale PR label or a cloud-worker gate artifact, record the single exact trusted next step and stop. Repeated notes-only passes cannot clear a label or publish a task (`.agents/reports/2026-11-22.md`, Lesson 1).
- A filtered `vitest --coverage` run cannot be used as an inner loop here: `coverage.include` is all of `src/**` with per-file 100% thresholds, so unrelated files fail first. Use an unfiltered `npx vitest run <file>` for red/green and reserve `check.sh` for the coverage gate.
- jsdom serialises a zero CSS length as `0`, not `0px`, and `matchMedia` breakpoints resolve in priority order: a resize from expanded back to compact must clear both `min-width` queries in the same `act`.
- Controlled components report a back command but do not change their own selection; prove restoration with a stateful harness, not a fixed-prop render. Clean up `dir`/`lang` in `afterEach` so RTL tests do not leak into later cases.
