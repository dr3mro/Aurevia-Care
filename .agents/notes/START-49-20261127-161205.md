## Lessons for workers

- Before writing a negative-path test class named by a task, list the branches in the named package and grep the existing tests for each one: if every branch is taken, the class is duplicative and a scope stop with a task request is the correct outcome.
- "Cross-tenant" is not always HTTP 404: a projection filter that omits foreign rows must be asserted as absence plus no foreign organization id in the output, never as "not found".
- A targeted `mvn ... test` runs under the JaCoCo agent but produces no fresh report or gate (report/check bind to `verify`); do not run standalone `jacoco:check` on partial exec data, and do not run full `mvn verify` as a worker.
- Fill `Test evidence`, `Coverage` and `Review verdicts` before requesting post-code reviews; record pre-existing tooling failures exactly and never suppress them to make a gate green.
- `task-requests` reaches the tracker through the daily notes reconciliation when a stop has no code or PR; keep the block precise and valid.
