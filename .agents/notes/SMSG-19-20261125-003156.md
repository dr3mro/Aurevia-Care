## Lessons for workers

- When a task's scope lists exact source files but its acceptance criteria require tests,
  keep co-located `.test.ts(x)` companions beside those files and name the ambiguity in the
  notes; sibling subfeatures do the same and the per-file coverage gate expects them.
- A route that needs an injected command is not a route: document it as a mounted part and
  require a real save callback rather than inventing a no-op adapter that would fake a state
  transition.
- Check `canAccessRoute()` for a new pattern before claiming it is role-gated; a pattern with
  no navigation entry is open to every signed-in role, so the hand-off must say so.
