# FIX-45325709537 — Swarm gate CLI accepts --head-root

## Summary

PR #1592's Swarm gate run 45325709537 (job 138214682218) failed before judging
anything: `swarm_gate.py: error: unrecognized arguments: --head-root tested`.
`.github/workflows/swarm-gate.yml` runs the trusted verifier from the base
checkout and intentionally reads the integration manifest from a separate
`tested` checkout, but `main()` in `scripts/swarm_gate.py` never declared or
forwarded the flag, even though `collect_context()` already accepted `head_root`.
Added the option and forwarded it by keyword. No workflow, permission or token
change was needed. Issue #1593's separate complaint about 151 check-docs errors
was already repaired on main (`check-docs` reports 0 violations), so it was left
out of scope.

## Lessons for workers

- A verifier CLI is part of its contract: when a workflow passes a flag, add a
  test that drives `main()` with the exact flag before changing the script.
- Two classes with the same name silently drop tests from discovery; grep for
  duplicate `class` declarations before trusting a test count.
