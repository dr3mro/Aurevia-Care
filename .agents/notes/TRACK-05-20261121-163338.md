## Lessons for workers

- For docs-only stories, the applicable step-6 gate is
  `python3 -I scripts/check-docs.py`; also run `check-names.py` and
  `check-secrets.py`. These three are fast and directly relevant to one
  Markdown file.
- In a cloud worker, `bash scripts/check.sh` can fail at `check-pack` because
  `opencode.json` is the CI profile under skip-worktree. Confirm with
  `git ls-files -v opencode.json` and `git show HEAD:opencode.json`; do not
  regenerate the file or edit protected tooling.
- Mermaid `flowchart` with one `subgraph` per role renders as a readable
  swimlane diagram on GitHub and needs no new dependency.
- Keep "What the patient sees" strictly to released content: a staff status
  change, transmission acknowledgment or clinical acknowledgment is not
  patient-visible (XCH-06, PAT-02).
