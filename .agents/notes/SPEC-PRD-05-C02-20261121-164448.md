## Lessons for workers

- Do not upgrade a clause from Not built to Partly built because a nearby tenant-level code hook exists: the clause's unit is the signed deployment decision, and rule 3 is explicit about who supplies it.

- `grep`ing the spec alone is not evidence of implementation — verify the named file exists (`test -f`) and record the failing command when it does not.
