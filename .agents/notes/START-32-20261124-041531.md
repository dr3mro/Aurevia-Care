## Lessons for workers

- Before treating `python3 -I scripts/check-docs.py` as a story gate, run it once on the untouched base and save the output. In this snapshot it already fails with 151 pre-existing errors in other docs; a before/after diff is the honest evidence that a new guide introduces none.
- In `docs/reference/modules/`, relative links use the `../../../` prefix to reach the repository root; 242 such links in this guide were verified with a small local regex script before the reviewers ran.
- Test counts in a module guide must be recomputed with a tool, not estimated: the first draft said 73 routes and 90 test classes; the actual values are 71 and 101.
- `grep -r '@Test'` overcounts by matching `@TestConfiguration`: use `grep -rE '@Test[[:space:]]*$'` for a true method count. In this tree the naive count is 922 and the exact count is 919 (clauses: 337 vs 334).
