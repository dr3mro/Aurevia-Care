## Summary
Reliability hardening for intermittent GitHub Pages deploy failures: the upload and
REST artifact listing can see `github-pages-<attempt>` while `actions/deploy-pages@v4`
still sees zero artifacts moments later. One bounded retry with a 20-second settle is
added, followed by a fail-closed guard. No gate is weakened.
