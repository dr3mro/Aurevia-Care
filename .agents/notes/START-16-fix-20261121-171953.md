## Lessons for workers

- `scripts/quick-check.sh` has `set -euo pipefail`; an *info*-level shellcheck
  finding anywhere in `scripts/*.sh` (e.g. SC2015 at `agent-run.sh:51`) aborts the
  whole worker gate before docs checks run. A docs-only worker will see "local
  checks failed" even when every in-scope check passes — reproduce with
  `bash scripts/quick-check.sh` and check whether the abort precedes your scope.
- The SC2015 fix belongs to a protected file (`scripts/agent-run.sh`). Replace
  `[[ -f scripts/taskstore.py ]] && python3 -I scripts/taskstore.py view || true`
  with an explicit `if [[ -f scripts/taskstore.py ]]; then ... || true; fi` block.
  A swarm worker must not edit it: put it in `## Lessons for workers` so the
  daily-notes reconciliation proposes it as a reviewed maintainer PR (that is
  the only automated path for `scripts/` changes).
- `scripts/check-docs.py` resolves a relative Markdown link from the file's own
  directory: from `docs/operations/exercises/`, root files need `../../../`,
  sibling `docs/operations/<area>` files need `../<area>/`, and
  `docs/WORKFLOW.md` needs `../../WORKFLOW.md`. A maintainer folder rename can
  turn previously green docs red; grep the scope for the old fragment at the
  start of a fix pass.
- Before citing a command in operations documentation, confirm the file exists
  and run it on synthetic fixtures. The offline evidence evaluators judge
  declarations only — never phrase a synthetic rehearsal as proof that a restore,
  alert, revocation or human approval occurred.
