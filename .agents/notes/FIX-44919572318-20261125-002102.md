## Findings

1. **Credentials/transient, not a code defect (tool).** Watchdog issue #387 was written from
   the full log and says `credentials`. The stored tail in the task is PostgreSQL container
   noise. Do not change the integrator to make this run green.
2. **No proof of recovery (tool).** The next green run skipped the integration job (empty
   queue). A person should verify `SWARM_TOKEN` health/scopes; this cannot be done from a
   worker without a token and is outside this story.
3. **Stale repair task (tool).** The task file shows `attempts: 18` and `scope: *`, which
   blocks swarm waves. PR #1643 already carries the same no-code classification and remains
   open with `needs-fix`/`debug-1`. An owner/integrator needs to accept the classification
   and close the task rather than dispatch another code worker. Issue #697 suggested a
   workflow change to auto-classify and close such transient scope-* repairs; that change is
   not part of this story's acceptance and was not made here.
4. **Brief inaccuracies (tool).** The advisor brief listed no read-only specialists, while
   AGENTS.md requires the quality loop; the quality-loop reviewers named there were used.
   The brief's closing instruction to run `scripts/check.sh` conflicts with AGENTS.md and the
   2026-11-22 reconciled note ("Do not run `scripts/check.sh` ... as a worker"); with no
   production change, and because that script invokes Git, it was not run. The brief's
   `scope: *` also conflicts with the worker rule against editing workflows, scripts and
   agent files; no such file was edited.

## Lessons for workers

- Classify a stuck repair before changing code: read the watchdog issue written from the
  full log, not just the stored tail. A `credentials` class means fix the runner secret, not
  the repository.
- A three-second failure in a gate step is an early exception, not a slow test failure. Look
  at the first action of the failing command (`gh pr view` here) before suspecting the gate.
- One clean verification pass is enough. Repeated evidence-only dispatches of a transient
  repair cannot merge themselves; hand the classification back to the owner/integrator.
- In a cloud worker, treat public Actions API reads as evidence when the log endpoint returns
  403; label the synthetic reproduction as simulated, never as the original log.
