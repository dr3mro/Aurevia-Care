## Summary
The Swarm gate now refreshes a moved PR head before declaring failure: a trusted
workflow step detects the move, checks out the live PR head without persisted
credentials, and a pure `refresh-event` subcommand rewrites only the event head with
a provenance marker. The verifier then re-runs all checks against that exact head.
A stale/non-ancestor note still fails, and a second head move still fails currency.
