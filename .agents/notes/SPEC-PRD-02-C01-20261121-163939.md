## Lessons for workers

For evidence notes, enumerate concrete file paths with relative `../../../../`
links from `docs/spec/clauses/<area>/` and verify each target with a shell
existence check before writing — `check-docs.py` fails the build on a single broken
link. Prefer "Partly built" with an explicit list of missing human/partner evidence
over claiming "Built and verified" from code/tests alone; the clause boundary often
needs a signed decision that source files cannot supply.
