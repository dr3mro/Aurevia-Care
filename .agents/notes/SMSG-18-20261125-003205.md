## Findings

- Scope decision: the wrapper is exported but has no production caller because `MessengerPanel.tsx` and `MailScreen.tsx` are outside the reserved `layout/` scope. `MessengerPanel.tsx:437` still hardcodes `data-breakpoint="expanded"` and `MailScreen.tsx:454` keeps its own grid. A wiring story with a caller-level integration test is requested in the `task-requests` block; until it lands, neither panel should claim WEB-07/UX-01 or the 768 px rule.
- Keyboard evidence: the composer has `position: sticky`, `inset-block-end: 0` and `max(token, var(--safe-block-end, 0px))` padding, but no `scroll-padding-block-end` on a scroll container and no component-owned field `scroll-margin-block-end`; `.field:focus-visible` supplies the latter only when callers use that class. This is a documented DOM/stylesheet check, not proof that the focused field stays visible. The requested E2E story with a virtual keyboard must prove it on the wired screens.
- No defects were found in the wrapper; no dependency, contract, migration, authorization or audit event changed.
- jsdom navigation warnings in the full run come from pre-existing system-page tests and are unrelated to this change.

## Lessons for workers

- A filtered `vitest --coverage` run cannot be used as an inner loop here: `coverage.include` is all of `src/**` with per-file 100% thresholds, so unrelated files fail first. Use an unfiltered `npx vitest run <file>` for red/green and reserve `check.sh` for the coverage gate.
- jsdom serialises a zero CSS length as `0`, not `0px`, and `matchMedia` breakpoints are resolved in priority order: a resize from expanded to compact must turn off both the expanded and medium queries in the same `act`.
- Controlled components report a back command but do not change their own selection; prove restoration with a stateful harness, not by clicking a fixed-prop render.
- In a colocated `src/**/*.test.tsx` the strict 150-line-per-function lint rule applies; split fixtures/harnesses into small helpers. Clean up `dir`/`lang` in `afterEach` so RTL tests do not leak into later cases.
