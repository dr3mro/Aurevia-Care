## Findings
The 500-row cap was saturated on live `main` (`gh pr list ... | jq length` -> 500). The Pages
failure was attempt-2 specific; later attempt-1 runs with `github-pages-N` succeeded, so the
attempt-scoped name was retained and only metadata visibility was hardened. Removed a now-dead
downstream non-dict guard and replaced the poll's `grep -q .` with an explicit captured result.

## Lessons for workers
When a tool's documented limit is also used as a truncation sentinel, a full window is
indistinguishable from complete data; paginate instead of raising on the boundary.
