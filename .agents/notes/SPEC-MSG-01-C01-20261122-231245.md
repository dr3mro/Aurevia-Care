## Lessons for workers

- For a test-only clause story, prove red with a temporary mutant of the exact
  production predicate, restore it under a shell `trap`, verify a clean
  `git diff --exit-code -- <production path>`, and re-run green. That records
  fault detection without a production hunk in the pull request.
- When seeding eligibility negatives, insert the care unit and its relationship
  together: `relationshipsFor` joins them, so a missing unit would make the
  negative pass for the wrong reason.
- `scripts/worker-check.sh` runs every integration suite; under the worker rules
  run the individual policy stages plus a targeted `-Dtest=Class` integration
  test instead, and leave the full JaCoCo/OWASP gate to the integrator.
- A worktree `opencode.json` under `skip-worktree` (`S`) can differ from HEAD in
  cloud workers; confirm once, record the commands, and do not edit the file.
