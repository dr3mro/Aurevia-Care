Out-of-scope `UseExplicitPostCommandsSignCorrectAcknowledgeTest:158-175` freezes six stale paths, `ResourceFamiliesIncludePatientsAppointmentsEncountersOrdersTest:120-122` freezes the therapy path, and `web/DurableReplayAuthorization.java:109-110` keys replay on `"POST " + definition.path()`. Repointing paths in place would break those callers; the additive mapping keeps them green.
3. Gate registration is deliberately unchanged. `CommandCatalog.paths()` now returns only definitions whose `gated` flag is true (the 24 baseline); mapping-only definitions resolve through `findByPath` but are not registered by the live interceptor. This respects the still-open owner decision in FU-1747-02 and the full-route parity work in FU-1747-03; broadening registration without HTTP evidence and clinical/security review was rejected by the security reviewer.
3a. Residual risk: a second consumer, `web/DurableReplayAuthorization.java:109-110`, builds its replay index from `commands()` and therefore now sees the ten mapping-only entries. Idempotent replay on those routes resolves to the owning policy instead of failing closed with no action; this is asserted by `CommandCatalogRealRouteTest.mappingOnlyEntriesAreVisibleToReplayScopeAsWellAsLookup` and disclosed in `contracts/openapi/README.md`. Filtering that index is out of this task's scope and is recorded as a task request below. There is still no live Spring-discovery POST↔catalog parity check.
4. Artifacts were regenerated from the 34-entry catalog; `apps/staff-web/src/api/generated/openapi.d.ts` is derived from `contracts/openapi.yaml` (out of scope) and is byte-identical. `contracts/openapi/README.md` now states the baseline/mapping-only split.
5. `scripts/docs.sh` exits 0 with pre-existing unresolved-reference warnings in `docs/reference/index.md`; no new warning came from this change.
6. Evidence is tool output plus read-only reviewer findings. There was no simulated-user walkthrough, no clinical reviewer and no authorized human feedback.

## Lessons for workers

- A catalog "realignment" can be additive: freeze published paths when out-of-scope tests and replay-scope keys depend on them, and bind delivered handlers with new ids. Decouple registration from lookup with an explicit flag instead of silently gating safety-critical routes.
- Assert with policy constants (`SpecialtyActions.PT_ACCEPT_REFERRAL` is `SPECIALTY_PT_ACCEPT_REFERRAL`), not guessed string literals.
- The Java conventions gate rejects `{@link #method()}`; use `{@code method()}` for same-class references.
- A generated-client drift test is the cheapest proof that a catalog change and its OpenAPI/client artifacts stayed in the same commit.
