## Lessons for workers

- When a dedupe key must block concurrent emits but a failed fetch must be retryable, mark the key synchronously before the first await and delete it on every no-send path; a single after-dispatch mark leaves a real double-send race.
- `dispatchNotice` returns a new device registry; the input map is never mutated. Assert invalidation through the returned outcomes and log event, not by reading the source map.
- RNTL `act` is async here: an un-awaited `act(() => view.unmount())` leaves effect cleanup unflushed and cascades false failures into later tests. Always `await act(async () => { view.unmount(); })`.
- `AppointmentStatus` is a closed union: a key-collision test cannot invent status words through a typed event. Let the key helper take a `string` status word and test the collision at that boundary.
- A repo-wide `prettier --check` can fail on hundreds of untouched files; check the canonical module gate before treating it as a change defect, and never add formatting churn to fix a non-gate.
