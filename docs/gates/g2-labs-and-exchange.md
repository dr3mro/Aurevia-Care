## Entry point to test trace

- **Specimen trace.** HTTP `POST /api/v1/lab/specimens/{id}/reject`, `POST /api/v1/lab/specimens/{id}/recollect`, `GET /api/v1/lab/specimens/{id}/history` (`SpecimenRejectionIntegrationTest`). `SpecimenRejectionService` keeps the rejection event and inserts a linked accession carrying the original patient and order reference; the integration test asserts the HTTP responses and the tenant denial.
- **Replay integrity.** HTTP `POST /api/v1/xch04/orders`, `POST /api/v1/xch04/results`, `GET /api/v1/xch04/results/{id}` (`ResultRoutingIntegrationTest`). `ResultRoutingService` resolves a replay by lineage and checksum instead of inserting a second revision; a different payload against a stored version is a 409. The conformance fixtures replay the same rules over both FHIR and HL7 v2 events (`PartnerReportProcessorTest`).
- **Unmatched results.** HTTP `POST /api/v1/xch04/results` (diversion path), `GET /api/v1/xch04/reconciliations` (`ResultRoutingIntegrationTest`) and `POST /api/v1/lab/outage/orders/{orderRef}/manual-results`, `GET /api/v1/lab/outage/unmatched` (`OutageIntegrationTest`). An unmatched or conflicting report is parked as an OPEN reconciliation entry with no imported report and no clinical review; `ReconciliationService` resolves it with a reason and keeps the first decision on a repeat.
- **Critical escalation and acknowledgment.** HTTP `POST /api/v1/critical-results`, `/{id}/assign`, `/{id}/verify`, `/{id}/escalate`, `/{id}/release`, `/{id}/acknowledge` (`CriticalResultFlowTest`). The deadline clock selects the approved primary or backup channel; escalation and release are events, and only an authorized clinician's acknowledgment changes state, bound to the verified revision.
- **Corrections.** HTTP `POST /api/v1/xch04/results` with a `CORRECTED` kind after the human acknowledgment at `POST /api/v1/xch04/results/{id}/acknowledge` (`ResultRoutingIntegrationTest.correctionPreservesTheOriginalReopensReviewAndNotifiesPriorRecipients`). A new revision and review are appended; the acknowledged original is never mutated.
