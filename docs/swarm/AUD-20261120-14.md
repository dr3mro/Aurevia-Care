## Story summary

The X-04 server-side authorization control is inert in production. `CommandAuthorization` and its 24-command `CommandCatalog`, the generated OpenAPI contract and the generated TypeScript client are never invoked by a request. The story's **expected fix** has three parts:

1. Provide `CommandAuthorization` as a Spring bean wired to the durable `DecisionSink` from READY-41.
2. Call it from each owning write endpoint for all 24 catalog commands.
3. Add a build-failing parity test that fails CI when a catalog command has no production caller.

## Acceptance mapping — expected vs. achievable in this scope

| Expected deliverable | Files it requires | Inside my scope? | Outcome |
|---|---|---|---|
| `CommandAuthorization` as a Spring bean with durable sink | A bean config plus a `DecisionSink` bean, `MembershipResolver` bean and `Clock` bean; durable sink is READY-41 (`config`, `db/migrations/V65__authorization_decisions.sql`) | **No** — READY-41 is a separate, still-open story (`[ ]` in tasks/); its `config`/`db/migrations` files are outside my scope and the class `JdbcDecisionSink` does not exist in this checkout, so any reference would not compile | Not done |
| Call the gate from each owning write endpoint (24 commands) | The 33 controllers holding 143 `@PostMapping` methods across ~15 packages (`web`, `patient`, `messaging`, `exchange`, `finance`, `lab`, `prescription`, `authz`, `chart`, `clinical`, `documents`, `events`, `scheduling`) | **No** — all controllers are outside `api/authorization` | Not done |
| Build-failing POST-mapping ↔ catalog parity test | A test under `apps/api/src/test/java/...` and/or wiring into `scripts/check.sh` / `.github/workflows` | **No** — `src/test`, `scripts/` and `.github/` are outside my scope | Not done |

There is no in-scope mechanism that makes the gate actually run: a Spring `@Component`/`@Bean` in `api/authorization` would need the `DecisionSink`/`MembershipResolver` beans that do not exist (registering it would break Spring context startup for every `@SpringBootTest`), and a bean that no controller calls remains inert. An interceptor in this package would still require those missing beans and would need to arbitrate 24 catalog commands against 143 unmapped POST routes (denying the rest would break the application; allowing them leaves the gate inert).
