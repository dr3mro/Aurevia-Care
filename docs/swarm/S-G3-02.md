## Review findings and dispositions

Three read-only specialist reviews were commissioned; all findings were concrete and were fixed or explicitly deferred:

1. **Withdrawn correction resurrected the original (Security, High).** `latestReleasedRevision` chose max `RELEASED`, so withdrawing a correction re-exposed the superseded revision. Fixed with `isSuperseded` (a released *or withdrawn* correction still supersedes; a held correction does not) applied in both `listFor` and `download`. Regression tests added.
2. **Audit sink was not thread-safe (Security, Medium).** Replaced `ArrayList` with `CopyOnWriteArrayList`; `events()` still returns an immutable snapshot.
3. **`listFor` served a revision `download` rejected (Backend, High).** Fixed by the same `isSuperseded` filter; the list test now pins one current view.
4. **Future-dated newer revision made today's revision un-downloadable (Backend, High).** `latestReleasedRevision` now takes the evaluation date and ignores future-effective revisions; regression test added.
5. **Audit record incomplete and wrong purpose (Backend, Medium).** Added purpose, scope and occurred-at instant, sourced from dedicated patient-access constants and the injected clock; asserted in tests.
6. **Impossible dates reached `LocalDate.parse` as 500 (Backend, Low).** `putReport` now validates with `LocalDate.parse` and rejects e.g. `2026-99-99` as 422; regression test added.
7. **Client used `id` while the server projection emits `reportId` (Mobile, High).** Renamed the client field to `reportId` end-to-end so real server-shaped payloads parse.
8. **Authorization response was not bound to the request (Mobile, Medium).** `parseAuthorization` now rejects a well-formed authorization for another report or revision with `AUTHORIZATION_MISMATCH`; tests added.
9. **RTL was only a text label (Mobile, Medium).** Applied `direction: rtl/ltr` row styles and asserted the style prop in tests.
10. **Asymmetric/empty correction context was silently dropped (Mobile, Low).** `normalizeCorrection` requires a complete non-empty pair or neither; tests added.
