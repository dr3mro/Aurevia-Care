## Lessons for workers
- In a cloud worker, treat `check-pack`/`gen-opencode` "stale" as a CI-profile artifact under `skip-worktree`; compare `.github/opencode.ci.json` and `git show HEAD:opencode.json` before calling it a defect, and never regenerate the file from a worker.

- For the `fast` profile, the JaCoCo bundle gate is red because `@Tag("integration")` classes are excluded; parse `target/site/jacoco/jacoco.xml` for the touched package to prove 100% per-class coverage and let the integrator run the authoritative bundle gate.
- Name packages after the business domain from authoritative TODO.md, not story text (`messaging/acknowledgment`, not `messaging/s_g3_08`); mobile feature folders keep `s_g3_*`.
- A domain kernel using an in-memory store needs no new migration; document the store contract for a future DB adapter (S-G3-08 decision).
- Keep Javadoc Doxygen-safe (`{@code}`, fully qualified `{@link java.time.Instant}`) when Doxygen is unavailable locally.
- A scope-confined worker must stop and report when the gate reports failures in other stories' code; it must not edit out-of-scope production code to make the gate green (CW-008/CW-009).
