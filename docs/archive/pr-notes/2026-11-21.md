## Lessons for workers

- `ON CONFLICT DO NOTHING` plus a read-by-business-key avoids a `RETURNING` empty-result branch and makes replay idempotent; assert the replay in the HTTP test. Bind `OffsetDateTime` (not raw `Instant`) to `timestamptz` and keep `TransactionTemplate` in every JDBC store — under FORCE RLS, reads are empty without it.
- A database approval trigger must enumerate every non-approval column with `IS DISTINCT FROM`; a status-only check lets a caller rewrite hours or the effective date.
- `mvn -Pno-security,fast -Dgroups=integration` does **not** run integration tests because the `fast` profile's `excludedGroups=integration` wins. Use `mvn -Pno-security -Dgroups=integration` and confirm the Surefire count. A bare `spotbugs:check` is vacuously green; compile first (`-DskipTests compile spotbugs:check`).
- A path-keyed wiring baseline turns a grandfathered suppression into a *new* finding on `git mv`; run `check-wiring.py` immediately after any rename. Before a rename, grep both the class name and its file path — `check-docs.py` validates relative Markdown links and generated OpenAPI artifacts are pinned to catalog string constants.
- Do not run `scripts/check.sh` in a swarm worker: it calls `apps/api/check.sh` → full `mvn verify`, which times out the run. Run targeted `-Dtest=...` plus the individual policy scripts and a targeted `jacoco:report`, then leave the full gate to the integrator.
- When a shared primitive must live in `api/contract` but that directory is outside the declared scope, stop and file a `task-requests` block; do not create a competing primitive in an in-scope domain package. Before starting an `AUD-` story, `grep TODO.md` for its regex/title — the daily audit can emit two tasks for one finding, one with a broken scope.
- `ResultSet.getStringArray` is not on the standard JDBC interface — use `getArray(...)` as `JdbcMessagingStore` does. `version == null ? 0 : version` on an `Integer` trips SpotBugs `BX_UNBOXING_IMMEDIATELY_REBOXED` — use `Integer.valueOf(0)`. `List.of(...)` throws on a `null` element — use `Arrays.asList(...)` for rejected-input tables containing `null`.
- In a cloud worker, `git ls-files -v opencode.json` showing `S` explains `check-pack.py`/`test_check_pack` failures: verify with `git show HEAD:opencode.json` and never regenerate or commit that file. Do not re-diagnose it on a later pass.
