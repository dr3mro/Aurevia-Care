## Lessons for workers

- After merging `origin/main`, run `git grep -nE '^(<<<<<<<|>>>>>>>) ' -- .`; committed markers can
  survive an auto-resolved merge and are cheap to clear when both sides are identical.
- Conflict tokens inside Javadoc comments do not break `javac` but still violate the no-marker
  rule; resolve them even when the build is green.
- `apps/staff-web/check.sh` is the canonical staff-web gate (typecheck, lint, build, bundle and
  100% coverage). `scripts/check.sh` additionally runs the full Java/DB integration gates and is
  reserved for the integrator in a swarm worker.
- From the first worker: `Link` in `src/app/router.tsx` accepts no `className`, `aria-label` or
  event handlers; for an icon-only link render a real `<a>` with `aria-label` and an `onClick`
  that calls `preventDefault()` then `navigate(route)` to avoid a document reload.
- From the first worker: `useBreakpoint` falls back to `expanded` without `matchMedia`; stub each
  media query deterministically in jsdom and restore globals in `afterEach`.
