## Lessons for workers

- On a "did not finish cleanly" fix attempt with no failing check, re-run the exact targeted command and read the Surefire XML (`tests=` / `failures=` / `errors=` / `skipped=` plus method names) before assuming a defect; a green build line alone can hide a vacuous green.
- AGENTS.md forbids a swarm worker from running `scripts/check.sh` / `apps/api/check.sh` / `mvn verify` (full OWASP, SpotBugs, JaCoCo and every integration test). Run the targeted `-Dtest` suite and the individual policy scripts; leave the full gate to the integrator. A plan reviewer correctly rejects even a capped `scripts/check.sh`.
- The quality gate needs the notes file to exist **with** `## Review verdicts` before it runs; write the notes first, then run `scripts/quality-gate.sh BASE_SHA NOTES_FILE`. Keep conflict-marker and other gap notes under `## Findings` only — an unresolved `Critical:`/`Required:` line inside `## Review verdicts` blocks the gate.
- Spring 7 renames the 422 status enum to `UNPROCESSABLE_CONTENT`; assert `getStatusCode().value() == 422` and compare parsed `Instant` values with a tolerance (Jackson serializes at microsecond precision).
- An HTTP clause test gains real proof from the store, not just the response: assert committed `audit_event` action/outcome/purpose/scope, the append-only `release_event`/`release_notification` ledgers and their absence on rejected commands, filtered by a unique `X-Correlation-Id`.
