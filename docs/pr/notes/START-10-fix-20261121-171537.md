Two in-scope findings from the simulated QA reviewer were fixed in this pass:

## Lessons for workers

- A verbatim Arabic string can still be paired with the wrong English label: check the *English and Arabic values of the same key*, not just that the Arabic exists in a bundle. Here `event` = 'Append-only event' / «حدث غير قابل للتعديل» was mistaken for the audit-screen `auditEvents`.
- Keep the "Code name" column to real Java classes or DB tables. For UI-only states write `none`; source file paths belong in the document's intro/source note, not in that column.
- The QA reviewer's evidence was simulated/static (file reads and grep, no shell). All findings were independently confirmed with executed tool commands before editing; record both evidence sources in the notes.
