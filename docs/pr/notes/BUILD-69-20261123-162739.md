## Findings

- The advisor brief named `messages.ts`; that filename is discovered by the out-of-scope
  `tests/messageParity.test.ts` registry and would fail the gate. Used `resultsMessages.ts`
  (the `labBoardMessages.ts` precedent) with an equivalent local parity test.
- `src/theme/tokens.ts` still exposes only six legacy fields, so the thick red border and red
  heading of the approved picture cannot be reproduced without a raw colour. Criticality is
  carried by a word, a shape-distinct icon and `data-critical` / `data-overdue`; a task-request
  for the missing status token is below.
- `DataTable` cells are strings and the component is out of scope, so the Kind column is a word
  plus a shape-distinct glyph rather than a coloured pill. State is never colour-only.
- `formatInstant` renders date and time; a small, documented `formatClockTime` helper in
  `resultsMessages.ts` renders the time-only values shown in the picture with Latin digits and
  the facility zone.
- `ApiPage` leaves the Retry button inert unless the caller supplies `actions.onRetry`;
  `ResultsPage` supplies a page-owned retry that changes the request dependency key.
- No patient data, real identifier, credential or secret appears in code, tests or notes.
  All names, MRNs, accessions and organization ids are invented synthetic values.
- No clinical or human acceptance is claimed; all review is simulated/static and all user
  walkthroughs are synthetic render tests.
- Merging the latest `main` into the worker branch activated three stricter ESLint rules
  (`jsx-a11y/no-autofocus`, `react-hooks/set-state-in-effect`, `max-params`) that the earlier
  segment had not encountered. Fixed in code, never by suppression: the page-load announcement is
  now derived from `shouldAnnounceCritical(document.activeElement)` during render instead of a
  `setState` inside an effect; the typing test focuses a real input created before mount instead
  of using `autoFocus`; and `renderPanel` takes one options object instead of five positional
  arguments. Colocated `src/**/*.test.tsx` files are linted under the source rules (the
  `testFiles` relaxation covers `tests/**` only).
- Removed the dead `identity.patient.localName !== undefined` operand from the `showLatin`
  guard: `annotatedName` returns `lang === 'ar'` only when a non-empty local name exists, so the
  operand could never be false. Comments in `routes.ts` were corrected to state that both results
  routes render the same screen rather than claiming route-specific emphasis.
- Display-only scope decision (reviewer Optional, accepted): the six screen callbacks in
  `ResultsPage.tsx` are intentionally inert because no results-inbox endpoint exists in the
  published contract and this story is presentational. The page shows a synthetic-data notice;
  a follow-up task must wire commands and a real recipient control before any clinical use.
  Likewise, `formatClockTime` constructs an `Intl.DateTimeFormat` per call, time-only values omit
  a visible zone label, and `DataTable` keys rows by rendered content rather than the stable
  domain id. These are captured as follow-up work, not silently accepted as production-ready.

## Lessons for workers

- After merging `origin/main`, re-run the full module check before declaring green: newly arrived
  ESLint rules (`react-hooks/set-state-in-effect`, `react-hooks/purity`, `jsx-a11y/no-autofocus`,
  `max-params`) can fail code that passed on the pre-merge base. Derive values during render
  instead of writing state in an effect, focus test inputs before mount instead of `autoFocus`,
  and use an options object once a helper reaches four parameters.
- Colocated feature tests (`src/features/**/*.test.tsx`) are linted with the strict *source* rules;
  the `testFiles` override in `eslint.config.ts` only relaxes `tests/**` and `e2e/**`.
- Check filename-based discovery registries before creating a conventional `messages.ts` in a
  bounded staff-web scope; a new file can fail a global test you are not allowed to edit.
- With `perFile: true` at 100%, inline no-op callbacks passed to child components are functions
  that must be invoked by a test; a page-level "exposes every action" test covers them cheaply.
- Testing Library matches an element's whole normalized text: wrap individual clinical values
  in their own elements, or use regex matchers for values embedded in table cells.
- `ApiPage` requires the caller to own `onRetry`; a page that claims an offline/timeout retry
  state must pass that action or the Retry button is a no-op.
- A form-free screen can still meet WEB-09: the conflict state must be reachable and offer
  Compare / Reload / Copy, while "preserve typed work" and "unsaved changes" are N/A.
