## Lessons for workers

- Before trusting a red integration run in a swarm branch, run the *targeted* `-Dtest=ClassName`
  command and read the first error. A `testCompile` failure in an unrelated class is an inherited
  `main` break, not a defect in the scoped test; prove the scoped test separately with a clearly
  labelled compile-only workaround, then revert the workaround before committing.
- `worker_gate.py:validate_candidate` treats any changed file outside the declared `scope` as a hard
  violation. Never leave an out-of-scope unblock in the committed tree — diagnose it, hand it over
  with a `task-requests` block, and keep the PR scoped.
- The chart `clauses` tests are HTTP integration tests with dedicated databases. For a sign-metadata
  proof, compare the persisted `effective_at` by parsed instant
  (`getObject(..., OffsetDateTime.class).toInstant()`), and give each clause test its own database
  name so parallel classes do not collide.
