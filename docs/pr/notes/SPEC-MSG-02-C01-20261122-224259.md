## Lessons for workers

- For a test-only clause proof, capture the mocked insert arguments in `AtomicReference`s and have `find()` build the response projection from them: this asserts both the persisted identities and the HTTP body without a database, and makes server-side derivation observable by returning values different from the request.
- `ConversationService.authorize` reads `repository.activeRoles(subject)`, not the third `TenantContext` field; stub active roles explicitly per synthetic caller or every staff case collapses to 403.
- In cloud workers, `worker-check.sh`, `python-coverage.sh` and six `test_check_pack` cases fail only on the skip-worktree `opencode.json`. Confirm once with `git ls-files -v` (`S`) plus HEAD-vs-generated equality, record the command and final line, run the remaining gate stages individually, and never edit `opencode.json`.
