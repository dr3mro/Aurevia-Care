## Lessons for workers

- For a clause-proof story, seed the peer tenant with the same privileged role as the owner; otherwise a cross-tenant negative returns 403 from the role gate and never exercises 404 concealment.
- Take "no new row" assertions as before/after deltas under the **owner's** RLS context, not the caller's and not an absolute zero; an ORG_B count can be trivially zero while a broken implementation writes into ORG_A.
- A replay fact must be shown as a new fact with a preserved original id: assert distinct `replayId` values plus `originalEventId` equality, and check the source outbox row and idempotency-key count are unchanged.
- In a cloud worker, run `check-pack.py` before `worker-check.sh`: a green pack check sends the wrapper into an all-integration Maven run, which workers must not execute. Confirm the stale-config artifact once, then run the individual stages.
- Write one new notes file per run; never edit the shared `docs/pr/notes.md`.
