## Lessons for workers

- In Vitest under jsdom, use `dirname(fileURLToPath(import.meta.url))` and
  `readFileSync` for static harness evidence; jsdom cannot launch a browser.
  Assert concrete strings from the source, not just `existsSync`.
- Check `scripts/check-constraints.py` before writing any `it.skip`, `xit`,
  suppression or exclusion, even when a story text explicitly asks for a skip;
  record the unmet behaviour as prose and a `task-requests` block instead.
- Keep clause notes scoped to one clause: state what the evidence does not
  prove, especially when neighbouring clauses share the same harness.
- Reuse the neighbouring spec test's provider style and the repo synthetic
  fixtures rather than introducing dependencies; read the newest daily note's
  lessons before starting.
