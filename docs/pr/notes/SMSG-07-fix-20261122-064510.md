## Lessons for workers

- When a slice adds controller routes, publish them in `contracts/openapi.yaml` in the same change
  and regenerate the client; never add them to `missing-routes.txt`.
- A GET returning a JSON array must use a named array schema whose name does not end in `Page`
  (for example `PendingStaffAttachments`).
- Run the whole contract test family together (`OpenApiRouteParityTest`, `OpenApiContractRulesTest`,
  `OpenApiErrorRulesTest`, `OpenApiPaginationRulesTest`, `OpenApiRouteCoverageTest`).
- In cloud workers a `check-pack`/`gen-opencode --check` failure usually means the CI profile is
  active under `skip-worktree`; verify with `git ls-files -v` and `git show HEAD:` before treating
  it as real. Never edit or regenerate that protected file to pass.
- Workers must not run the full `mvn verify` (>10 min, ends the run as a timeout); run targeted
  test classes and `jacoco:report` for the touched area instead.
- When local gates are green but the integrator reports red, read the check-runs for the exact head
  SHA before writing another verification note; repeated re-verification without the SHA turns a
  stale-SHA race into an unbounded loop.
- After merging `origin/main`, re-run `git diff origin/main...HEAD --name-status` and confirm no
  out-of-scope `scripts/` edit was auto-merged; this pass changed only this notes file.
