## Decisions

- Plan review round 1 returned NO-GO with four Required gaps; all were addressed and the plan reviewer re-reviewed it GO: (a) an in-scope `realtime.ts` producer that opens the SSE stream with `fetch` + `ReadableStream` and descriptor headers (EventSource cannot send tenant headers), falls back to identifier-only polling with cursor resume, and feeds `MessengerPanel`; (b) attachment send is staged UI only because `InstantSendRequest` forbids extra fields and has no upload route — the explicit Send assertion checks the request body has exactly `facilityId`, `conversationId`, `body` and that no file bytes are transmitted; (c) branch-complete tests for 100% coverage; (d) a named `MESSENGER_VIEW_TIME_ZONE = 'UTC'` constant for deterministic day separators.
- Navigation/route wiring and real attachment upload are outside this task's scope; both are recorded as findings with `task-requests` entries.
- Deliberate recipe deviation retained: `MessengerPanel` owns the realtime session rather than delegating to a separate `MessengerPage` container. The task names `MessengerPanel` as the built component, the scope is a single new folder, and the producer/polling logic lives in the in-scope `realtime.ts` module that feeds the panel.
- Segment 2 — composer retention without an effect: merged `main` carries eslint-plugin-react-hooks 7.1.1, whose `react-hooks/set-state-in-effect` rule rejects resetting `editedAfterFailure` in an effect. Replaced it with derived state keyed to `sendFailure.idempotencyKey` (`editedForFailureKey`); a new failure resets retention by derivation, with no state write in an effect and no cascading render. No suppression was added.
- Segment 2 — SSE boundary validation: added `isIdentifierEvent` in `domain.ts` (published kinds only, `Number.isSafeInteger` and non-negative sequence) and applied it in `parseSseFrame`. A malformed frame cannot trigger a refetch or set a bad `Last-Event-ID`. No duplicate guard was added in `onFrame`: `parseSseFrame` is the only production producer, so a second guard would be dead code with an uncoverable branch.
- Segment 2 — polling fallback lifetime: `open()` now cancels the polling fallback, and an in-flight poll result is discarded while the connection is `streaming` (the poll API has no abort signal, so the status check is the single guard). One `onDataChanged()` per page, not one per event, because a page can hold up to 100 identifiers.
- Segment 2 — tenant-safe connection label: the displayed connection status is derived from a tenant-keyed state object, so switching organization/facility immediately shows `reconnecting` instead of the previous tenant's "Connected".
- Segment 2 — interpolation safety: `messengerTextWithValue` uses a replacer function so a synthetic value containing `$&` or `$'` cannot be interpreted as a replacement pattern.

## Lessons for workers

- Read the generated contract schemas before designing a UI command: `InstantSendRequest` forbids extra fields, so "attachments" must be staged UI until an upload contract exists. Do not invent a wire field to satisfy a visual requirement.
- `EventSource` cannot send `X-Active-Organization` or `Last-Event-ID`; open the SSE endpoint with `fetch` and descriptor headers, and make the abort/reader cleanup observable in tests.
- A `role="status"` connection label changes faster than a synchronous `getByText` assertion; drive the fake stream and assert the `data-connection` attribute with `waitFor`.
- Fixture files are production source for coverage purposes: a `?? ''` fallback in `fixtures.ts` counts as a branch and must be exercised or replaced with a literal.
- Re-run lint after merging `main`: a newer eslint-plugin-react-hooks rule rejected previously-green code. Replace reset-in-effect state with derivation keyed to the triggering identity; never add an eslint disable comment.
- Validate untrusted stream frames once at the parse boundary. A second guard downstream of the only producer is dead code with an uncoverable branch.
- When a poll API cannot be aborted, end its loop with a status/generation guard and cancel its scheduled timer; otherwise an in-flight result restarts polling after the stream has recovered.
- A poll page names changes; refetch once per page. A page of 100 events must not issue 100 refetches.
- `vi.fn(() => value)` infers a zero-argument call tuple; give the mock a parameter when the test asserts `mock.calls[n][0]`. A `describe` callback over 150 lines fails `max-lines-per-function` — split it.
- The staff-web coverage artifact is `coverage/coverage-summary.json` (text + json-summary reporters), not `coverage-final.json`; cite the artifact the shipped config actually writes.
- In this shared worktree another session can reset uncommitted files. Commit scoped, verified changes with explicit pathspecs before writing long notes or waiting on reviewers.
