## Lessons for workers

- In a cloud worker the worktree `opencode.json` is the CI profile under `skip-worktree` (`git ls-files -v opencode.json` → `S`); `worker-check.sh` and `test_check_pack` then fail on "stale". Confirm once, run the remaining gate stages individually, and never regenerate or commit that file.
- `-Pno-security` sets `spotbugs.skip=true`: a `spotbugs:check` under that profile prints `Spotbugs plugin skipped` and is vacuously green. Compile first and pass `-Dspotbugs.skip=false` to get a real finding count.
- For a digest-based reference-conflict test, change a payload field that actually enters the fingerprint (amount, type or reason) and assert the balance/entry count afterwards; the replay check runs before the version check, so a stale version on a reused reference would not prove the conflict.
- A refused posting must be followed by a valid posting that asserts receipt number 1 — that is what proves no receipt was consumed on the failure path.
