## Lessons for workers

- Before calling a feature "Built and verified" in a clause note, check that its table has a production migration in `db/migrations/` and its routes exist in `contracts/openapi*`; a passing integration test that loads a test-scoped migration and a web client that borrows an unrelated header descriptor are strong signals the feature is only partly built.
