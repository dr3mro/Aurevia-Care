## Lessons for workers

- Before writing that a group of tests uses real PostgreSQL, open each test's own harness: clause tests filed under a package directory may use MockMvc with mocked repositories even when their siblings are `@SpringBootTest` with Flyway.
- `scripts/check-docs.py` scans every Markdown file, including historical `docs/pr/reports/` notes. A non-zero exit is not necessarily your change. Run the checker's own `markdown_errors`, link resolution and `mentioned_ids` against just your file, and record both the full run and the targeted result so the integrator can tell pre-existing debt from a new failure.
- When documenting a shared primitive such as `AuditAppender`, count its production importers: a package can own the write API while dozens of other services produce the rows, so "who writes this action" cannot be answered from the owning package alone.
