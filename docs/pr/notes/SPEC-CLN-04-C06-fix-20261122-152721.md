## Lessons for workers

- Before treating a red tooling test as this story's defect, prove provenance: run the exact
  command, then inspect the same path at `origin/main` with `git show` to see whether the
  same code/test exists on clean main. If it does, record it as pre-existing and out of
  scope rather than editing a protected file.
- A test that mocks `Path.is_dir` to `True` can bypass a production `is_dir()` guard and
  reach a filesystem call on a missing path; when you add such a guard, give the test a real
  temporary directory (or make the reader return `False` for a missing path) so the guard is
  not silently defeated.
