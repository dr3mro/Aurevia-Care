## Authorization boundaries and audit events

Every non-bearer request on the browser chain requires an authenticated OIDC session; CSRF is enforced with a per-session token readable only via the non-HTTP-only `XSRF-TOKEN` cookie (an anti-CSRF value, not an auth token — nothing is stored in browser storage). The browser principal's `sub`/`orgs` attributes are resolved through the existing `ClaimsTenantResolver`, so a session cannot widen its organization set and the active tenant still comes only from `X-Active-Organization` intersected with verified claims. The bearer chain is unchanged; CSRF is ignored only for `Authorization: Bearer` requests. No new audit event was added; 401/403 denial semantics are unchanged.

## Migration and rollout considerations

`@ConditionalOnWebApplication(SERVLET)` keeps the non-web startup test green and prevents the browser chain from existing without an HTTP surface; `@Profile("!synthetic-auth")` leaves the synthetic profile untouched. In production all three `AUREVIA_OIDC_*` values must be supplied or startup fails closed; issuer and client secret are never written to the repository. The IdP must publish `/authorize`, `/token` and `/userinfo` beneath the issuer and return `sub` and `orgs` in user-info — confirm with the real IdP before enablement. The host must terminate TLS so the session and XSRF cookies carry `Secure`.

## Lessons for workers

- On a re-dispatched/already-merged story, first run `git merge-base --is-ancestor <merged-pr> HEAD` and `git diff origin/main...HEAD --name-only`; verify and document rather than reimplementing code that is already on `main`.
- When a worker gate is red, reproduce each stage separately and check whether the failing file is in your declared `scope` before touching it. A cross-worker regression on `main` is a hand-off item, not an out-of-scope edit.
- Any new self-registering feature route (`features/*/routes.ts` + `import.meta.glob`) automatically changes `createRoutes()` and will break the hard-coded pattern arrays in `apps/staff-web/src/app/routes.test.tsx` and `tests/app/AppShell.test.tsx`; update both (or make them resilient) in the same change, or the whole frontend gate goes red.
- Regenerate the generated `opencode.json` with `python3 -I scripts/gen-opencode.py` before `worker-check.sh` in a CI-profile worker; because the file is skip-worktree this restores HEAD's local profile without creating a commit (do not edit `scripts/` or the file by hand).
- In this Boot 4.1.2 / Spring Security 7 slice, `AntPathRequestMatcher` no longer exists — use `PathPatternRequestMatcher.pathPattern(HttpMethod.POST, "/logout")` and `ClientRegistration.getProviderDetails().getAuthorizationUri()`.
- With `CookieCsrfTokenRepository`, set `CsrfTokenRequestAttributeHandler.setCsrfRequestAttributeName(null)` or the `XSRF-TOKEN` cookie is never written on a GET and the SPA has no token to send.
- `MockHttpSession` has no `setCreationTime`; override `getCreationTime()` in an anonymous subclass for deterministic session-age tests.
