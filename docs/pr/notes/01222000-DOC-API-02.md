## Lessons for workers

- A red/green `/tmp` scan is the only test-first option for a documentation-only story when `scripts/` is protected; record the scope conflict instead of silently dropping the "add a failing case" clause.
- Strip ID tokens with string-literal masking, but never treat prose apostrophes as Java char literals — that bug hid one token and understated RED. Recompute RED against pristine `HEAD` files with the final detector.
- Ask senior-backend for per-package invariants before writing WHY comments: it caught seven comments that were true when written but stale against current code, including a false claim that a held release can be corrected.
- Check the notes-path convention of both `agent-run.sh` (`.agents/notes/`) and `worker_gate.py` (`docs/pr/notes/`); keeping both copies is cheaper than a gate send-back.
- `git add -N` is required before a `git diff -U0` audit of new files, and a `set -euo pipefail` script stops silently when a grep filter legitimately finds zero bad lines.
