## Data changes

`db/migrations/V86__recurrence_templates.sql` (reserved version V86, `Change: expand`):
three additive tables `recurrence_template`, `appointment_series`, `series_occurrence`.
Each has `organization_id`, a composite PK including it, `created_at`, ENABLE + FORCE RLS and a
policy `USING/WITH CHECK (organization_id = public.app_org())`. Append-only reject-mutation
triggers for `UPDATE`, `DELETE` and `TRUNCATE` cover every role including the migration owner;
SELECT/INSERT are granted only to `aurevia_app` and UPDATE/DELETE/TRUNCATE revoked.
`recurrence_template` enforces exactly one termination via
`CHECK ((occurrence_count IS NULL) <> (end_local_date IS NULL))`. No backfill, no UPDATE of
existing rows, no destructive DDL; brief ACCESS EXCLUSIVE locks are bounded by table creation.
Rollback is a forward-fix migration; no capability is removed. No migration was added or edited
in this pass.

## Lessons for workers

- Do not re-run the slow full `mvn verify` as a worker. The decisive coverage command is the
  targeted unit suite plus `SeriesHttpIntegrationTest`, `AppointmentListIntegrationTest` and
  `it/SchedulingBookingTest`; a class subset leaves the large touched classes below 100%.
- JaCoCo counters print as `missed/covered`: `1/4` is a MISSED branch, not 25% coverage. Parse
  `mi`/`ci`/`mb`/`cb` directly; a `n/a` branch counter means the class has no branches.
- `check-pack.py` / `gen-opencode.py --check` staleness under `skip-worktree` is a known false
  positive in this worker environment. Verify with `git ls-files -v opencode.json` and compare
  worktree/CI/HEAD hashes before treating it as your defect; do not regenerate it locally.
- Integration tests in one class share a database; give each scenario distinct dates or an earlier
  successful series makes later ones fail with `SERIES_CONFLICT`.
- The generic "frontend definition of done" block in the swarm prompt applies only to stories
  that touch a frontend module; for a backend-only scope, state that explicitly rather than
  installing toolchains or fabricating typecheck evidence.
