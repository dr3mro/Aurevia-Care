- `worker-check.sh` can stop at the `opencode.json` CI-profile false positive before its later stages; run `frontend-check.sh`, SpotBugs (compile first), `db/check.sh` and the targeted Maven test individually and record each final line. - Capture the exact Surefire `tests/errors/skipped/failures` attributes from the XML report; a quiet `mvn -q` run prints no test summary on success.
