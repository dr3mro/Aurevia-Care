## Lessons for workers

- When a new controller mapping lands, register it in `contracts/openapi.yaml` or in `contracts/openapi/missing-routes.txt` in the same change. Deferring it only through a `task-requests` block leaves the integrator's `OpenApiRouteParityTest` red and blocks the merge.
- Baseline path variables must be normalized to `{}` and the file kept sorted; the parity test parses `METHOD /path` lines and normalizes both sides before comparing.
- In this cloud worker `opencode.json` is a skip-worktree CI profile: confirm with `git ls-files -v` and `cmp` against `.github/opencode.ci.json` and `git show HEAD:opencode.json`; never regenerate or commit that file.
- Before re-doing a fix, inspect `git log origin/main..HEAD` — earlier workers may already have committed it, and the correct job is independent verification plus a fresh notes file.
- `scripts/check.sh` invokes the full `mvn verify`; under a "never run every integration test" instruction, run its safe sub-checks explicitly instead and leave the full gate to the integrator.
