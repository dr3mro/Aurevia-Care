## Lessons for workers

- In a Vitest test, `readFileSync(new URL(relative, import.meta.url))` fails with
  `The URL must be of scheme file`; use `dirname(fileURLToPath(import.meta.url))`
  plus `resolve` as the neighbouring tests do. The `new URL` form in
  `vite.config.ts` runs in Node and does not transfer to Vitest modules.
- Strict type-aware ESLint flags `String#match` (`prefer-regexp-exec`); write
  `/pattern/.exec(source)` and narrow `match?.[1] ?? ''` under
  `noUncheckedIndexedAccess`.
- A source-inspection clause test must assert wiring into the exported list and
  the runner script, not just token presence; otherwise a config that declares
  a matrix but never runs it still passes.
- Where the swarm cannot run a browser or reach a maintainer, record the
  declaration-versus-execution gap in prose and `task-requests` instead of a
  skipped test; the sibling localization clause note is the precedent.
