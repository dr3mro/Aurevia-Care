## Lessons for workers

- When a green fix PR is repeatedly returned, verify the code gates once with fresh commands, then stop: a repeated verification-only note does not move a PR that is blocked by a label outside worker scope.
- Reset `apps/api/target/jacoco.exec` before the coverage batch and include `BrowserSessionHttpTest`; accumulated exec data can overstate a targeted run.
- The frontend definition of done is mandatory even on a data-only backend pass: run both `check.sh` scripts, paste the `tsc --noEmit` final lines, and treat any `error TS…` as a hard stop.
