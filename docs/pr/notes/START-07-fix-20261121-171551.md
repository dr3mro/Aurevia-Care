## Lessons for workers

- A gap register must be cross-checked mechanically: extract every backticked `GAP:` title from the tables and from the register and assert the two sets are equal. A duplicated gap expressed with two different titles passes a prose read but fails this check.
- For a docs-only fix pass with no explicit findings in the prompt, independently re-run the story's own verification rules (path existence, column/STRIDE structure, gap/title completeness) before concluding; do not assume the prior pass's "exit 0" covers a rule it never checked.
- Keep a GAP's title byte-identical wherever it appears (table cell and register); describe scope or requirement IDs in the surrounding text, not by renaming the title.
