## Lessons for workers

- When a targeted `mvn -Dtest=... test` fails at `testCompile` in a file you did not touch,
  enumerate `grep '^\[ERROR\] .*\.java'` before assuming your change is broken, then prove
  your own file with `javac` against `mvn dependency:build-classpath` and run it with the
  direct `mvn surefire:test` goal (which skips the lifecycle's `testCompile`). That gives
  green, reproducible evidence for your file without editing out-of-scope code.
- Parallel feature merges can break a base between a worker's green run and the integrator
  gate: a record gaining a component (BUILD-16 `ExportRecord.provenance`) silently breaks an
  older test written against the previous arity (BUILD-42 `OffboardingCommandTest`). Re-run
  after every `git merge origin/main` and record the base SHA with the evidence.
- For a clause with no HTTP surface, enabled domain-level tests plus one
  `@Disabled("GAP: ...")` HTTP test and a "Partly proven" clause document is the correct,
  green-preserving shape under this story; verify the absence of a controller by grep rather
  than assuming it from an earlier note.
