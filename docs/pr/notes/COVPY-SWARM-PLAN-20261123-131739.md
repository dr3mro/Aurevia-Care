## Lessons for workers

- Measure a shared script with `coverage json` filtered to your assigned line range: the whole-file
  percentage hides which part owns a gap, and sibling commits can move the live numbers.
- If a branch sits after an exhaustive `if/elif` over a closed return set, it is dead code. Do not
  patch the helper to return an impossible value just to colour the arc; delete the branch instead.
  Three reviewers independently rejected the fabricated-value approach here.
- A `task-requests` scope cannot name `scripts/*.py`, a workflow or an agent file. When a repair
  directive explicitly authorizes the production edit, apply the smallest fix and re-run the
  reviewers; otherwise write the precise change in Findings for a person instead of filing an
  unusable request.
- `coverage` rewrites the tracked `.coverage` file; always set `COVERAGE_FILE` to a temporary path
  and confirm `git status` shows only the scope file before committing.
