## Findings

- **Requirement mismatch (documented, not a blocker).** The task metadata names CLN-07, but the chart package is CLN-03. Evidence: `ChartController` and `ChartService` Javadoc, `db/migrations/V13__longitudinal_chart.sql` header and five clause tests say CLN-03; `apps/api/src/main/java/com/aurevia/documents/PdfRenderer.java` Javadoc and `SigningDiffersPatientReleasePdfRenderingTest` place CLN-07 in `com.aurevia.documents`. The guide states both facts and makes no CLN-07 delivery claim. This does not change the task outcome (write a truthful module guide), so it is a finding rather than a stop.
- **Pre-existing red docs gate (out of scope).** `python3 -I scripts/check-docs.py` failed before this task with 151 lines of broken links, unknown IDs and table-structure faults in committed files under `docs/pr/reports/` and a few older notes. The same 151 lines remain and no new line was added. Fixing them needs its own task; this worker must not edit those files.
- **Pre-existing disabled test.** `CaptureChiefConcernHistoryExamAssessmentDiagnosesTest.capturesChiefConcernHistoryExamAssessmentAndPlanAsChartEntries` is `@Disabled` with an explicit gap reason: SOAP narrative fields live in CLN-04 templates and note revisions, not as chart entry types. The guide records this gap. This worker did not add or enable a skipped test.
- **Test-folder scope surprise.** The `apps/api/src/test/java/com/aurevia/chart/clauses` folder holds 22 clause tests, but only five hit a `/api/v1/chart` route. The other 17 cover other packages and are not evidence for this guide.

## Lessons for workers

- Before editing Markdown in this snapshot, save the `python3 -I scripts/check-docs.py` output as a baseline and diff after: the gate is already red from other workers' committed PR reports, so a bare exit 1 is not your defect.
- Check that a story's requirement ID matches the package named in its title; when they disagree, cite the code and migrations in the guide and record the mismatch in notes instead of guessing or claiming delivery.
- Follow `docs/reference/modules/api-api.md` for module-guide structure, keep every table row at the header's pipe count, and link to source rather than copying implementation.
