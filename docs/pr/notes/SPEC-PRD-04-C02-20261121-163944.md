## Findings

- No code, workflow, infrastructure file, contract or document implements
  claims adjudication, a payer/insurance integration, card data storage or an
  accounting/general ledger. The four-term sweep found only hash/hex false
  positives (recorded above).
- Naming traps ruled out: `web/ClaimsTenantResolver` handles JWT token claims
  (`sub`/`orgs`/`iss`), not insurance claims; `FinanceContract.LedgerEntry` is
  an append-only self-pay payment/refund/credit entry, and
  `IdempotencyLedger`/`EvidenceLedger`/`ConformanceLedger` are technical
  records — none is a double-entry accounting ledger.
- The finance module is deliberately scope-limited: `FinanceContract` Javadoc
  says item labels are non-clinical and no clinical table is joined;
  `V45__finance.sql` stores only finance columns and inherits forced RLS;
  `FinanceFlowTest.reconciliationIsFinanceOnlyAndStableAcrossReplay` asserts a
  synthetic clinical marker never appears in finance responses.
- Real gap: there is no automated, build-failing guard that asserts the absence
  of the four capabilities. The note proposes one bounded follow-up task (a
  static/architecture check plus test) but does not create it or edit the
  maintainer-owned `scripts/`/workflow paths.
- `docs/spec/clauses/` did not exist on this branch; the scoped note created
  its `product/` directory as part of writing the one file in scope.
- Independent senior-backend review agreed with every conclusion and with the
  `Not built` status; the only suggested correction (grep self-match) had
  already been applied before the review arrived, and the re-run confirmed it.

## Lessons for workers

For a negative or boundary clause, first sweep the whole repository for the
prohibited terms, then open every similarly named file before concluding —
"claims" can mean JWT claims and "ledger" can mean an append-only technical log.
Exclude the evidence note itself from the final sweep: its own wording otherwise
produces matches that look like violations. Keep the Status honest when nothing
is built and there is no automated guard: "Not built" is the correct state for
a prohibition, and "Built and verified" would overclaim verification.
