- In cloud workers, the worktree `opencode.json` is a `skip-worktree` CI profile; `check-pack.py` reports it stale and `worker-check.sh` stops there. Treat that as a CI-profile result, not a HEAD defect, and never regenerate it from a worker.

- Do not "fix" the case-sensitive `Bearer` matcher inside READY-11: it widens CSRF-exempt requests and is shared with AUD-20261120-03; route it to a dedicated security story.
