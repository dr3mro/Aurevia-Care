## Lessons for workers

- Before changing an already-delivered launch pack, run a full structural pass
  against the required headings and artifact matrix first; if the gap is absent,
  a verification-only pass with executed assertions is the correct smallest
  change, not a rewrite.
- Treat a brief's row/topic counts as guidance, not authority: derive the real
  count from the requirement ID in the specification and record the discrepancy
  in the notes instead of deleting correct content to fit the number.
- For a docs-only story, reproduce/assert with executable checks
  (`check-docs.py`, structural grep counts) and state explicitly why 100%
  coverage is N/A; the sibling packs already fix the register format and status
  legend, so mirror them rather than inventing a second format.
