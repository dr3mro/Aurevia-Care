## Lessons for workers

- `scripts/check-docs.py` resolves a relative Markdown link from the file's own
  directory. From `docs/operations/exercises/`, root files need `../../../`,
  sibling `docs/operations/<area>` files need `../<area>/`, and `docs/WORKFLOW.md`
  needs `../../WORKFLOW.md`.
- When a maintainer renames a folder, previously green docs can go red with
  broken links; re-run `python3 -I scripts/check-docs.py` at the start of a fix
  pass and grep for the old path fragment across the scope to catch both links
  and inline command citations.
- Before citing a command in operations documentation, confirm the file exists
  and run it on synthetic fixtures. A plausible-looking command at a stale path
  is worse than an honest `NOT YET IN PLACE:` marker.
- The offline evidence evaluators judge declarations only. Never phrase a
  synthetic rehearsal as proof that a restore, alert, revocation or human
  approval occurred.
