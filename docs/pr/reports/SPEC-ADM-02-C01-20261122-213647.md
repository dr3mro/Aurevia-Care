# SPEC-ADM-02-C01 — Spec ADM-02 clause 1 (API test): Provide operational queues

## Summary

Test-only clause evidence for ADM-02 clause 1. Two of the seven required queues exist today
as pure domain projections; the other five, the HTTP aggregate, the durable store and the
operator/audit command boundary do not. This change adds one active unit test class with
five asserting tests for the two built projections, plus the four-heading clause doc that
records the unbuilt remainder under `## Gap`. No production code, existing test, contract or
migration is changed.

A quality-gate repair (attempt 1 of 2) removed an initially added `@Disabled("GAP: ...")`
HTTP test: a skipped test can never run, so it was dead code, not evidence. Its assertions
and the missing behavior now live only in the clause doc's `## Gap` and in the follow-up
task request below. This is a deliberate scope change from the task's original step 3, made
knowingly because the gate forbids adding a skipped test and the asserted aggregate cannot
be wired inside a test-only story (it needs an owner-approved migration version, stores, a
controller, an OpenAPI entry and five new projections).

## Lessons for workers

- A "complete but `@Disabled`" spec-clause test provides no evidence and fails
  `check-constraints.py`. Record the missing behavior in the clause doc's Gap and a
  `task-requests` follow-up instead of adding a skipped test you cannot enable.
- Before citing a reserved migration version from an older note, re-check `db/migrations/`
  and `tasks/*reserved:*`; V91 → V93 guidance went stale twice while this story was written.
- Keep the class free of `@SpringBootTest` and `jdbc:postgresql` when only two pure domain
  projections are under test; that keeps `test_fast_tier.py` satisfied without an
  integration tag and lets the targeted `-Dtest=...` command run without a database.
- In a cloud worker, `git ls-files -v opencode.json` returning `S` explains all
  `test_check_pack` and `check-pack` failures; confirm once and run the remaining stages
  individually instead of re-diagnosing.
