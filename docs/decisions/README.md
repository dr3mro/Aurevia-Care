# Decision records

Record each consequential architecture or process decision in a short file named `NNNN-title.md`, copied from [template.md](template.md). Link the requirement IDs it serves and the evidence that supports it. Supersede a record with a new one instead of rewriting history. MEMORY.md keeps only a one-line pointer.

Before writing a new record, match the convention already in this directory: continue the `NNNN` sequence and reuse the headings in [template.md](template.md). If an existing record conflicts with the template, surface the conflict in the new record instead of starting a second scheme. Write a record when the reasoning would be expensive to reverse or would otherwise be explained repeatedly; do not document obvious code.
