## Skill registry

Native frontmatter supports only `name`, `description` and `metadata.namespace`, so routing metadata must be external. Proposed `.opencode/config/skill-registry.json`, generated by `scripts/gen-skill-registry.py` and validated in `check-pack.py`, with fields: `id`, `path`, `description`, `system`, `content_sha256`, `purpose`, `domains`, `task_categories`, `file_patterns`, mandatory and optional dependencies, compatible agents, byte-cost, capabilities, risk class and references. `run-workflow` is excluded as a system-namespace skill.

Routing must reuse `scripts/route-task.py` (`pick`, `ALWAYS`, `delivery`) rather than duplicating `ROUTES`. Fix first: `existing()` builds `aurevia-<name>.md` agent paths, but real agent files are bare (`.opencode/agents/context-optimizer.md`). Dependency closure must detect missing ids, cycles, duplicates and incompatible requirements, and fail closed when a mandatory activation fails.
