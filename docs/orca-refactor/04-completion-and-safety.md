## Healthcare safety verification policy

- **P0 Evidence standard.** A behavior is verified only when a real entry point reaches it, a `Jdbc*` store in `src/main` backs it with a migration applying RLS and FORCE RLS, a real-caller or HTTP integration test exercises it, and a named test method exists. Unit coverage alone is not completion. Record human approvals separately.
- **P1 Patient identification (IAM-03/04/05).** Issuer-scoped MRN; two identifiers at high-risk transitions; shared demographics never link records; unlink ends access immediately; consolidation locks both records, requires a second reviewer and rolls back on ambiguity. Negatives: wrong identifier, stale version, missing reviewer, cross-tenant duplicate. Evidence: `ConsolidationServiceTest`, `ConsolidationIsolationTest`, `IdentityProofingIsolationTest`. Gaps: MRN-search endpoint, rate-limit test, printed identity validation.
- **P2 Tenant isolation (ARC-02, IAM-01).** Tenant from verified token and active membership; forced RLS; fail closed on missing context; identical local IDs stay isolated across API, search, files, workers and exports. Evidence: `IsolationAcrossSurfacesTest`. Gaps: HTTP cross-tenant attachment download with a verified grant, forced-RLS grant drift.
- **P3 RBAC (IAM-01/02, ARC-03/04).** Registered command allowlist, fresh roles per protected request, permission changes effective next request, clinical users decide care. Negatives: wrong role, unauthenticated, unregistered command, expired membership, admin release decision. Evidence: `CommandAuthorizationTest`, `AuditNegativePathsTest`, allergy-check negative tests. Gaps: token audience/expiry negatives, synthetic-auth profile must never be enabled in production.
- **P4 Audit (OPS-02, ARC-04).** Actor from transaction GUC; append-only hash chain; audit reads audited; disclosures recorded; no PHI in logs or URLs. Evidence: `AuditServiceTest`, `AuditQueryTest`, `AuditNegativePathsTest`, V3 `audit_verify_chain`. Gaps: scheduled chain alerting, tamper-resistant replica, regulatory sign-off.
- **P5 Medication and allergy (RX-01/02).** Only verified substance identity or approved cross-reactivity may match; unknown means unresolved, never "no conflict"; override reason required on conflict; stable submission ID; ambiguous transmission is not retried before partner status is verified. Evidence: `AllergyCheckerTest`, `CheckAgainstVerifiedAllergyIngredientsSurfaceUnknownsTest`. Medication–medication interaction is not a V1 requirement.
- **P6 Specimen identity (LAB-01/02, XCH-04).** Accession unique per issuer; patient and accession matched at collection and receipt; recollection mints a distinct linked ID; conflicting identifiers diverted. Evidence: `SpecimenRejectionServiceTest`, `SpecimenRejectionIntegrationTest`, `UnmatchedReportReviewAcceptanceTest`. Gap: real-partner boundary test.
- **P7 Critical results (XCH-05, ADM-01).** Named owner, due time and escalation version; primary channel before deadline, approved backup after; delivery and patient release never count as acknowledgment; correction reopens review; UI banner anchored to clinical-review state. Evidence: `CriticalResultEscalationAcceptanceTest`, `CriticalResultFlowTest`, `FinalReportReplayIntegrityAcceptanceTest`. Gaps: read-back API negative, rosters and drills, human screen-reader pass.
- **P8 Radiology association (RAD-01, XCH-04).** Verify patient, accession, role, version and tenant before setting Study Instance UID; mismatch mutates nothing and opens one review; signed interpretation immutable; addendum links to prior interpretation. Evidence: `RadiologyWrongPatientStudyRefusedAcceptanceTest`, `ImagingControllerHttpTest`. Gaps: interpreter privileges, physical partner delivery.
- **P9 Arabic/English RTL and accessibility (UX-01).** `dir`/`lang` per run, `<bdi>` isolation, logical properties, numerals and units in one LTR run, no mirrored clinical glyphs, UTC instants with IANA zone, no clinical detail in notifications. Evidence: `I18nProvider.direction.test.tsx`, `format.localization.test.ts`, `logicalLayout.test.ts`, patient design and notification payload tests. Gaps: numbering-system and measurement-spacing defects, WCAG audit, VoiceOver/TalkBack and Arabic clinician review.
- **P10 Defect and sign-off handling.** Reproducible failures become `BUGS.md` entries with source type and retest status; environmental blockers stay in `tasks/`. Open entries affecting this policy: ORCA-REVIEWER-PROVENANCE, OPS-GLOBAL-WORKER-CAPACITY, DELIVERY-1491, DELIVERY-1983, QA-SOURCE-05/06. Human G0–G5 acceptance cannot be moved to verified by a repository check.
