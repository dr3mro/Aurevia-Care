# Module guide: API foundation (`com.aurevia.api`)

The `api` package is the cross-cutting HTTP foundation shared by the whole backend: it renders every protected route's machine-readable error body, parses version and precondition headers, and provides bounded paging, cursor, digest, idempotency and command-authorization primitives. It also owns the generated command contract — a Java command catalog plus a deterministic generator for the OpenAPI document, typed TypeScript client and checksum manifest — so the wire contract and the server gate share one source of truth ([ApiErrorHandler.java](../../../apps/api/src/main/java/com/aurevia/api/ApiErrorHandler.java), [CommandCatalog.java](../../../apps/api/src/main/java/com/aurevia/api/authorization/CommandCatalog.java)).

Primary requirement: WEB-04 (machine-readable error bodies that reveal no stack trace, SQL, other tenant or internal class name); the command, authorization and idempotency primitives additionally serve PRD-06, IAM-01, IAM-02, ARC-02, ARC-03, ARC-04, ARC-05 and OPS-02 ([PROJECT_V1_SPEC.md](../../../.opencode/config/PROJECT_V1_SPEC.md), [contracts/openapi/README.md](../../../contracts/openapi/README.md)).

## Entry points

This package declares no `@RestController`, no scheduled job and no event handler. Its entry points are library calls made by other packages, one Spring framework advice, and one build-time CLI. The "caller" column therefore names the actor or layer that may invoke each one; business roles are re-derived server-side and are never accepted from the client.

| Entry point | Kind | Who may call it / when | Source |
|---|---|---|---|
| `ApiErrorHandler` (`@RestControllerAdvice`) | Framework exception handler | Spring MVC, for any uncaught `ApiException`, `DuplicateKeyException`, `IllegalArgumentException` or `IllegalStateException` on any route; no business role selects it | [ApiErrorHandler.java](../../../apps/api/src/main/java/com/aurevia/api/ApiErrorHandler.java) |
| `ApiException(status, code, message)` | Thrown domain/web failure | Any service or controller that must fail with an explicit status and stable code; 113 production call sites outside this package | [ApiException.java](../../../apps/api/src/main/java/com/aurevia/api/ApiException.java) |
| `IfMatch.parse(header)` | Header parser | Controllers performing an irreversible/versioned POST; accepts weak `W/"3"` and quoted `"3"` validators; 21 production call sites | [IfMatch.java](../../../apps/api/src/main/java/com/aurevia/api/IfMatch.java) |
| `SqlFailureTranslator.translate(exception)` | Failure mapper | Services translating `DataIntegrityViolationException` into a stable API error (3 production call sites) | [SqlFailureTranslator.java](../../../apps/api/src/main/java/com/aurevia/api/SqlFailureTranslator.java) |
| `ApiVersion.from(header)` | Header parser | Web layer selecting the only routed version, `/api/v1`; absent/blank defaults to V1 | [ApiVersion.java](../../../apps/api/src/main/java/com/aurevia/api/contract/ApiVersion.java) |
| `IdempotencyKey.parse` / `new IdempotencyKey` | Wire primitive | Owning services parsing `Idempotency-Key` (428 absent, 422 malformed) | [IdempotencyKey.java](../../../apps/api/src/main/java/com/aurevia/api/contract/IdempotencyKey.java) |
| `RequestDigest.of` / `canonicalBytes` | Wire primitive | Owning services fingerprinting tenant + subject + command + payload; digest is server-computed, never from the client | [RequestDigest.java](../../../apps/api/src/main/java/com/aurevia/api/contract/RequestDigest.java) |
| `Cursor.encode` / `Cursor.decode` / `PageRequest.parse` | Wire primitive | List endpoints issuing and validating tenant-bound, stable-ordering cursors and a page limit (1–200, default 50) | [Cursor.java](../../../apps/api/src/main/java/com/aurevia/api/contract/Cursor.java), [PageRequest.java](../../../apps/api/src/main/java/com/aurevia/api/contract/PageRequest.java) |
| `IdempotencyLedger.claim/complete/fail/expire` | Contract + synthetic implementation | Owning services implementing retry/replay semantics; only the in-memory reference implementation lives here | [IdempotencyLedger.java](../../../apps/api/src/main/java/com/aurevia/api/contract/IdempotencyLedger.java) |
| `CommandAuthorization.authorize(request, identity)` | Server authorization gate | Caller supplies a server-derived `ServerIdentity`; membership and roles are re-resolved each call and the action is decided by exactly the owning policy. Client-claimed role/permission fields are inert | [CommandAuthorization.java](../../../apps/api/src/main/java/com/aurevia/api/authorization/CommandAuthorization.java) |
| `CommandCatalog.synthetic` / `require` / `find` | Command registry | 24 explicit POST commands, each bound to one action and one owning policy; a command absent from the catalog cannot be authorized | [CommandCatalog.java](../../../apps/api/src/main/java/com/aurevia/api/authorization/CommandCatalog.java) |
| `CommandClientGenerator.main` | Build-time CLI (not an HTTP route) | Developer/build job: `CommandClientGenerator <dir>` writes artifacts, `--check <dir>` fails on drift from the catalog | [CommandClientGenerator.java](../../../apps/api/src/main/java/com/aurevia/api/authorization/CommandClientGenerator.java), [contracts/openapi/README.md](../../../contracts/openapi/README.md) |

The generated client function for each command has the shape `fn(ctx, [path parameters,] idempotencyKey, ifMatch, body, transport)` — path-template parameters are inserted between `ctx` and `idempotencyKey` — and **no role, permission or scope argument**; `ctx` describes the caller for header construction only. Role decisions live in the owning domain policies wired by `CommandAuthorization.synthetic` (`ActionPolicy`, `WorklistPolicy`, `LabActionPolicy`, `SpecialtyActions`, `Xch03ActionPolicy`, `ReleaseActionPolicy`, `CriticalActions`, `FinanceActions`, `InstructionFactActions`) ([CommandAuthorization.java](../../../apps/api/src/main/java/com/aurevia/api/authorization/CommandAuthorization.java), [CommandClientGenerator.java](../../../apps/api/src/main/java/com/aurevia/api/authorization/CommandClientGenerator.java)).

## Tables it reads and writes

The package contains no JDBC repository and reads or writes **no database table directly**. Its database relationship is indirect:

| Table / schema object | Relationship | Source |
|---|---|---|
| `public.audit_event` | The OPS-02 durable sink is *supplied by the caller* in the owning service's transaction. `CommandAuthorization.Decision` carries the tenant, subject, correlation id, action, roles, reason code and clock instant that such a sink records; the table is created in V1, and the append-only hash-chain functions and triggers that protect it are defined in V3 | [CommandAuthorization.java](../../../apps/api/src/main/java/com/aurevia/api/authorization/CommandAuthorization.java), [V1__tenant_schema.sql](../../../db/migrations/V1__tenant_schema.sql), [V3__audit_chain.sql](../../../db/migrations/V3__audit_chain.sql) |
| Tenant context fields (`organization_id`, subject, `correlation_id`) | Read from `TenantContext.current()`, never inferred from a request body; `ApiErrorHandler` echoes the correlation id in every error body and uses `unassigned` before a context is bound | [ApiErrorHandler.java](../../../apps/api/src/main/java/com/aurevia/api/ApiErrorHandler.java), [TenantContext.java](../../../apps/api/src/main/java/com/aurevia/tenant/TenantContext.java) |
| Idempotency state | No table exists in this package: `InMemoryIdempotencyLedger` is a process-local `ConcurrentHashMap`. Durable business uniqueness (ARC-04) belongs to the owning module's transactional constraint | [IdempotencyLedger.java](../../../apps/api/src/main/java/com/aurevia/api/contract/IdempotencyLedger.java), [contracts/openapi/README.md](../../../contracts/openapi/README.md) |
| Reserved migration `V57` | Deliberately unused by this slice; the generated command contract adds no table or migration | [contracts/openapi/README.md](../../../contracts/openapi/README.md) |

## Events published or consumed

**None.** No class in the package publishes or consumes a domain event, and no `@EventListener`, message sender or outbox call appears in its sources. `CommandAuthorization.Decision` is a synchronous audit *outcome* passed to a `DecisionSink`, not a durable event; the in-memory sink is a synthetic reference ledger ([CommandAuthorization.java](../../../apps/api/src/main/java/com/aurevia/api/authorization/CommandAuthorization.java), [InMemoryDecisionSink.java](../../../apps/api/src/main/java/com/aurevia/api/authorization/InMemoryDecisionSink.java)). Durable event outbox delivery is the separate `events` package and its X-02 contract ([contracts/events/README.md](../../../contracts/events/README.md)).

## Things to know

- **The gate is not wired into running controllers.** `CommandAuthorization`, `CommandCatalog`, `CommandClientGenerator`, `InMemoryDecisionSink` and the `contract` primitives (other than `ApiException`, `IfMatch`, `SqlFailureTranslator`) have no production callers outside this package and its tests. The drift gate proves catalog ↔ client ↔ manifest consistency, not that every deployed `@PostMapping` calls the gate; wiring and a POST-mapping ↔ catalog parity test are follow-on work ([contracts/openapi/README.md](../../../contracts/openapi/README.md)).
- **Both ledger implementations are synthetic.** `InMemoryDecisionSink` and `InMemoryIdempotencyLedger` are process-local and non-durable; a production OPS-02 sink and atomic state/event/audit idempotency must be supplied transactionally by the owning service ([InMemoryDecisionSink.java](../../../apps/api/src/main/java/com/aurevia/api/authorization/InMemoryDecisionSink.java), [IdempotencyLedger.java](../../../apps/api/src/main/java/com/aurevia/api/contract/IdempotencyLedger.java)).
- **The gate is deliberately coarse.** It does not replace the owning service's object authorization, compare-and-set revision check or human clinical attestation; PRD-06 clinical decisions remain human acts ([CommandAuthorization.java](../../../apps/api/src/main/java/com/aurevia/api/authorization/CommandAuthorization.java), [contracts/openapi/README.md](../../../contracts/openapi/README.md)).
- **Two families of error codes coexist.** `ApiErrorCode` owns the version/idempotency/cursor/paging codes, while `IfMatch` (`PRECONDITION_REQUIRED`, `INVALID_IF_MATCH`), `ApiErrorHandler` (`CONFLICT`, `INVALID_INPUT`, `INTERNAL_ERROR`), `RequestDigest` (a 500 `INTERNAL_ERROR` when SHA-256 is unavailable) and the tenant interceptor (`INVALID_CORRELATION_ID`) own others in the same `{code, message, correlationId}` body ([ApiErrorCode.java](../../../apps/api/src/main/java/com/aurevia/api/contract/ApiErrorCode.java), [ApiErrorHandler.java](../../../apps/api/src/main/java/com/aurevia/api/ApiErrorHandler.java), [RequestDigest.java](../../../apps/api/src/main/java/com/aurevia/api/contract/RequestDigest.java)).
- **Concealment and canonical form are intentional.** A foreign-tenant cursor yields the same `INVALID_CURSOR` 422 as a malformed one (no tenant-existence oracle); a foreign-key violation maps to a generic 404 under forced RLS; canonical digests use 4-byte length-prefixed UTF-8 so mixed-script payloads cannot collide by delimiter movement ([Cursor.java](../../../apps/api/src/main/java/com/aurevia/api/contract/Cursor.java), [SqlFailureTranslator.java](../../../apps/api/src/main/java/com/aurevia/api/SqlFailureTranslator.java), [ByteParts.java](../../../apps/api/src/main/java/com/aurevia/api/contract/ByteParts.java)).
- **WEB-04 is only partly satisfied here.** This package provides the machine-readable error body and bounded input parsing (page limit, cursor/key length, header preconditions). Rate limiting with `429`/`Retry-After`, the origin allowlist and request header/body/time caps are not implemented in this package and remain infrastructure/owning-module work ([PROJECT_V1_SPEC.md](../../../.opencode/config/PROJECT_V1_SPEC.md), [contracts/openapi/README.md](../../../contracts/openapi/README.md)).
- **Generated artifacts must stay in sync.** `openapi.yaml`, `client.ts` and `manifest.json` are checked in under `contracts/openapi/generated`; a catalog change that is not regenerated fails both `CommandClientGenerator --check` and the Java drift test ([contracts/openapi/README.md](../../../contracts/openapi/README.md)).
