- Date: 2026-11-21

- Also referenced: IAM-02, IAM-05, IAM-06, ARC-01, ARC-03, ARC-04, ARC-05, ARC-06, ARC-07, OPS-01, OPS-05, OPS-06, OPS-07, WEB-01, WEB-02, WEB-03, WEB-05, WEB-06, WEB-12, PAT-01, PAT-02, PAT-03, MSG-03, MSG-05, MSG-07, XCH-01, XCH-05, XCH-06
- Risk class: cross-boundary with safety-critical controls (patient identity, permissions, audit, disclosure)

## Scope and evidence basis

This is a static model of the code in this checkout (HEAD `d12d72c`). Every control below is tied to a real source file or test that was read during this task; no control is claimed from the specification alone. Every missing control is written as a `GAP:` line with a suggested task title and is collected in the gap register at the end. No live deployment, WAF, identity provider, penetration test, human participant or real patient data was involved — this is simulated, synthetic review evidence, not production assurance.

Threats use STRIDE: **S**poofing, **T**ampering, **R**epudiation, **I**nformation disclosure, **D**enial of service, **E**levation of privilege. "Attacker" means an actor the design must not trust with the asset; it is not an accusation about a role.

The tables are diagram-free by design. Paths are repository-relative and written as code (not Markdown links) so they resolve from any documentation viewer. A file named without a path is a real file in this checkout; full paths are supplied wherever a bare name would be ambiguous. Method names in the entry-point trace refer to the class named immediately before them.
