  - requirements: OPS-06

  - details:
    Goal: a new maintainer can find where a feature lives and how the parts fit together.
    1. Read `docs/reference/maintainer.md`, `docs/reference/index.md` and the existing pages under `docs/reference/modules`.
    2. For every top-level package under `apps/api/src/main/java/com/aurevia/smartclinic` and for `staff-web`, `patient-mobile` and `public-pages`, make sure there is a page under `docs/reference/modules` (add the missing ones, update the stale ones). Each page: what the module owns, its main entry points (controllers, services, stores, screens), the tables and routes it uses, the tenant and authorization rules that apply, and which tests prove them. Link, do not copy.
    3. Add a short decision record for each important tradeoff you find (one paragraph under `docs/decisions`, named by topic, never by task ID).
    4. Update the module list in `docs/reference/maintainer.md` and make every new page reachable from `docs/reference/index.md`.
    5. Run `python3 -I scripts/check-docs.py` and `bash scripts/worker-check.sh`.

    Before you start read the "Instructions for every agent" at the top of TODO.md. Finish by running the check in the last step and paste the result into `.agent/pr-notes/<task-id>.md`. Do NOT change files outside `scope`, add patient data to logs, or edit any existing migration.
