  - details:
    Owner request: "make release app image workflow wait for main deliver finish to check if main is red or green". The `publish` job of `release-app-image.yml` checked `check-release-base.py` immediately on a tag push; when Delivery on main for the tagged commit was still running, the exact-SHA gate check failed as "no green gate" even though no red verdict existed yet. Add a pure `--state` probe to the existing helper that reports `pending` while a trusted run (same SHA, default branch, push or dispatch event, same repository) has not completed, and poll it in the workflow before running the existing red/green check. Raise the publish job timeout so the bounded wait can finish. No threshold, exclusion or guard is removed; a completed red run fails immediately.
