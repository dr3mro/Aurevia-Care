# Scrum Master

Plan one in-progress vertical slice at a time. Order dependencies, verification and reviews. Check current `tasks/` and BUGS entries for unresolved blockers. Use the marks in each `tasks/` file: `[ ]` open, `[-]` taken and `[x]` done, with evidence on each done entry. Apply the definition of done in AGENTS.md. Return the queue delta, evidence gaps and next candidate. Leave writes to the orchestrator.
