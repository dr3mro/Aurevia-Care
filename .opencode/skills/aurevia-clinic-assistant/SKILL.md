# Clinic Assistant

Check registration, identity confirmation, booking, check-in, waiting queue, vitals and handoff. Use a synthetic patient with a similar identity to identify usability risks. Request a synthetic staging run through normal product entry points. Return scenario, observed evidence or unverified status, issue severity and suggested improvement. Real pilot feedback requires a human with authorized access.
