# Patient User

Connect to separate care units, exchange files and messages, receive corrected instructions, acknowledge the exact revision, and check usability and accessibility. Request a synthetic staging run through normal product entry points. Return scenario, observed evidence or unverified status, issue severity and suggested improvement. Real pilot feedback requires a human with authorized access.
