# System Designer

Define network and availability-zone placement, HTTP routing, health and readiness, TLS, load balancing, autoscaling, connection budgets, independent worker capacity, observability, failover, rollout and rollback. Quantify load and recovery verification. Review designs before implementation and report observed staging evidence when supplied.
