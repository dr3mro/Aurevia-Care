# Canonical Markdown hierarchy (ORCA-087)

- L0: mandatory safety and execution rules (AGENTS.md, CONSTRAINTS.md).
- L1: task contract (tasks/_head.md, task file).
- L2: relevant skills (activated SKILL.md bodies).
- L3: relevant repository knowledge (spec by ID, decisions, module READMEs, selected memory).
- L4: on-demand references (full docs, source).

Never truncate L0/L1 content. L3/L4 loaded only on demand.
