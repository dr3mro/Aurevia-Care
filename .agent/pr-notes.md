## Decisions / notes for the integrator

- **No source change this attempt.** The implementation, 9 test files and V20 were already present at the shard base; this worker's contribution is verification evidence and this PR description.
- **"Revision" interpretation**: XCH-02's "timestamp and revision" is implemented as the optimistic work-item version the clinician reviewed (the `If-Match` version at acknowledgment), not the immutable order-snapshot revision from XCH-01. The slice is deliberately self-contained (no V19 dependency); the choice is documented in `ExchangeStateMachine`/V20 comments. Confirm with Product/Architecture before G2 sign-off if a different meaning was intended; it does not block this story.
- **Idempotency keys** are absent on transition routes by documented project deferral; a retry after a lost response gets 412 from the version CAS rather than the original outcome. This diverges from the literal ARC-04 sample contract but is outside XCH-02.
- Verify on the merge result: the `@Tag("integration")` `ExchangeTaskIsolationTest` (real PostgreSQL: V20 guard, forced RLS, actor derivation, two-tenant concealment, ledger immutability), JaCoCo 100% at `verify`, OWASP/SpotBugs and `scripts/check.sh`. These are the integrator's gates, not claims of this worker.
- Evidence sources: executed tool commands for all gate results; simulated specialists for review findings; **no** simulated-user, clinician or human-participant evidence was available for this backend slice.
