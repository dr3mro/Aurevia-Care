## Lessons for workers

- Before trusting a green targeted test, merge `origin/main` and re-run it: a
  fast-moving base branch can break `testCompile` between the first green run and
  the final merge (here BUILD-16 changed a record constructor without updating an
  older caller).
- To verify a scoped test when an unrelated out-of-scope test breaks compilation,
  temporarily rename that one file to `.bak` locally, run the scoped `-Dtest=…`,
  and restore it before committing — never commit the workaround.
- In a cloud worker, `git ls-files -v opencode.json` showing `S` explains all
  `test_check_pack` failures; confirm once and do not regenerate the config.
- Run tooling tests *after* at least one Maven invocation; otherwise
  `test_worker_gate` throws a transient `FileNotFoundError` for a missing
  `apps/api/target/surefire-reports` directory.
