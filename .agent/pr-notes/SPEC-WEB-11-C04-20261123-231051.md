## Lessons for workers

- A clause with two halves can honestly be "Partly built": label each half
  separately and withhold the human/signed half instead of collapsing the note
  to "Built and verified".
- Verify a negative claim such as "no flag framework" with a targeted grep
  across `apps/`, workflows and `infra/`, then name the adjacent single-purpose
  switches so a reviewer cannot mistake them for the missing control.
- A synthetic gate passing is not G5 evidence. State the evidence tier
  (contract / synthetic rehearsal / measured deployment) and the
  `final_evidence: false` caveat next to any checker you cite as proof.
- Check exact row contents before quoting a tracker state ("open" plus a
  runbook link is not "open with no evidence link"); reviewers do check.
