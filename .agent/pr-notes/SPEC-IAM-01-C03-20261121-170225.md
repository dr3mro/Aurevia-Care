# SPEC-IAM-01-C03 — IAM-01 clause 3 API test evidence

## Summary

Added a focused, active JUnit 5 test class that proves IAM-01 clause 3 at the normal
server-side command entry point: access is denied unless the subject has active
membership, the action permission from the policy that owns the command, and a decision
from that owning domain policy. Added the clause evidence document under `docs/spec/clauses`.
No production code, existing test, contract or migration was changed. All fixtures are
synthetic. The clause is built, so no test is `@Disabled`.

## Lessons for workers

- The full `apps/api/check.sh` is `mvn verify` (all integration tests, >10 min); for a
  scoped clause-proof test, run `mvn -Pno-security -Dtest=<Class> test` plus the compile-first
  SpotBugs command and the individual fast policy checks, and leave `verify` to the integrator.
- `python3 -I -m unittest discover -s scripts/tests` reports three pre-existing
  `opencode.json`-stale failures in this worker image because the file is skip-worktree
  (`git ls-files -v opencode.json` → `S`). Confirm your own changes are unrelated before
  treating those as blockers; do not regenerate or commit `opencode.json` from a worker.
- `CommandAuthorization` is the IAM-01 clause-3 entry point: membership, owning-policy
  action permission and a recorded decision are all observable from `authorize(...)` and the
  `Decision`/`InMemoryDecisionSink` pair, which makes focused negative proofs straightforward.
