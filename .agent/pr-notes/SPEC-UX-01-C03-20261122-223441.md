## Lessons for workers

- A `.ts` clause-evidence test can render real React components without JSX via
  `createElement`; pass `children` in the provider props object to satisfy
  `RouterProviderProps` under `exactOptionalPropertyTypes`/strict TS in this
  repo.
- `Intl.DateTimeFormat` with `dateStyle`/`timeStyle` omits the offset, so the
  fall-back proof is the repeated wall clock (05:30Z and 06:30Z both 1:30 AM),
  not a different string. Verify expected ICU output with a quick `node -e`
  before asserting.
- When a Suspense fallback also renders `role="status"`, query by accessible
  name (`getByRole('status', { name: 'Notifications' })`) to avoid a
  multiple-match error.
- Before writing a clause-evidence story that mandates `it.skip`/`@Disabled`,
  expect `scripts/check-constraints.py` to flag it; raise the conflict with the
  owner and record it rather than aliasing the skip or editing protected files.
