## Lessons for workers

- A fix prompt can arrive with a stale findings snapshot: the integrator's one-line
  failure can be present while the debugger report that names the failing job is
  still absent. Reproduce first, then decide whether there is an in-scope defect;
  do not repair an unrelated file to make a global grep pass when the worker gate
  declares that file out of scope.
- A full Java verification can finish inside the five-minute cap here and is the
  strongest reproduction evidence for a coverage or full-suite failure; record its
  exact final lines, but leave the authoritative gate to the integrator.
- Read the worker gate's scope parsing before an out-of-scope repair: a changed path
  outside the declared scope produces a `scope` violation regardless of the reason.
- Avoid angle-bracket placeholder text in notes: the worker gate treats it as an
  unfinished hand-off. Describe shell patterns in prose instead of quoting them.
