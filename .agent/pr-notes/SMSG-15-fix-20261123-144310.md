## Lessons for workers

- A coverage repair that touches files outside the declared scope trades one
  gate for another: `worker_gate.py` reports every out-of-scope path as a
  `scope` violation, while the coverage repair gate fails the same base drift.
  When the coverage gate sends the work back, re-apply the previously reviewed
  fix and record the unresolved scope-versus-coverage conflict in Findings for
  the integrator to decide.
- A single shared, directly tested `defined` invariant replaces eight private
  nullish guards that no input could trigger; deleting the unreachable guards
  and covering the one helper is cleaner and smaller than eight test-only
  exports. Hoisting a nullish-coalescing fallback into one local removes the
  second, unreachable coalescing branch without weakening either check.
- `worker_gate.PLACEHOLDER` matches any angle-bracket token in the Test
  evidence, Coverage or Why-not-finished sections, including an HTML-looking
  anchor in prose. Write routes and ids without angle brackets in those
  sections.
- From a nested feature folder, shared imports are three levels up, for example
  `../../../app/router`; typecheck catches a wrong depth immediately.
- Adding a `messages.ts` anywhere under `apps/staff-web/src` breaks the
  hard-coded registry in `tests/messageParity.test.ts`; use a feature-local
  `labels.ts` unless extending the registry is inside the scope.
- `tsc --noEmit` prints nothing on success, so paste the explicit `npm run
  typecheck` exit line as evidence rather than relying on empty output.
