## Findings

- The story (step 3) asks for a skipped `it.skip("GAP: …")` test, but `scripts/check-constraints.py:52-53` rejects an added `it.skip(` in a `.ts` file and AGENTS.md forbids skipped tests. Resolution: ACTIVE green absence assertions in the spec plus the complete positive enabling test quoted verbatim in the clause document (Markdown is exempt). This is a deliberate, documented deviation from the story wording, not a weakened gate.
- Clause 1 is the umbrella title of WEB-13, not a fourth rule. Reproducing C02/C03/C04 would duplicate three parallel workers, so C01 proves only the whole-boundary view and cross-references the siblings under `## Gap`; Status is `Partly proven` for that reason.
- "Absent" in the GAP test name is scoped to the authenticated staff portal's own `public/` surface and route tables. The status/maintenance/support pages themselves already exist in the separate `apps/public-pages/` module (delivered earlier, proven by the pre-existing `tests/publicPages.test.ts` and owned by C03); the clause document states this explicitly so the label cannot be misread.
- The maintainer confirmation requested by the task brief was unavailable in this worker context. The brief and story name the two scope paths, so they were treated as planned paths; no other path was created.
- The full Vitest run prints pre-existing jsdom "Not implemented: navigation" console noise from `UnsupportedBrowserPage` tests. All 254 test files and 2984 tests passed and `check.sh` exited 0; the noise is not introduced by this change.
- No production code, existing test, contract, migration or dependency changed. No patient data or credential appears in the test, document or these notes; the only clinical-looking string is the synthetic `Patient MRN 42` used to prove refusal.

## Lessons for workers

- For a title-only umbrella clause, prove the boundary from this module's side and cross-reference the sibling clause tasks instead of duplicating their assertions; set Status to `Partly proven` and say why.
- "noindex" contains the letters "index". Detect indexing permissions with a word-boundary match (`\bindex\b`) and assert both the synthetic allowed case and the real noindex case so the matcher cannot pass by naive substring search.
- Scope absence claims to the module. A page that exists in a separate, correctly hosted module is not "missing" — write "absent from this portal" and cite the owning module and task.
- Run `npm run lint` as soon as the test file is written: `@typescript-eslint/prefer-string-starts-ends-with` rejects a regex `$` test on a string, so prefer `path.endsWith('/routes.ts')`.
- To satisfy the no-skipped-test rule while still recording the complete future proof, keep an active green absence tripwire in the spec and quote the positive `it.skip("GAP: …")` test in the Markdown clause document.
