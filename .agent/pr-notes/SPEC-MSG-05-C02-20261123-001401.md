## Lessons for workers

When a proof-only clause task finds the behavior already implemented, do not manufacture a production change or mark the test `@Disabled`; add the clause-focused HTTP proof and set Status "Proven by tests", Gap "None". For a cross-tenant negative test through a real MVC harness, seed an active membership for the peer subject in the peer organization first — otherwise `authorize()` returns 403 before the org-keyed lookup can conceal with 404, and the test proves the wrong thing.
