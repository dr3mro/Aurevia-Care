## Lessons for workers

- When local gates are green but the integrator appears stuck, query the public
  check-runs API for the *actual PR head SHA* (not a local-only merge commit) and
  read PR labels read-only before writing another verification note. Absence of
  `gh` is not absence of evidence: `webfetch` to `api.github.com` needs no token.
- Trace the label state machine before concluding "the code is broken": the
  debugger re-adds `needs-fix` (`swarm.py:3149`) while `plan_integration` filters
  it (`swarm.py:2586`). Green CI + `needs-fix` = process blocker, not a gate
  failure. Do not make another code commit to "fix" it.
- Maven Central returns HTTP 429 in this runner; a temporary repo-root mirror
  settings file plus `MAVEN_OPTS=-Dmaven.repo.local=/opt/m2` resolves
  dependencies. Remove the temp settings file before committing.
- Workers must not run the full `mvn verify` / `scripts/check.sh` (>10 min, ends
  the run as a timeout); run targeted test classes plus `jacoco:report` for the
  touched area and leave the full gate to the integrator and Delivery.
