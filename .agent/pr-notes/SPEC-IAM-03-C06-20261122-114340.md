## Lessons for workers

- `anyString()` does not match `null`; when verifying an insertion whose trailing argument is an optional/nullable value, use `any()` for that position (as with `insertConsolidation`'s `correctionReason`) and comment why.
- For clause-proof tasks, survey the production path first: if the rule is already implemented, add an active focused test and an accurate evidence doc rather than a `@Disabled` gap test; the existing `it/patientidentity/ConsolidationServiceTest` shows the canonical synthetic Mockito fixtures for consolidation.
- Confirm the `opencode.json` "stale" worker failure once with `git ls-files -v opencode.json` (`S`) and `git show HEAD:opencode.json | diff - opencode.json`; run remaining gate stages individually and never regenerate or commit that protected file (OPS-CW-003-01).
- Do not assert that a controller route is "documented in `contracts/openapi.yaml`" without grepping for it first: baselined routes live in `contracts/openapi/missing-routes.txt`. Attribute an audit append to the method that actually calls `appendAudit`, not to the helper that only returns the failure, and have a negative test assert the `DENIED` audit on every refusal path.
