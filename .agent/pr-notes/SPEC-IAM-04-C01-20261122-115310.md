## Lessons for workers

- Before writing a clause proof, survey the domain package: the consolidation worklist was already implemented and had an HTTP integration test, so the right deliverable was an active proof test plus an evidence document, not a `@Disabled` GAP test.
- For a same-tenant clause, a service-level mock test proves entitlement and that the service returns only the tenant-bounded result; cross-tenant exclusion itself belongs to a real-PostgreSQL RLS integration test — cite the existing one rather than asserting SQL strings or duplicating a heavy test.
- In a cloud worker, six `test_check_pack` failures plus `git ls-files -v opencode.json` = `S` confirm the CI-profile overlay; record it once and run the remaining checks individually instead of regenerating the protected file.
- Scope discipline: the missing OpenAPI entry and the committed Javadoc conflict markers are real but out of scope for a clause-proof task; document them rather than editing protected or unrelated files.
