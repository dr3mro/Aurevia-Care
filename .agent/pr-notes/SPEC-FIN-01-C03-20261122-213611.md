# SPEC-FIN-01-C03 — FIN-01 clause 3 API proof

## Summary

Added one HTTP-level integration test class and one evidence note proving that FIN-01 clause 3 is
already built: payments, credits and refunds are linked immutable ledger entries, and reversals and
adjustments require a reason and an independent approver. No production code, migration, contract or
existing test was changed. The clause is `Proven by tests`; the gap is `None`.

Scope (only these two new files):
- `apps/api/src/test/java/com/aurevia/finance/clauses/RecordPaymentRefundCreditLinkedImmutableEntriesTest.java`
- `docs/spec/clauses/finance/record-payment-refund-credit-linked-immutable-entries.md`

## Affected requirements

FIN-01 (clause 3, verbatim: "Record payment, refund and credit as linked immutable entries, requiring
reason and approval according to policy.").

## Lessons for workers

- A proof-only clause test has no red phase: the correct check is a green targeted Surefire run plus the full negative matrix, not a disabled test or a manufactured failure.
- State immutability twice: serialized HTTP snapshots before/after later posts and after a fresh GET, plus a database UPDATE/DELETE rejection that binds the tenant, control-`SELECT`s the row, and asserts SQLSTATE 44000 from the migration owner. An in-process `View.entries().clear()` assertion belongs in the unit test, not in an HTTP test.
- Make tenant negatives non-vacuous: create the resource inside the other organization, prove the owning actor can see it, and only then assert 404 for the foreign actor.
- The advisor's exact 422 code matters: a missing approver is `INVALID_APPROVERSUBJECT` from input validation, while a well-formed but unauthorized approver is `INVALID_APPROVER` from the policy check. Assert both to cover both branches.
- In a cloud worker, `check-pack.py`, `test_check_pack.*` and a missing `coverage` package are environment artifacts; confirm the `S opencode.json` skip-worktree profile once, record the command and final line, and run the remaining gate stages individually.
