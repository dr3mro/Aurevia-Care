## Lessons for workers

- `scripts/check-constraints.py` flags any newly added `@SuppressWarnings`, even in a test.
  Use `doAnswer` with `TransactionCallback<?> callback = invocation.getArgument(0)` instead
  of an unchecked cast when stubbing a synchronous `TransactionTemplate`.
- In this cloud worker `opencode.json` is the CI profile under `skip-worktree` (`S`); that
  alone makes `check-pack.py` and six `test_check_pack` cases red. Confirm once, record the
  final lines, run the remaining gate stages individually, and never regenerate the file.
- For a proof-only clause test, assert the observable append-only fact (the `reopened`
  event and its from/to states), not just a returned view built from a stub.
- A targeted JaCoCo run combining the new clause test with the neighbouring service test
  gives concrete 100% evidence for the exercised production class without the ten-minute
  full `mvn verify` that times out workers.
- When citing sibling tests in a clause record, use fully qualified class names; the
  coverage auditor flagged abbreviated `it/...` paths as a documentation-accuracy nit.
