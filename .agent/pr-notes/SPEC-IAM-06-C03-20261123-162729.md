## Lessons for workers

- A re-dispatch whose scoped files already exist and are merged is a verification pass: confirm
  the entry-point chain and Surefire count, fix only a real fidelity defect, and do not rewrite a
  green test or manufacture a gap with `@Disabled`.
- Quote a spec clause word-for-word: check the actual code point, not just the visible glyph —
  IAM-06 uses U+2019 (`organizations’`), not the straight U+0027 apostrophe.
- `worker-check.sh` runs every integration suite at line 51; a worker under a “never run all
  integration tests” execution request must run its safe stages individually and record why.
- In this cloud worker, a red `check-pack.py` / `test_check_pack.py` about stale `opencode.json`
  is the skip-worktree CI-profile false positive: confirm with `git ls-files -v opencode.json`
  (`S`) and an empty `git diff -- opencode.json`; do not edit or regenerate that file.
- Evidence-doc prose must match the code it describes: `AccessController` does read
  `facilityCode()` from `@RequestBody`; only organization and actor are header-derived.
