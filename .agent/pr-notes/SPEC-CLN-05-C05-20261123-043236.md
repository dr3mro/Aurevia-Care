## Lessons for workers

- Spring's `HttpStatus` renders 422 as `UNPROCESSABLE_CONTENT` in this toolchain;
  assert `getStatusCode().value() == 422` for validation errors to stay robust.
- For the entered-in-error ledger, signed v2 has `supersedes_version = 1` because
  signing supersedes draft v1; the clause's own assertion is on v3 superseding v2.
- Keep the worker gate's stale-`opencode.json` result as a one-time false-positive
  record (skip-worktree `S` flag); run the remaining stages individually instead
  of regenerating or touching that file.
