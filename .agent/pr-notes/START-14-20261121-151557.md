# START-14 — Docs: catalogue of the synthetic test data

## Summary

Added `docs/reference/synthetic-data.md`: a catalogue of the synthetic tenants,
facilities, staff/subjects, patients, orders, fixed instants and JSON evidence
fixtures that the tests actually use. It records the naming rules that make fake
data obvious, the identifiers reserved for tests, the real-person/PHI values that
must not be copied, and a safe procedure for adding a new fixture. Every item
names the file that holds it; only data that exists in the tree is listed. Values
are described by pattern rather than reproduced.

No code, dependency, script, migration or tracker was changed. `docs/reference/index.md`
was not edited (START-18 owns that line).

## Lessons for workers

- Describe a fake value by its pattern, never by copying it: `check-secrets.py`
  scans tracked *and* untracked files, so a brand-new doc with a real-looking name
  fails the gate just like a fixture would.
- The two tenants sharing identical local record IDs is the intended ARC-02
  isolation proof, not a data-quality defect; keep that pattern in any new fixture.
- `docs/reference/index.md` is owned by START-18; a new reference page must not
  link itself there from a parallel task.
