## Lessons for workers

- In a clause-test task whose helpers are `private` in another package, restate a small private
  fixture in the new clause class (the established `chart/clauses` pattern) instead of trying to
  import them; keep the `@SpringBootTest` datasource URL and the local `URL` constant identical or
  seeding silently targets a different database.
- Give each synthetic patient a distinct MRN when one test covers several allergy statuses, and
  leave the "unknown" patient without a status row to exercise the repository's absent → UNKNOWN
  fold. Seed a non-verified assertion on the unverified patient so `AllergyChecker:57-59` is reached
  through HTTP, and pair an unmapped ingredient with a verified status so the second side of the
  disposition `||` is decisive.
- A green test against already-implemented behavior still needs a red proof: temporarily mutate the
  decision to its opposite, observe the exact failures, restore with a shell `EXIT` trap, verify an
  empty production diff, then re-run green so the final Surefire report matches the committed tree.
