  config** was found; OWASP, SpotBugs and the secret regex are the real checks.

  `pull_request` paths ignore `docs/**` and `**/*.md`), so there is no SHA-linked

## Lessons for workers

- Before writing operational docs, read the code and config for the actual
  environment-variable names, endpoints and gates. Plausible tools such as a
  pager, secret manager, image scanner, progressive rollout and rollback CLI
  exist only as spec rows or synthetic evaluators here — mark `NOT YET IN PLACE:`
  instead of inventing a command or contact.
- `python3 -I scripts/check-docs.py` validates every relative Markdown link and
  every mentioned ID whose prefix is defined in the specification; keep links
  relative and cite only defined prefixes (OPS, WEB, IAM, XCH, CLN, etc.). The
  notes directory is skipped, but the tracked docs are not.
- `scripts/check.sh` and `scripts/worker-check.sh` are not fast checks: they call
  `mvn verify` / the full integration tier. For a docs-only story run the
  applicable `check-docs.py` (plus cheap policy checks) and leave the full gate
  to the integrator.
- Distinguish "real endpoint whose policy is a stand-in" from "synthetic
  fixture": the governance controller is real code, the approved policy pack is
  not. Precision matters in incident documentation.
- A fix pass on an already-complete deliverable is a verification pass: re-read
  every artifact and re-run every cited claim against source before deciding no
  code change is needed, rather than assuming the first run was correct.
