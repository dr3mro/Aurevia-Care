# SMSG-15 — Staff web: patient reference chip and blocked-view state

## Summary

Ten new files under `apps/staff-web/src/features/staffmsg/references/` ship two
presentational components and their pure helpers: `PatientReferenceChip` shows a
non-identifying label as an in-app chart link when access is allowed and a word
+ icon `role="alert"` blocked view (no label, id or link) otherwise, and
`ReferenceInserter` offers a labelled subject field whose warning is fixed
translated copy for a fixed reason code — the raw subject is never echoed.
No dependency, route, contract, generated client or shared file was changed.

- MSG-07 — staff-message references; subject screened with fixed reason codes, never copied.
- WEB-09 — staff-web state views, bilingual labels and accessibility.

## Why this is not finished

`bash apps/staff-web/check.sh` cannot exit 0 on this base revision. It stops at
stage 1 (`npm run gen:api:check`) with `✘  Generated types are not up-to-date!`,
and when that stage is skipped the final `npm run test:coverage` exits 1 on 19
untouched files that are below the 100% per-file threshold. Both defects are on
`origin/main` before this change, both need edits outside the SMSG-15 scope, and
both are recorded as task requests above. Everything inside the scope is green:
27 scoped tests pass, typecheck/lint/build/bundle gates pass, and all five new
production files are 100/100/100/100 in both the scoped and full-suite coverage
reports. Next step: the integrator (or the two requested tasks) regenerates the
OpenAPI client and restores the pre-existing per-file coverage, then reruns
`bash apps/staff-web/check.sh` on the merge result.

## Lessons for workers

- From a nested feature folder such as `features/staffmsg/references`, shared
  imports are three levels up (`../../../app/router`), not the two levels a
  one-deep feature folder uses; typecheck catches this immediately.
- Adding a `messages.ts` anywhere under `apps/staff-web/src` breaks the
  hard-coded registry in `tests/messageParity.test.ts`. For a feature-local
  bilingual bundle, follow `features/radreferrer/labels.ts` unless extending the
  registry is inside your scope.
- For a fast 100% proof use `vitest run --coverage --coverage.include='<your folder>/**/*.{ts,tsx}'`;
  the full `check.sh` may still be red for base drift — capture both and never
  edit a shared or generated file to make a worker gate green.
- Keep MRN-like screening fixtures under seven digits (`MRN: 12345`): DIGIT_RUN
  is checked first, so an MRN with a 7+ digit run reports `DIGIT_RUN` instead.
