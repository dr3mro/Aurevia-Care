## Lessons for workers

- When a clause test is requested for a decision point that already has full unit coverage, keep the new proof focused on the clause's positive and negative outcomes and record unwired reachability as a documented gap; do not add a skipped test or production wiring outside the declared scope.
- Check the open task register before writing a `## Gap` register entry: an existing task may already own the wiring, which makes the correct count "0 new tasks" and prevents a duplicate `task-requests` block.
- The prompt-named notes file path overrides an older path in a brief; the quality gate reads that exact file, and its `## Review verdicts` section must contain verdict lines only because `check-verdicts.py` treats any nearby `Required:`/`Critical:` line as unresolved.
