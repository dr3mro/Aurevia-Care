## Lessons for workers
- Before deleting a "dead" source file, run `scripts/check-docs.py`: a Markdown link elsewhere can make deletion a cross-boundary change that a narrow scope forbids. Wiring may be the only in-scope outcome.
- A thin `@RestController` with a public constructor injecting the service (no `new ...Service(...)`) clears `check-wiring` and keeps the service's own unit coverage intact.
- When Maven cannot resolve dependencies offline, a standalone javac + JUnit + JaCoCo-agent harness can still prove per-class 100% coverage; compile with `-parameters` so Spring resolves `@RequestParam` names, and keep a single Jackson major version on the classpath (Jackson 3 uses `tools.jackson` plus `jackson-annotations` 2.21).
