## Lessons for workers

- Count directory levels before copying an import from `tests/i18n/`: a file under `tests/spec/localization/` needs `../../../src/...`, not `../../src/...`.
- A clause-evidence test is intentionally a named mapping of an already-built clause; it will resemble neighbouring tests. Its value is the clause doc that cross-references production code, so do not bolt on duplicated validator or domain tests just to look novel.
- Before writing "missing test" into a clause doc, grep the API test tree: an integration test may already cover the behaviour (here `FollowUpHttpIntegrationTest`).
- Do not assert absence of Arabic-Indic digits with locale `en` — that is a tautology. Assert it with `ar`, where the platform default would otherwise differ.
- `tsc --noEmit` prints nothing on success; run `npm run typecheck` separately and record its exit code as evidence.
- Swarm workers must not run `scripts/check.sh` (it invokes the full Java `mvn verify`); the staff-web definition of done is `bash apps/staff-web/check.sh`.
