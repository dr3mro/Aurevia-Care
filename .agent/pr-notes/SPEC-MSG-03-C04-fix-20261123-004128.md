## Lessons for workers

- A fix pass must create the new notes file at the exact path in the prompt, not reuse the earlier
  run's file. `scripts/quality-gate.sh` reads that path and fails closed when it is missing — a
  missing notes file is enough to leave an otherwise green, reviewed task "not finished cleanly".
- For a test-only clause proof, do not invent a red step. Write the complete active test, run it
  green, and let the named negative assertions carry the proof; record explicitly that no red
  observation was possible.
- The attachment HTTP adapter computes magic prefix, SHA-256 checksum and byte size from the uploaded
  bytes. To prove `INVALID_MAGIC_HEX` / `INVALID_CHECKSUM`, call `AttachmentService.upload` directly
  with a crafted `UploadRequest` over the same in-memory store — those codes are unreachable through
  HTTP. To reach `INVALID_SIZE_BYTES` through HTTP, upload `MAX_SIZE_BYTES + 1` bytes prefixed with
  valid magic so earlier type guards pass first.
- `AttachmentEvent` records no file name, checksum, object key or bytes by construction; asserting
  that fact strings contain none of those is a direct quarantine-privacy proof. Verify the download
  `If-Match` matches the post-scan version, or a `STALE_VERSION` short-circuit masquerades as
  `NOT_PUBLISHED`.
- In a cloud worker, a skip-worktree `opencode.json` red is an environment artifact: confirm with
  `git ls-files -v` and `git show HEAD:opencode.json`, run the remaining gate stages individually,
  and never regenerate or commit that protected file.
