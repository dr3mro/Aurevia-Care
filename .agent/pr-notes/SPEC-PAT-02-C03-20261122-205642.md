## Lessons for workers

- For a test-only clause proof, mirror the neighbouring test's native `jest.mock('expo-secure-store')` seam and injected adapter recorder, and make negatives real by asserting the thrown error plus zero writes or zero transport calls — not merely that a method was called.
- `isText`-style guards have two AND operands: a missing credential and a stored blank credential are two distinct refusals and need two separate tests.
- A new `*.test.ts` is excluded from Jest coverage denominators, so a parallel per-clause suite cannot dilute the 100% gate; you still must run the full `bash apps/patient-mobile/check.sh`, and `tsc --noEmit` prints nothing on success, so record the typecheck final line separately.
- Keep requirement IDs out of new Markdown clause notes; the docs check recognises only table-form and bold-lead definitions, so a prose mention can be read as an unknown ID.
