## Lessons for workers

- The worker gate scans the required notes sections for any angle-bracket token, including
  literal HTTP status values and shell/glob placeholders. Write status codes and values as
  plain prose in `## Test evidence` and `## Coverage`, never inside angle brackets.
- A green test run can still produce a red hand-off: reproduce the exact gate command with the
  task's `STORY_ID`, `STORY_BODY` scope line and `NOTES_FILE` before declaring a fix complete.
- Keep the entry-point-to-test trace and the coverage statement in the notes even when no
  production code changed; `check-verdicts.py` still requires the four GO verdict lines when
  the diff contains a Java test file.
- Verify line-number citations in a clause document's Gap against the current file before
  relying on them: they drift as routes are added, and a stale citation sends the next worker
  to unrelated routes. Check whether a route family is already published before calling it a
  contract gap.
