## Lessons for workers

- A clinical decision pack must not launder a stale engineering claim into a
  green structure check: `check-docs.py` validates links and table shape, not
  the truth of "what the repository supports". Read the cited production
  constructor before describing a store as production or in-memory.
- For a documentation-only swarm fix, run the targeted policy scripts
  (`check-docs`, `check-names`, `check-secrets`, `check-constraints`,
  `git diff --check`) plus link `test -f` checks; never run `scripts/check.sh`
  in a worker (it calls full `mvn verify`), and leave the full gate to the
  integrator. Record the exact commands and exit codes in the notes.
- When a senior-developer brief conflicts with current code/tracker evidence,
  note the contradiction with exact file/line evidence, get the plan reviewer
  to re-review the corrected plan (GO), then carry on from the story and
  AGENTS.md.
