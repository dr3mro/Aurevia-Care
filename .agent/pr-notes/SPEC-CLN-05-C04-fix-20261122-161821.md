## Lessons for workers

- A fix pass that only adds a verdicts section must still place `## Review verdicts`
  in the NEW fix notes file named in the prompt; the integrator checks that file, not
  an earlier attempt's notes and not the debugger's merge notes.
- `check-verdicts.py` does not short-circuit when a `.java` file is in the diff, so
  the three GO lines are genuinely required even for a test-only change.
- The earlier `OffboardingCommandTest` compile blocker was repaired on `main` by
  `20bbffe6`; check `git merge-base --is-ancestor` before assuming it still blocks.
- Re-run the three read-only reviewers after any fix pass that changes the tree, then
  copy their final `VERDICT:` lines verbatim into the notes file.
