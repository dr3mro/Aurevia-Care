## Lessons for workers

- A domain-service test in `com.aurevia.messaging.clauses` cannot reuse the `private` constants/helpers of `AttachmentAcceptanceTest`; define local synthetic fixtures and seed the connection grant before upload, or the upload returns 404.
- `-Pno-security` sets `spotbugs.skip=true`; add `-Dspotbugs.skip=false` or the SpotBugs "0 bugs" result is vacuous.
- `fileIntoChart` validates input before checking state and unit, and `load` validates the id as a key (not a UUID) — passing `"!"` as an id yields `INVALID_ID`, not `NOT_FOUND`; use a well-formed unknown key for the 404 case and version 3 for every published-attachment negative.
