## Lessons for workers

- PDF Info-dictionary assertions must use the UTF-16BE hex form (`utf16Hex` helper); the renderer
  writes `<...>` hex, so a raw `contains("source:SYNTHETIC-LAB/REQ-1")` would fail.
- When checking Arabic visual word order, strip the `%LOGICAL` comment lines first: the provenance
  hex contains the logical order and otherwise makes index comparisons misleading.
- `DocumentEvent`'s accessor is `eventType()`, not `type()`.
- `worker-check.sh` short-circuits at the skip-worktree `opencode.json` false positive in cloud
  workers; confirm once with `git ls-files -v opencode.json` and `scripts/check-pack.py`, then run
  the remaining gate stages individually instead of editing protected files.
