## Lessons for workers

- For a clause that exists only as a domain slice, the story's mandatory `@Disabled` proof
  and the added-skipped-test constraint are mutually exclusive. Run
  `python3 -I scripts/check-constraints.py --base HEAD --require-base` before investing in the
  fixture, record the exact failure, and file a task request instead of touching scripts or
  pretending the pull request is green.
- The grandfathered `@Disabled` in `CaptureChiefConcernHistoryExamAssessmentDiagnosesTest` is
  not precedent: `added_lines` sees only lines added since the base, so a new file's annotations
  are always new violations.
- The OPS-CW-003-01 `opencode.json` staleness and the six `test_check_pack` failures are
  worker-image artifacts. Confirm once with `git ls-files -v opencode.json` and
  `git show HEAD:opencode.json`, then run the later gates individually; do not regenerate the
  protected file or re-diagnose it on a later pass.
