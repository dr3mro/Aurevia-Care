## Lessons for workers

- A clause whose HTTP slice is absent cannot gain a green HTTP proof inside an evidence-only task:
  the disabled-test constraint and the no-production-code scope are mutually exclusive. Run
  `python3 -I scripts/check-constraints.py --base HEAD --require-base` before investing in the
  fixture; if it flags your added skipped test, delete the dead proof and hand the four behaviours
  off in `task-requests` instead of editing a protected script or claiming a green gate.
- The grandfathered `@Disabled` in `CaptureChiefConcernHistoryExamAssessmentDiagnosesTest` is not
  precedent: `added_lines` sees only lines added since the base, so a new file's annotations are
  always new violations.
- The OPS-CW-003-01 `opencode.json` staleness and the six `test_check_pack` failures are worker-image
  artifacts. Confirm once with `git ls-files -v opencode.json` and `git show HEAD:opencode.json`, run
  the later gates individually, and do not regenerate the protected file on a later pass.
