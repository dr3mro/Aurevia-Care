## Lessons for workers

- Verify an evidence doc's factual claims against the repository before leaving them
  as "Proven": this run found a stale OpenAPI statement inherited from the prior note.
- When asserting on `audit_event` rows for a sensitive action, filter by `action` as
  well as `correlation_id` — one command writes several audit rows under one correlation.
- `-Pno-security,fast -Dgroups=integration` runs zero integration tests; use
  `-Pno-security -Dgroups=integration -Dtest=...` and confirm the Surefire count. Compile
  before `spotbugs:check` or it is vacuously green.
- Do not run `scripts/worker-check.sh`, `scripts/check.sh` or full `mvn verify` in a
  swarm worker; run the targeted suite, SpotBugs after compile and the individual
  policy scripts, and leave the full gate to the integrator.
