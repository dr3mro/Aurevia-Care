# SPEC-IAM-03-C04 — Warn on likely duplicates (IAM-03 clause 4)

## Summary

Adds a focused, clause-only API proof for IAM-03 clause 4 ("Warn on likely duplicates.").
A new HTTP integration test exercises the existing warning through the normal patient-read
entry point with synthetic fixtures, covering the positive rule and four refusal paths
(peer tenant, unknown date of birth, differing name/date, unauthorized role). A clause
evidence document records the status, mapping and gap. **Test and documentation only:**
no production code, existing test, contract or migration was changed.

## Lessons for workers

- Check the test classpath's JSON library before writing a Java integration test: this module uses
  `tools.jackson.databind` (Jackson 3). `com.fasterxml.jackson.databind` is not present and fails
  test compilation; using `asString()` matches the project's style.
- When parallel workers add patient clause suites, give each test its own synthetic database name
  (here `orevia_warn_duplicates_it`) even when mirroring `PatientRegistrationTest`'s fixture.
- `scripts/check.sh` invokes full `mvn verify`; a swarm worker should run its policy stages and the
  single touched test class individually, per the prompt and AGENTS.md.
- Confirm `git ls-files -v opencode.json` once for `check-pack` / `gen-opencode.py --check`
  failures under `skip-worktree`; do not regenerate the protected file from a worker.

No task requests: no task outside the two scoped files was needed.
