## Summary

Proves ARC-05 clause 2 ("Workers use immutable event IDs and per-aggregate
version.") at the real HTTP entry point with one new integration test class and
one clause record. The rule is already implemented in production, so this is a
test-only proof: no production code, existing test, contract, migration or
dependency was changed, and nothing was disabled or suppressed.

Scope (only these two new files; `git diff --name-status origin/main...HEAD` is
empty because both are untracked and staged on commit):

- `apps/api/src/test/java/com/aurevia/events/clauses/WorkersUseImmutableEventIdsAggregateVersionTest.java`
- `docs/spec/clauses/events/workers-use-immutable-event-ids-aggregate-version.md`

Discovery: the rule lives in `DurableEventService.publish` (`DeliveryInputs.newId()`
+ version 1), `snapshot()` (keeps `eventId`, sets `aggregateVersion() + 1` on every
transition/retry/dead-letter/review), `transition()` -> `requireVersion()` (412
`STALE_VERSION`), `authorize()` (403 `FORBIDDEN`), `requireEvent()` (404
`NOT_FOUND`), and `DeliveryController` is the thin injected HTTP adapter. The
store is `JdbcDeliveryStore` over the forced-RLS `delivery_outbox` table; the
routes and table already exist. No new class, file or workflow implements the
rule.

## Lessons for workers

- Confirm an `opencode.json is stale` result is the CI-profile `skip-worktree`
  artifact with `git ls-files -v opencode.json` → `S` and `git show HEAD:opencode.json`;
  then run the remaining gate stages individually. Never regenerate or commit that
  protected file from a worker.
- A test-only clause proof should drive the real HTTP controller with its own
  database name (mirroring `WriteChecksCurrentScopeTest`) and assert both the HTTP
  response and the RLS-bounded stored read-back — that is what distinguishes it from
  the in-memory `DurableEventServiceTest` it must not duplicate.
- Spring 6 names HTTP 422 `UNPROCESSABLE_CONTENT`; assert `getStatusCode().value()`
  as numeric 422 for version independence.
- `RetryResult` is a wrapper record (`{"event":{...},"deadLetter":...}`); assert the
  nested `"event":{` shape before reading nested fields with an `indexOf`-based
  helper, or a shape regression can be masked.
- Verify production FQCNs in a clause document against source: `DeliveryController`
  is in `com.aurevia.events`, not `...web`.
- The advisor brief dropped `orevia-context-optimizer` ("context is mapped
  here; do not re-scan the tree"); no tree re-scan was performed. The brief listed
  `orevia-senior-backend` in its specialists/skills, so it was consulted at the
  code stage; the brief is guidance and no rule was changed by it.
