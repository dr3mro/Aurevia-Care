## Lessons for workers

- In this Spring 6.1+/Boot 4 toolchain the 422 enum is `UNPROCESSABLE_CONTENT`; assert the
  numeric value or the new constant to avoid a late red run.
- A test-only clause-evidence story cannot show a literal red phase. Say so explicitly and
  record which guard each negative would catch if removed, instead of fabricating one.
- `worker-check.sh` runs every integration test and `check.sh` runs full `mvn verify`;
  in a swarm worker run the targeted `-Dtest=...` suite and each policy script separately.
- The plan reviewer's GO on the first plan is not guaranteed: naming the exact event-trail
  assertion and the precise out-of-scope contract files up front saves a NO-GO round.
- Verify `verify(absent)` leaves the state `ambiguous` and only the retry moves it to
  `submitted`; asserting `submitted` after verification is a tempting but wrong claim.
