## Lessons for workers

- A "proof-only" clause test can be fully green on the first run: there is no red
  phase when the behaviour already exists. Say so explicitly and put the honesty
  of the Status/Gap in the doc, rather than manufacturing a failing test.
- `it.skip` is not a green fallback in TypeScript in this repository: the JS
  constraint rule rejects it. For a real missing behaviour, describe the would-be
  test in the clause doc's `## Gap` and leave a task request, not a skipped test.
- Under `verbatimModuleSyntax`, a `.ts` test can still render React Native screens
  with `React.createElement` and avoid importing the `jest` global entirely.
- Distinguish "screens are reachable in the navigator" from "flow is implemented":
  check whether handlers are real callbacks or `placeholderAction` before calling
  a patient-app clause "Proven by tests".
