## Lessons for workers

- For a clause evidence note, the authoritative evidence is often negative:
  explicit `NOT YET IN PLACE`, `open`, `needs infrastructure owner` and `Not
  approved` statements. A delivered decision pack or a synthetic evaluator that
  checks `rollback_tested` is a declaration, not proof that a rehearsal happened.
- Verify the exact line of a table row before citing it. I initially cited the
  `evidence.md` table header at line 19 instead of the WEB-11 row at line 31;
  both the code reviewer and DevSecOps caught it.
- Build absence assertions narrowly. `rehearsal (record|result|report)` matched
  unrelated synthetic-rehearsal docs; `rollback rehearsal (record|result|report)`
  plus `signed (release )?checklist` and `approver: First Last` gave the intended
  exit 0.
- `check-docs.py` validates links, requirement IDs and Markdown structure only.
  Add deterministic greps for the verbatim clause, the exact heading set and the
  status value, otherwise those claims rest on inspection alone.
- From `docs/spec/clauses/<domain>/`, `../../../../` reaches the repository root
  and `../../../` reaches `docs/`; link only files that exist today.
