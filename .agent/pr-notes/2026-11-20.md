## Lessons for workers
- Derive identity from `TenantContext` plus `StaffRepository.activeRoles` inside the tenant-guarded transaction when a kernel takes an explicit actor/roles; never accept a role or organization from the request body (AUD-20261119-03).
- A `@RestController` with a public `@Autowired` constructor plus a package-private fixture constructor lets standalone MockMvc drive real domain services while the production constructor stays covered by existing `@SpringBootTest` context loads (AUD-20261119-03).
- Two interfaces declaring `find(String, String)` with different return types cannot be implemented by one adapter class — use nested per-port adapter classes (AUD-20261119-03).
- Check where the assertions a story names actually live before declaring its scope impossible; a narrow `web` scope can be contradicted by `it` assertions the same story requires changing (AUD-20261120-01).
- In a cloud worker, a red pack check is usually the CI profile under `skip-worktree`: compare with `.github/opencode.ci.json` and `git show HEAD:opencode.json` before regenerating anything. Unset leaked swarm vars with `env -u CHECK_SCRIPT -u BRANCH_PREFIX -u BASE_BRANCH` when running `worker-check.sh` locally (AUD-20261120-01).
- `python3 -I` ignores `PYTHONPATH`; a missing `yaml` module cannot be fixed by exporting it. Install the wheel into site-packages as an environment-only repair (AUD-20261120-01).
- With Spring Security MockMvc `standaloneSetup`, bridge `SecurityContextRepository.REPO` into `SecurityContextHolder` yourself or `jwt()` silently yields 401; in Spring Boot 4.1.2 use `WebApplicationContextRunner` + `MockMvcBuilders.standaloneSetup(...).addFilters(chain.getFilters())` instead of `@WebMvcTest`/`@AutoConfigureMockMvc` (AUD-20261120-03).
- Run SpotBugs with tests (`mvn -Dowasp.skip=true verify`); `-DskipTests` makes JaCoCo fail first and hides the verdict. Delete an unreachable null guard flagged by SpotBugs rather than annotating it (AUD-20261120-03).
- Never end a Java text-block SQL fragment with `SELECT`/`RETURNING` and concatenate a column constant on the next line — trailing whitespace is stripped and tokens fuse (`SELECTorganization_id`); write `"SELECT " + COLUMNS + "FROM ..."` (AUD-20261120-06).
- pgjdbc 42.7.x cannot bind `java.time.Instant` without an explicit SQL type; use `OffsetDateTime.ofInstant(instant, ZoneOffset.UTC)`. A JDBC adapter behind a domain service with no `TransactionTemplate` must open the guarded transaction itself or reads are empty under forced RLS (AUD-20261120-06).
- A failing integration test is the fastest way to find SQL/JDBC type errors that unit mocks cannot reveal; run the new `@Tag("integration")` class directly before the full gate (AUD-20261120-06).
- An applied Flyway migration's version + description + checksum are immutable; renaming one breaks `validateOnMigrate` ("applied migration not resolved locally") (AUD-20261120-11).
