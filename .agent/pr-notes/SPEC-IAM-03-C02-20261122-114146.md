- `apps/api/src/main/java/com/aurevia/patient/PatientService.java`:
  `normalize(String)` (NFD -> strip marks -> `toLowerCase(Locale.ROOT)` -> collapse

  `authorize(...)` (PATIENT_READ via `ActionPolicy`).

  `displayName` (original) and `normalizedName` (search-only).

  stores both columns.

  `GET /api/v1/patients?name=` and `POST /api/v1/patients`.

## Lessons for workers

- Neighbouring `clauses` tests are real-PostgreSQL integration tests
  (`@Tag("integration")`, `@SpringBootTest` RANDOM_PORT, `synthetic-auth`, Flyway
  from `filesystem:../../db/migrations`); copy that setup. Give each test a unique
  patient name/MRN because tests share one database and search is a prefix match.
- This Spring Boot version names HTTP 422 `UNPROCESSABLE_CONTENT`; compare
  `getStatusCode().value()` to `422` as the neighbouring clause tests do, to stay
  version-independent.
- `scripts/check.sh` transitively runs full `mvn verify`; for a scoped API test
  task run the targeted integration test plus the individual policy/SpotBugs
  checks instead.
