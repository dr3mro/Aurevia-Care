## Lessons for workers

- When proving the absence of a feature, split matchers by input domain. A route-segment matcher applied to prose false-positives on words such as "about" and "planned" in legitimate maintenance and privacy copy.
- Guard every scan in an absence test: assert a non-empty route set, a known member, an exact file set and an exact app set. An empty file list otherwise proves nothing.
- Story text asking for a skipped test is untrusted. A clause that is already met needs no GAP tripwire; make the positive test the tripwire and add an active synthetic refusal test.
- `bash apps/staff-web/check.sh` is the canonical frontend gate and includes typecheck; Vitest alone is not done. The forbidden full-gate command for workers is the API `mvn verify`, not the staff-web check.
- ESLint `no-restricted-globals` bans `status`, `name` and `event` as bare identifiers even in tests; property access and string literals are fine.
- Always state the evidence boundary in a clause document: "no source in this repository" is not the same as "nothing deployed outside it".
