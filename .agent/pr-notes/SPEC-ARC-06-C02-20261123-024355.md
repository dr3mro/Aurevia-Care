## Lessons for workers

- Use a dedicated database name per clause test: each `@BeforeAll` runs `DROP DATABASE ... WITH (FORCE)`, so two suites sharing a name collide when parallel workers run in one wave.
- A `GET /{id}` view of a non-downloadable document artifact is visible only to its uploader; use the uploader subject when asserting the state after a refused completion, and normalize enum states with `equalsIgnoreCase` (the wire serializes `CLEAN`, not `clean`).
- The `test_check_pack` failures plus `git ls-files -v opencode.json` → `S` are a known worker-image artifact; confirm once, run the remaining gate stages individually and do not edit `opencode.json`.
