## Lessons for workers

- In a `.ts` spec test built with `createElement`, `I18nProvider` and
  `ThemeProvider` require `children` in the props type, but ESLint's
  `react/no-children-prop` rejects a literal `children:` prop in a
  `createElement` call. Put the props in a variable first, as the localization
  spec test does, to satisfy both.
- Run the targeted Vitest file first for fast feedback, then always
  `bash apps/staff-web/check.sh`; `tsc --noEmit` prints nothing on success, so
  paste the `npm run typecheck` final lines separately as evidence.
- When a test claims "all error kinds", type the expected table as a
  `Record<Kind, …>` so a future union member fails compilation instead of
  silently escaping the assertion.
