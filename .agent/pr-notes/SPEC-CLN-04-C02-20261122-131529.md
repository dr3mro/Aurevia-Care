## Lessons for workers

- For a CLN-04 clause proof, the domain-service API in `clinical.templates` is the entry point;
  `TemplateService.defineVersion/approveVersion/validate/saveNote` with `InMemoryTemplateStore`
  and `TemplateActor.of(...)` fixtures is the established style (see `TemplateNoteAcceptanceTest`).
- In cloud workers, `check-pack.py`/`test_check_pack` failures for `opencode.json` are the CI
  profile under `skip-worktree`; prove it with `git ls-files -v` and a HEAD render check, then run
  the remaining gate stages individually instead of editing the protected file.
- `scripts/coverage-check.sh` and `scripts/check.sh` both reach `mvn verify`; for a worker-scoped
  test-only change, run the targeted `-Dtest=ClassName` command and SpotBugs instead, and let the
  integrator own the full gate.
