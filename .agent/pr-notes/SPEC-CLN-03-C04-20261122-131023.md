## Lessons for workers

- `POST /api/v1/catalogs/{family}/entries` returns a `ConfigEntry` JSON (`{"version":1,...}`), not a bare version number — read the `version` field. The generic catalog's `ConfigurationService.approve` does not require a distinct approver (unlike `DiagnosisCatalogService`/`DurableVersionStore`), so one `tenant_admin` can define and approve in this test.
- The `patient_record` insert trigger requires `app.actor` to be an existing user of the tenant; seed the actor before inserting the synthetic patient, or `@BeforeAll` fails before any clause behavior is exercised.
- In this cloud worker, treat `check.sh`/`python-coverage.sh` `opencode.json is stale` results as the CI profile under skip-worktree, not HEAD truth; confirm with `git ls-files -v` and `git show HEAD:opencode.json` and move on instead of editing the protected file.
