## Lessons for workers

- Confirm `git ls-files -v opencode.json` before treating `opencode.json is stale`
  as a real defect: `S` means the CI runtime profile is installed under
  skip-worktree while HEAD holds the correct generated local profile. Record the
  command and final line once, run the other gate stages individually, and never
  regenerate or edit the protected file from a worker.
- For a clause-proof story, use `smartclinic-context-optimizer` to confirm
  implemented/partial/unknown before writing tests. Writing `@Disabled` for an
  already-built clause fails the quality gate; writing GREEN tests for it is the
  correct proof.
- `release()` returns a prior decision at the `(revisionId, version, policyVersion)`
  key before rechecking PDF readiness, and the store key ignores the checksum.
  When proving a checksum-only "corrected" revision is refused, first assert no
  prior release exists, then assert the final decision's checksum so it cannot
  be a cached one.
- `DocumentContract.DocumentEvent`'s accessor is `eventType()`, not `type()`;
  check the record definition before writing event assertions.
