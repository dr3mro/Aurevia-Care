## Lessons for workers

- For a proof-only clause task, write and run the test before writing `## Status: Proven by tests`
  and `## Gap: None` in the clause doc; a reviewer will otherwise flag the fixed conclusion.
- `alternativesFor(null, at)` is unreachable through `PrescriptionService.searchCatalog`, which
  always passes a non-null entry from `catalog.search(...)`. Put a direct-`DrugCatalog` null test
  in its own explicitly named method instead of mixing it into the service-level empty-catalog test.
- Two different denial folds in one `authorize` method need different distinguishing assertions
  (exact message, and called-vs-never-called `activeRoles`) or a single 403 assertion hides which
  fold fired.
- In a cloud worker, stop re-diagnosing `opencode.json is stale`: confirm `git ls-files -v` -> `S`
  once, record the command and final line, then run the remaining gate stages individually.
