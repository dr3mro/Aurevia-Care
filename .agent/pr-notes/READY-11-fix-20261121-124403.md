## Authorization boundaries and audit events

Every non-bearer request on the browser chain requires an authenticated OIDC session. CSRF is enforced with a per-session token readable only through the non-HTTP-only `XSRF-TOKEN` cookie (an anti-CSRF value, not an authentication token — nothing is written to browser storage; staff-web `transport.ts` reads it and sends it as `X-XSRF-TOKEN` with `credentials:'include'`). The browser principal's `sub`/`orgs` attributes are resolved through the existing `ClaimsTenantResolver`, so a session cannot widen its organization set and the active tenant still comes only from `X-Active-Organization` intersected with verified claims. The bearer chain is unchanged; CSRF is ignored only for `Authorization: Bearer` requests. No audit event was added and 401/403 denial semantics are unchanged.

## Migration and rollout considerations

`@ConditionalOnWebApplication(SERVLET)` keeps the non-web startup test green and prevents the browser chain from existing without an HTTP surface; `@Profile("!synthetic-auth")` leaves the synthetic profile untouched. In production all three `OREVIA_OIDC_*` values must be supplied or startup fails closed. Issuer and client secret are never written to the repository. The IdP must publish `/authorize`, `/token` and `/userinfo` beneath the issuer and return `sub` and `orgs` in user-info — confirm with the real IdP before enablement. The host must terminate TLS so the session and XSRF cookies carry `Secure`; SameSite=Lax requires the SPA and API to be same-site for `credentials:'include'` to carry the session cookie.

## Lessons for workers

- On a re-dispatched/already-reported-done story, verify the production files still exist in the current worktree AND that `git merge-base --is-ancestor <merged-pr> HEAD` holds before trusting earlier notes. A file-existence check plus a `git diff <merged-pr> HEAD -- <scoped files>` byte-identity check catches an accidental deletion or drift that a diff-only check misses.
- When a broad "reconciled" integration commit deletes many files, check whether each story's files were re-merged; restore dropped files from the canonical merged commit only after confirming no other commit changed them in between.
- Regenerate `opencode.json` with `python3 -I scripts/gen-opencode.py` before any gate in a CI-profile worker; it is `skip-worktree`, so this restores HEAD's local profile without committing (do not edit `scripts/` or the file by hand).
- Frontend definition of done: both `apps/staff-web/check.sh` and `apps/patient-mobile/check.sh` include typecheck — Jest/Vitest green alone is not done; paste the explicit `tsc --noEmit` final lines into the notes.
- In this Boot 4.1.2 / Spring Security 7 slice, `AntPathRequestMatcher` no longer exists — use `PathPatternRequestMatcher.pathPattern(HttpMethod.POST, "/logout")` and `ClientRegistration.getProviderDetails().getAuthorizationUri()`.
- With `CookieCsrfTokenRepository`, set `CsrfTokenRequestAttributeHandler.setCsrfRequestAttributeName(null)` or `XSRF-TOKEN` is never written on a GET and the SPA has no token to send.
- `MockHttpSession` has no `setCreationTime`; override `getCreationTime()` in an anonymous subclass for deterministic session-age tests.
