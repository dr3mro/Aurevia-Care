## Lessons for workers

- The fixed-clock `InstructionService(store, actions, clock)` constructor is package-private; a clause
  test in a different package must use the public two-argument constructor or assert no time fields.
- MockMvc helpers should return `ResultActions`, not `MvcResult`, when callers chain `.andExpect(...)`;
  call `.andReturn()` only at the point the JSON body is read.
- `send` already records a `DISPATCHED` fact at revision 1; to prove an absence of a new notification
  fact on withdrawal, assert the fact count is unchanged rather than asserting no dispatch fact exists.
- Seed tenant-B fixtures while tenant B is the active context — every `InMemory.seed*` method keys off
  `TenantContext`; only `seedConnectionOrg` accepts an explicit organization.
- Confirm the `opencode.json` skip-worktree artifact once (`git ls-files -v`, compare HEAD/CI hashes),
  record the failing command and final line, then run the remaining gate stages individually.
