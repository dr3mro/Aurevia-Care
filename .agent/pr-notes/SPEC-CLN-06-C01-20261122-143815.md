## Lessons for workers

- `ends_at` must be strictly greater than `starts_at` in `public.appointment`
  (`db/migrations/V8__scheduling.sql` `appointment_check`); when seeding a prior
  appointment, always give it a real duration rather than reusing the start timestamp.
- `mvn -Pno-security -Dgroups=integration` runs integration tests; adding `fast` sets
  `excludedGroups=integration` and silently skips them. Confirm the Surefire count, not just
  the exit code. A bare `spotbugs:check` is vacuously green — compile first.
- In a cloud worker, `git ls-files -v opencode.json` = `S` plus `test_check_pack`
  "opencode.json is stale" failures is the documented false positive. Verify HEAD with
  `git show HEAD:opencode.json` and never regenerate or commit that file.
- When `scripts/worker-check.sh` stops at that false positive, run its remaining stages
  individually; do not substitute the full `scripts/check.sh`, which times out a worker.
