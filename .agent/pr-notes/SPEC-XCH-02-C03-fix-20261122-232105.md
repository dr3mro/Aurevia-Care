## Lessons for workers

- When a fix prompt carries a debugger report, reproduce the story's own scoped
  surface first; if it is green and the named blocker is out of scope, do not edit the
  out-of-scope file to force a green — route it with a `task-requests` entry and
  escalate.
- "Delivery failed" from `scripts/swarm.py` can cover a flaky, pre-existing test on
  `main`; a green local run of that flake proves little. Judge the story by its scoped
  tests and the CI job/step annotation, not by one passing repetition.
- `scripts/check.sh` calls `apps/api/check.sh` (full `mvn verify`); use the targeted
  `-Dtest=...` run plus individual policy scripts instead, and leave the full gate to
  the integrator.
- Keep notes free of PHI, credentials and raw logs, and record which evidence was
  executed versus credited from a reviewer's report.
