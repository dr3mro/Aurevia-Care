## Lessons for workers

- A specialist's independent map is worth running even for a docs-only task: it found three material facts (synthetic `src/main` ports, process-local `@Repository` service-profile store, test-only notification functions) that a first pass focused on feature screens can miss.

- Distinguish "a class exists under `src/main`" from "a durable production store backs it": `@Repository` on an in-memory store with no forced RLS is a gap, not evidence of a built feature.
