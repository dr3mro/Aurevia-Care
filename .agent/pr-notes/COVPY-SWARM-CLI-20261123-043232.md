## Lessons for workers

- `contextlib.redirect_stdout` is a plain context manager, not a mock patcher: in a
  `setUp` that uses `addCleanup`, capture streams with
  `mock.patch("sys.stdout", new_callable=io.StringIO)` and call `.start()`.
- A coverage exception arc such as `[3813,-3813]` or `[3919,-3919]` is only closed
  when an exception is raised BY that attributed line. Patch the callee on the
  line itself (`load_slots`, `monitor_assign`), not a file read on the line before.
- Read the implementation before asserting output: the `monitor-select` daily guard
  uses a bare `return` (so `main` returns `None`), `repair_task` titles are
  `Repair main: <name> failed`, and the log only replaces its own ``` fences with
  ''' while the ` ```text ` template fence remains.
- `coverage` is absent from this worker image and neither `pip`, `python3 -m pip`
  nor `ensurepip` is available; `apt-get update && apt-get install -y
  python3-coverage` (6.5.0) works. `.coverage` is tracked, so restore it with
  `git checkout -- .coverage` after manual coverage runs.
- For a test-only change the changed-line gate is vacuous; prove the work with a
  scoped filter of the coverage JSON (missing lines/branches inside the owned
  ranges must be empty) and paste both the scoped result and the whole-file
  report into the notes.
