## Lessons for workers

- In a plain `.ts` spec test that must render `I18nProvider`, the provider declares `children` as a required prop: createElement varargs alone fail typecheck, while an inline `children` prop fails `react/no-children-prop`. Build the props object as a variable, as `tests/spec/localization/support-english-arabic-rtl-direction-local-name.test.ts:47-51` does; it is type-safe and not a suppression.
- For an "every screen" clause, a filesystem source scan anchored to `import.meta.url` makes an honest active gap tripwire that fails when the gap is closed. Document the exact tokens and file list it pins, so a later refactor is not mistaken for a regression.
- Frontend definition of done is `bash apps/staff-web/check.sh` (gen:api:check, typecheck, lint, build, gzip, 100% coverage), not bare Vitest. A successful `tsc --noEmit` prints only the npm banner, so paste the command and its exit status as evidence.
- Reuse the synthetic fixtures and render helpers of the page's existing test rather than inventing a new harness; it keeps the spec test small and the browser event exercise faithful to the real listener.
