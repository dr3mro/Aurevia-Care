## Lessons for workers

- For a test-only clause proof, a green test passes by construction; prove it is
  non-vacuous with a temporary fault in your own assertion (red), restore it,
  then run the full module gate (green). Never touch production to manufacture red.
- `scripts/check-constraints.py` rejects added `it.skip`/`.only` in TypeScript,
  so the task's "mark a missing behavior `it.skip('GAP: ...')`" fallback cannot be
  used in a merged worker change: when behavior is missing, record the gap in the
  clause note and stop instead.
- The whole-requirement product clause note can lag the code. Verify the current
  installed-page wiring with a targeted read before repeating a "placeholderAction"
  gap claim in a new clause note.
- Patient-mobile has no database. The versioned confirm client's mocked Transport
  plus the installed-page Jest tests are the correct fixture and reachability
  seam; no DB setup belongs in a patient-app clause test.
