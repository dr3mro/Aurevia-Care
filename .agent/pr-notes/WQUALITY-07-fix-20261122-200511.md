## Lessons for workers

- When a PR is red from a defect outside the story scope, do not "fix" it by editing a protected
  path from a worker branch: that gets the PR held for a person and does not unblock it. Record
  the exact failing command, the exact fix and the authorized landing path in the notes and file
  a `task-requests` entry instead.
- Two tests that mock `Path.is_dir` to `True` but not the downstream `usable_reports()` will
  hit the real filesystem; mock both OR use a real `TemporaryDirectory`. Keep the failing-class
  assertion intact so the test still proves the gate behaviour it was written for.
- A documentation-only diff needs no code reviewers: `check-verdicts.py` prints
  `only documentation changed; nothing to review`. Do not fabricate GO lines for reviewers that
  were not run.
