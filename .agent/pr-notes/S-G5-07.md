## Defects found and disposition

1. **Documentation/code mismatch (found and fixed this attempt).**
   `docs/operations/s_g5_07/environment-and-fixtures.md` claimed that identifiers are compared with exact
   string equality with "no ... whitespace trimming ... applied to the comparison (values are stripped only
   to detect a blank declaration)". A direct probe confirmed the evaluator instead appends `value.strip()`
   to the distinctness lists, so a whitespace-padded duplicate is treated as a duplicate and fails closed.
   The code behaviour is the safer one (it prevents whitespace aliasing), so it was kept; the documentation
   was corrected to state the actual behaviour. Two regression tests were added to pin it:
   `test_whitespace_variant_account_is_treated_as_a_duplicate` and
   `test_whitespace_variant_resource_is_treated_as_a_duplicate`. Test-first note: the behaviour was already
   fail-closed in the delivered implementation; the new tests lock it in and the doc fix removes the
   misleading claim, rather than changing a security decision. Documented test count updated 59 → 61 in
   `README.md` and `evidence-contract.md`.

2. **Pre-existing repository tooling failures (out of scope, not modified).**
   `python3 -I -m unittest discover -s scripts/tests -q` reports 5 failures / 4 errors on the base commit:
   - `test_fast_tier` and `test_workflow_concurrency` cannot import `yaml` (`ModuleNotFoundError`) — local
     Python lacks PyYAML; the CI image installs it.
   - `test_swarm.PlanTests` (`test_open_spec_tasks_are_dispatchable`, `test_label_editing_jobs_have_issues_write`,
     `test_workflow_permissions_use_only_valid_scopes`) and `test_agent_run.AgentRunTests` (2) and
     `test_java_conventions.JavaConventionTest` (2) assert on repository state/other modules unrelated to
     this scope; the `3 not >= 10` assertion reflects the live swarm tracker state.
   These are recorded, not fixed: they are outside `infra/s_g5_07` / `docs/operations/s_g5_07` and are the
   integrator's / owning workers' concern. None touches this story's code.

  rejected a self-attesting environment manifest as vacuous. Real verification remains a cloud/human-gated
  G5 item; no vacuous manifest was introduced.

  documentation, rather than weakening the comparison to match the old wording.
