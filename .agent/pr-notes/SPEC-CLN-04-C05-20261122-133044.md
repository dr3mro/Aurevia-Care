## Lessons for workers

- For CLN-04 clause tests, the implementation lives in `clinical.templates` (domain service + `InMemoryTemplateStore`), not `chart/record`; reuse the fixtures and style of `TemplateNoteAcceptanceTest` and `TemplatePersistenceTest`.
- Check `git ls-files -v opencode.json` (flag `S`) before treating any `test_check_pack` / `check-pack.py` "stale" failure as your own; verify the committed profile with `git show HEAD:opencode.json` and leave the worktree file and protected generator scripts untouched.
- `scripts/check.sh` delegates to the full module gates; per AGENTS.md a swarm worker should run targeted `-Dtest=...` suites plus the individual policy scripts and leave the full gate to the integrator.
