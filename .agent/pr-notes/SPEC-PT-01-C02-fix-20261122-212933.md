## Lessons for workers

- A fix pass must not assume the debugger report reached it: verify whether the hand-off actually
  contains the report, and re-delegate the diagnosis if it does not.
- Check `python3 -I scripts/check-constraints.py --require-base` before adding any `@Disabled` to a
  Java file: the added-line rule rejects it even when the story asks for a GAP placeholder. Preserve
  the complete test in the notes instead of shipping a gate-breaking skip.
- For a service + real-PostgreSQL evidence test, re-read the episode version after every successful
  write; failed writes do not bump it, so one precondition can serve several negative assertions.
- Use a distinct database name and UUID scale key/referral id per test class and per method, because
  the integrator runs all `@Tag("integration")` suites in one Maven invocation.
- The domain approver is `CLINICAL_GOVERNANCE`, not `TENANT_ADMIN`; copying an admin actor into
  `approveOutcomeScale` fails with 403 before the assertion under test is reached.
