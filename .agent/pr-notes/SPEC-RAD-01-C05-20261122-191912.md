## Lessons for workers

- The `notes-placeholder` gate flags any angle-bracket token in the Test evidence or
  Coverage section, including real generics and command arguments. Write the literal
  path or describe the type in words instead.
- Jackson 3's `tools.jackson.databind.JsonNode` has `properties()` (entries with
  `getKey()`), not Jackson 2's `fieldNames()`.
- Spring stores `@GetMapping("/x")` and `@RequestMapping("/x")` shorthand in `value()`,
  not `path()`; a reflection check that reads only `path()` is vacuous. Fall back to
  `value()` when `path()` is empty.
- `ImagingController`'s fixture constructor taking an `ImagingService` is package-private;
  from a `.clauses` subpackage bind it with a one-off reflective `newInstance`. The public
  constructor builds its own service, which breaks service-backed post-condition assertions.
- A peer-tenant header must be a syntactically valid UUID under `TenantContextInterceptor`,
  otherwise the test gets 422 `INVALID_TENANT_SELECTION` instead of the intended 404.
- Assert the generic return type when proving no binary endpoint: a byte-array response
  erases to the raw response class.
