## Lessons for workers

- Re-verify earlier passes' green claims with your own commands; do not treat
  notes as execution evidence. This pass did so and confirmed 100% coverage.
- Distinguish three failure classes before editing code: in-scope defects (fix
  them), out-of-scope/owner decisions (hand off, never edit), and
  environment/protected artefacts (document, never regenerate or edit).
- In this cloud worker `opencode.json` is the CI profile under `skip-worktree`.
  Compare the worktree file, `git show HEAD:opencode.json` and both generator
  outputs before believing a `check-pack` failure.
- A test that mocks `Path.is_dir` → `True` without creating the directory will
  fail with `FileNotFoundError` on a clean checkout; reproduce on a clean reports
  directory before attributing it to the current branch. This is the precise
  reason BUILD-41 keeps bouncing back, and it lives in protected `scripts/tests/`.
- A `worker_gate` "scope" violation on `contracts/openapi/missing-routes.txt` for
  a controller-adding story is a scope-definition defect, not a missing fix:
  reverting the baseline simply converts the deviation into a hard route-parity
  failure.
