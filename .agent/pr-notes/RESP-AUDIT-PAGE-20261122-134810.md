# RESP-AUDIT-PAGE — Staff web: responsive `AuditPage` (features-admin)

## Summary

Re-dispatched verification of a task whose implementation was already completed and merged. The scoped change (commit `972d9c6a`, PR #732) made `AuditPage` responsive at every supported width (320–1280 px) in LTR and RTL without changing behaviour, text, API calls or exported names. It uses the shared `page` grid (logical safe-area gutter, `minmax(0, 1fr)`), `stack`, `grid-2` and `cluster` classes from `apps/staff-web/src/theme/responsive.css` and reads the active band from `useBreakpoint`; five filter fields stack on phones and take two columns from medium, and every audit value stays in the tree with wrapping room (`data-audit-page`, `data-breakpoint`, `data-audit-part`, `data-audit-fields` hooks). A new responsive test mocks `matchMedia` for compact/medium/expanded, asserts structure, labels, roles, DOM keyboard order and the Arabic RTL case, and reads the stylesheet as a text proxy. This run re-verified the current HEAD state: the two scoped test files pass (34/34), `tsc --noEmit` is clean, and `AuditPage.tsx` is 100% covered on all four metrics. No source change was needed; this run changes no production file.

## Lessons for workers

- `responsive.css` wraps `.app-shell > *`, `.cluster > *`, `.stack > *`, `.grid-2 > *` and `.card-list > *`, but has no `.page > *` rule and no `.audit-filters`/`.audit-events` class. Do not edit the stylesheet from a page story; wrap children in `stack`/`cluster`/`grid-2` and record the missing rule for a stylesheet story.
- `Form` switches its inner grid to two columns only when it has >6 fields; the audit form has 5, so a `grid-2` div around the fields supplies the phone-stacking/medium-two-column behaviour without changing `Form`.
- Reuse the `matchMedia` stub pattern from `tests/components/ApiPage.responsive.test.tsx` (one state object per query, `addEventListener`/`removeEventListener`) so `useBreakpoint` listeners can be fired deterministically inside `act()`.
- In a Vitest jsdom module `import.meta.url` is not a `file:` URL; use `dirname(fileURLToPath(import.meta.url))` + `join` to read the stylesheet, as the scoped test does.
- When asserting CSS from stylesheet text, account for grouped selectors (`.app-shell > *, .cluster > *, .stack > *, … { … }`), not a standalone `.stack > *` block.
- A re-dispatched worker may find the task's code already merged in HEAD. Verify the scope in isolation (targeted Vitest, `npm run typecheck`, a `reportOnFailure` coverage probe) instead of redoing the work, and distinguish pre-existing module-gate failures from ones you caused by checking whether the failing files are outside your scope.
- Vitest writes no `coverage/coverage-summary.json` when tests fail; pass `--coverage.reportOnFailure` for a scoped coverage probe, and read the per-file numbers rather than trusting the global threshold failures for unrelated files.
