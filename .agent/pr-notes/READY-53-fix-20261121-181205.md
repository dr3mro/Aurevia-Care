- **Pre-existing, out-of-scope doc failure (tool evidence).**
  `python3 -I scripts/check-docs.py` fails on
  `docs/reference/partner-api-guide.md:200`. The stricter table validation added
  by WFAUDIT-07 (`scripts/check-docs.py`, commit `32151eab`, 12:32) counts an
  unescaped `|` inside the code span `` `status=open|resolved` `` as an extra cell
  (`_cells()` only ignores `\|`, not pipes inside inline code). The file was added
  by START-13 at 12:16 and is unchanged in HEAD, in the merge-base `31a61fe6`, and
  in current `origin/main` (`41c43d64`, 18:11). It therefore fails on main too and
  is not caused by this story. Fixing it requires editing `docs/reference/` (or the
  maintainer-owned checker), both outside this task's declared scope; a
  task-request is included below.
- **Expected cloud-worker artifact.** `check-pack.py` reports `opencode.json` stale
  because the swarm runner copied the CI profile under `skip-worktree` (`git ls-files -v`
  = `S`). `git diff -- opencode.json` is empty and AGENTS.md forbids editing it;
  left untouched.
- **Environment note.** Root `npm run typecheck` initially failed with `TS2307`
  for `react-native`/`@testing-library/react-native` in
  `apps/patient-mobile/src/**`; causes were absent patient-mobile dependencies,
  not source errors. After `npm ci` in `apps/patient-mobile`, root typecheck is
  clean. No patient-mobile source was changed.
- No patient data, MRN or chart data appears in any page, test, log or note. All
  contact addresses use the reserved `example.invalid` domain.

## Lessons for workers

- Before treating a dispatched fix pass as a real code change, re-run the full gate
  set for the declared scope from a clean `npm ci`. In this pass the story's own
  gates were already green; the only red checks were pre-existing defects in files
  owned by other tasks or cloud-worker measurement artifacts.
- Run `npm ci` in `apps/patient-mobile` before root `npm run typecheck`; the root
  tsconfig includes patient-mobile sources, so their React Native types must be
  installed or unrelated `TS2307` errors appear.
- The `check-docs.py` table-cell rule counts pipes inside inline code spans. When
  adding a table cell containing a literal pipe, escape it as `\|` or keep the pipe
  out of inline code.
