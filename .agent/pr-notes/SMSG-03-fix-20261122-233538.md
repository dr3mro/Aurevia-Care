## Authorization boundaries and audit events

Tenant and actor come only from `TenantContext.current()`, which fails closed with 403
when unbound; no request record carries an organization or actor field. Every command
re-checks active staff membership and roles through `activeStaff`, and facility scope
through `facilityWithinScope` against the V93 fold, for the actor and each peer at open,
each peer at group creation, the new subject at add, the caller in `requireAccess` (send,
markRead, messages, add, remove) and in both list endpoints. A still-open participant row
is not proof of a current staff role, so a revoked membership loses access on the next
request. The fold's facility argument is the tenant's database facility code, not
request-body input; a facility absent from the tenant fails closed. A former member still
sees history up to `left_at` but is refused on writes and cursor advances.
Cross-organization access is concealed as 404 by forced RLS. The controller passes the
idempotency header only; sender and role are bound by database triggers. No audit event
type was added or changed, as MSG-07 audit is a separate task.

## Migration and rollout considerations

No migration to deploy. The endpoints are additive after V91 and V93 and need no lock or
backfill. The tightened active-staff and facility checks only narrow access, matching the
app-wide IAM-01 zero-staleness policy. Read cursors restart empty on process restart, a
documented limitation that does not affect the immutable ledger.

## Lessons for workers

- The hand-off note is itself a gated artifact. Paraphrase failure output in
  `Test evidence` and `Coverage` without angle-bracketed exception names or type tokens,
  because `worker_gate.py` treats them as unfilled placeholders. Do not respond by
  narrowing the placeholder regex — that check was deliberately requested by
  `WQUALITY-03`; write a clean note instead.
- An open participant row is not proof of a current staff role. Re-check active
  membership on every command and list, not only when a conversation is opened.
- A controller mocked in one test and a real service called in another is not
  reachability. Drive one request through the controller, service and store into real
  PostgreSQL and assert a durable row.
- When adding a boolean collaborator check to a guarded method, add a default-allow stub
  in the test setup and override it per negative test.
- In a cloud worker, confirm `git ls-files -v opencode.json` before treating a
  check-pack or generator staleness failure as a change defect, and leave the full
  `mvn verify` and all-integration run to the integrator.
