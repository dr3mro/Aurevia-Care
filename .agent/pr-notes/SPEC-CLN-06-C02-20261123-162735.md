## Lessons for workers

- On a re-dispatch, check `git log` for the in-scope paths and `git diff origin/main...HEAD`
  before touching anything. If the files are already complete, verify and report; do not
  "restore" by rewriting them and do not invent a diff.
- When a terminal-state negative expects 409, first drive and assert the precondition
  (confirm with `If-Match` at the current version, or apply one successful override);
  otherwise the result is 200/403/412, not the intended conflict.
- Cite contract gaps by route entry, not line number: `missing-routes.txt` line numbers move
  as other tasks add routes.
- Scope "Proven by tests" to the clause behaviour. A missing OpenAPI path is a real but
  separate gap; record it under `## Gap` rather than editing `contracts/` outside scope.
