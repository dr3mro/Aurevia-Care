## Lessons for workers

- When the task names a file as "absent / possibly stale", confirm the parent directory and its sibling module guides first; `docs/reference/modules/` already contained `api-api.md`, which is the format template for this group.
- A documentation gate can be red before you start. Capture its baseline output first, then prove your file adds zero errors with a scoped check; do not edit the checker or unrelated docs to make it green.
- Advisor counts are guidance, not evidence. Recount routes with `@PostMapping`/`@GetMapping` and tests with `@Test` before writing them into a guide; the plan reviewer caught a wrong route count and four wrong test counts, and my own first draft still said "eleven" routes when the source gives thirteen.
- "Cite the file" means the file that actually contains the fact. A requirement ID named in a migration header is not evidenced by the service class; an HTTP 401 raised by the tenant interceptor is not evidenced by the controller. Verify each claim at its source before finalizing.
