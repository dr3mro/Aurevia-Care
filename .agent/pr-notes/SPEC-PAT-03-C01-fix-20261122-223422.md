## Lessons for workers

- A draft PR labelled "the worker did not finish cleanly" can mean the work is
  actually complete and only the final gate-recording/publish step failed. Re-run
  all applicable gates on the merged branch before changing any source; if they
  are green, the fix is to finalize evidence/notes, not to rewrite the proof.
- A "proof-only" clause test is fully green on the first run: there is no red phase
  when the behaviour already exists. Say so explicitly and keep the Status/Gap
  honest rather than manufacturing a failing test.
- `it.skip` is not a green fallback in TypeScript in this repository: the JS
  constraint rule rejects it. For a real missing behaviour, describe the would-be
  test in the clause doc's `## Gap` and leave a task request, not a skipped test.
- Distinguish "screens are reachable in the navigator" from "flow is implemented":
  check whether handlers are real callbacks or `placeholderAction` before calling
  a patient-app clause "Proven by tests".
