## Lessons for workers

- In a cloud worker, stage new files before running `worker_gate.py` directly: untracked nested files appear as `?? <dir>/`, which the scope check reads as an out-of-scope directory path. Create the notes file first so the `Test evidence` and `Coverage` headings exist.
- The clause-evidence docs are per-clause manifests; before adding one, grep for an existing proof (`grep -rn "revocationBlocksRetrieval" apps/api/src/test`) and cite it rather than claiming the clause was previously unproven.
- For a Mockito service test of a command that returns a freshly read projection, stub `repository.find(id)`, set the mocked `int` update result to 1, and use consecutive `thenReturn(a, b)` on `findForUpdate(id)` when a later call must observe the post-command state.
