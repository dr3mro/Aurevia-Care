## Lessons for workers

- Never paste a literal Git conflict-marker grep into a notes Test evidence
  section: the worker gate's placeholder detector matches the pipe between the
  marker halves and rejects the note. Describe the check in words instead.
- Install the Playwright browser and its OS libraries before treating an e2e
  story as blocked; a missing system library is an environment issue, not a test
  failure.
- The e2e files sit outside the module `tsconfig.json` include, so `npm run
  typecheck` does not check them. Run an explicit strict `tsc --noEmit` over the
  e2e files as part of the frontend definition of done.
- Remove Playwright's generated output directory before finishing: it is outside
  the task scope and trips worker-gate scope validation.
- In a cloud worker the worktree `opencode.json` is the CI profile under
  `skip-worktree`; validate pack drift against the committed HEAD file, not the
  worktree copy.
