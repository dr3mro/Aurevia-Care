## Lessons for workers

- A `.test.ts` file cannot contain JSX under this TypeScript setup: import `createElement` from `react` and build the element, or ask for the scope to be amended to `.test.tsx` rather than silently renaming.
- Helpers in sibling test files are usually module-local. Redefine minimal local fakes in the new test file; importing another `*.test.ts` re-registers its whole suite. Keep `import type` for types because `verbatimModuleSyntax` is on.
- A plan-reviewer NO-GO is recoverable: fix each Required gap in the plan and re-ask for the verdict before writing code. The first review caught all three of the above before any file existed.
- In this pinned patient-mobile stack `render()` is async (`await render(...)`) and `toHaveTextContent` matches the whole string; assert exact strings and use `--reporters=default --verbose` to capture individual test names as evidence.
- Run `bash apps/patient-mobile/check.sh` as the canonical gate, and add `npm run lint -- --max-warnings=0`; a green Jest run alone is not done.
- `scripts/check-docs.py` also reads Markdown under `.agent/`, so keep notes in the PR-template heading order with backticked paths instead of relative links, and avoid stray code fences or control characters.
- When a global `git grep` finds conflict markers, confirm on `origin/main` and record it as pre-existing and out of scope instead of editing a protected or unrelated file.
