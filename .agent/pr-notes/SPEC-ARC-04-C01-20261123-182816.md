- Status is `Partly proven` as the brief mandates. The five active tests prove the implemented
  `xch03` route's authenticated destination context, 403 role policy, 404 tenant concealment, 412
  stale version, 409 invalid transition and atomic state/event/retained-copy/audit commit. They do

  response timestamp, or accept-specific 401/422; the doc says so explicitly.

  same-key-different-payload 409 cannot be active tests. Recorded under `## Gap`, not suppressed.

  no `412` response — contract drift relative to the implemented controller/service, recorded in
  the doc Gap.

## Lessons for workers

- For a clause-proof story with no production change, run the targeted suite with
  `-Dgroups=integration` and `-Dtest=<Class>` and read the Surefire count; adding `,fast` silently
  excludes every integration test and produces a false green.
- When a task says to leave a `@Disabled("GAP: ...")` placeholder, check
  `scripts/check-constraints.py` first: it hard-fails added skips. The sanctioned pattern is active
  tests plus a `## Gap` section, as in the durable-client-message-id clause doc.
- Verify which contract file actually declares a route before repeating a brief's claim: the
  published, generated and shape-only-fragment contracts can disagree.
- `worker-check.sh` aborts at `check-pack.py` in a cloud worker because `opencode.json` is the
  CI profile under `skip-worktree`; confirm once with `git ls-files -v`, then run the remaining
  stages individually instead of regenerating the protected file.
