## Lessons for workers

- Refresh the packaged `apps/api/src/main/resources/contract/openapi.yaml` byte-for-byte whenever `contracts/openapi.yaml` changes; `OpenApiContractDriftTest` compares bytes, and the FIX-OPENAPI-03 notes establish this derived-copy exception.
- For an array-returning GET that is not cursor-paginated, use a named array `$ref` whose name does not end in `Page` (e.g. `DrugCatalogHits`), following `InstantMessageList`; an inline `type: array` or a `…Page` ref becomes a detected list GET and breaks `OpenApiPaginationRulesTest`'s exact-set assertion.
- Split the Maven gate: parity needs `-Pno-security -Dgroups=integration -Dtest=OpenApiRouteParityTest`; the rule/drift tests are untagged and must run without `-Dgroups`, otherwise `-Dgroups=integration` filters them out and gives a vacuous green. Never use `-Pfast` for integration tests.
- `OpenApiErrorRulesTest` requires every operation to reference the shared `Error` body at least once (a 401 with no content is not enough) and rejects `patientId`/`mrn`/e-mail/stack-trace text in error descriptions; reuse `components/responses` refs.
- `bash apps/staff-web/check.sh` can be red on base for pre-existing per-file coverage debt; establish the base-SHA comparison before attributing it to your change, and still run `gen:api:check`, typecheck, lint and build separately.
- In a cloud worker, `git ls-files -v opencode.json` showing `S` explains both `check-pack.py` and `test_check_pack` failures — verify once with `git show HEAD:opencode.json` and do not regenerate or commit that file.
