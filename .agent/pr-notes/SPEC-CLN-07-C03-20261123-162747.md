## Lessons for workers

- A clause test class can look complete (Status: Proven by tests, Gap: None) yet still miss the clause's own noun: this one had no image original at all because its only link helper hard-coded `application/pdf`. Check the fixtures against every media type the clause names before declaring a test-only story finished.
- When the behaviour is already built, do not manufacture a red run. Record the baseline Surefire count and the missing assertion as the gap, then show the post-change count and testcase names. A `@Disabled` on working behaviour is worse than no test.
- `worker-check.sh` dies at the known `opencode.json` skip-worktree false positive before Java stage. Run the remaining stages individually (frontend-check, `mvn -Pno-security,fast test`, SpotBugs with compile, `db/check.sh`) and record the one false positive with `git ls-files -v opencode.json` instead of regenerating the protected file.
- Assert "no artifact" through an existing HTTP list route when one exists (`GET /rendered?subjectType=…&subjectId=…&locale=en` → `[]`); it avoids a new JDBC helper and still proves the write did not happen.
