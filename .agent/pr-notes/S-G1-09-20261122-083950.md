## Lessons for workers

- For a gate evidence note, cite the concrete merged test class **and method** verified by a file read and `git log`, not a story title or design document — and keep "engineering evidence proven" strictly separate from "human acceptance open".
- `scripts/check.sh` runs the full `apps/api/check.sh` verify/integration suite and is forbidden for workers; for a docs-only change use `python3 -I scripts/check-docs.py` plus `bash scripts/coverage-check.sh` instead.
- Conflict markers can be committed on `main`. Run `git grep -nE '^(<<<<<<<|>>>>>>>) '` and check `git show origin/main:<path>` before assuming your merge introduced them; report out-of-scope markers rather than editing them.
