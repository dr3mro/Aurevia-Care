## Lessons for workers

- For a re-export-only barrel, `Object.keys(module).sort()` in a Vitest test is the direct way to prove "exports X and nothing else"; assert each value is a function (a component).
- V8 coverage reports a pure re-export barrel as 0 statements at 100% — the test's import of the barrel is what proves the entry point; do not add fake code to "cover" it.
- Run the full `bash apps/staff-web/check.sh` rather than assuming the `gen:api:check` drift recorded in older notes persists; in this run it was green end to end.
- When a barrel documents an owning screen, verify the README's import path and every JSX prop against the real component signatures and state that the owning screen is a separate task.
