## Summary

Focused proof test for CLN-04 clause 7: "Allow free text with language, and preserve historical field meanings with each saved version." Added one synthetic JUnit class under `chart/clauses` and the clause evidence document under `docs/spec/clauses/chart`. It is in the neighbour package `apps/api/src/main/java/com/aurevia/clinical/templates`: `TemplateService` (free-text language rule in `validate`, field/dictionary snapshot in `saveNote`, read-back in `savedNote`), `FieldValue` and `FieldDefinition` (language tags), `SavedNoteRevision` (immutable field meanings), `TemplateVersion`, `TemplateNoteRevision`, `BaselineTemplates`, `InMemoryTemplateStore`, `JdbcTemplateStore`. There is no dedicated template controller and no `/templates` route in `contracts/openapi.yaml`, so the domain entry point is exercised directly, matching `TemplateNoteAcceptanceTest` and `it/clinical/TemplateVersioningTest`.

New test class `com.aurevia.chart.clauses.AllowFreeTextLanguagePreserveHistoricalFieldTest`, three tests:

- `freeTextWithLanguageValidatesAndTheSavedRevisionKeepsItsVersionFieldMeanings` — positive: Arabic free text tagged `ar` validates and saves; the saved value and the version-one field definition (`chief concern`, canonical language `en`, type `FREE_TEXT`) survive a later version-two rename and language change, and the frozen snapshot rejects caller mutation.
- `freeTextWithoutALanguageIsRejectedAndCannotBeSaved` — negative (missing input): `language:chiefConcern` violation, `saveNote` refuses with 422 and nothing is persisted.
- `aSavedHistoricalNoteIsConcealedFromAnotherTenant` — negative (another tenant): a clinician of a different tenant gets 404 `NOT_FOUND`.
