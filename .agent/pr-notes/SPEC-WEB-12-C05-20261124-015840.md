## Lessons for workers

- On a re-dispatched story, survey `main`, the prior notes and the scope path
  before writing: if the note already exists and is correct, contribute only
  verification evidence and do not overwrite it.
- A document that records a control as `open`, `not started` or an unchecked
  box is proof of a gap, not proof the control exists. Keep status honest and
  name the human owner (Security with the infrastructure owner here).
- When grepping for `pentest`, use word boundaries; plain case-insensitive
  matching finds `OpenTest` and yields a misleading hit.
- From a file four levels below the repository root, relative links to real
  root/docs files need `../../../../`; reference absent paths as inline code,
  never as Markdown links.
