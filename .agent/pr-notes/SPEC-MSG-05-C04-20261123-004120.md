## Lessons for workers

- Confirm whether a clause is already built before writing the test; an implemented clause needs
  green evidence, not a disabled GAP test or a "Not built" status.
- For SpotBugs, compile first and add `-Dspotbugs.skip=false` when using `-Pno-security`; check for
  `BugInstance size is 0` in the output, not just EXIT 0.
- A second-tenant HTTP negative only proves concealment (404) when the caller is a valid member of
  the other tenant; without that seeding it fails earlier at the role gate with 403.
