Two ordered chains: `@Order(1)` staff-web browser chain matches requests **without** `Authorization: Bearer` and uses `oauth2Login` + HTTP-only/secure/SameSite=Lax session cookie + `CookieCsrfTokenRepository.withHttpOnlyFalse()` (CSRF on); `@Order(2)` bearer chain keeps the AUD-20261120-03 stateless resource-server semantics and stays CSRF-exempt for bearer requests only. Tenant is bound from verified claims by `TenantContextInterceptor` for both `JwtAuthenticationToken` and `OAuth2AuthenticationToken`; a browser principal without the `orgs` claim is rejected 401. No audit event was added or changed by READY-11.
