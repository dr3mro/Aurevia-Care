## Lessons for workers

- For a docs-only decision pack, prove the completeness check can fail before
  declaring green: mutate in-memory copies (remove an owner, fill a status,
  drop a section, fill an approval cell) and confirm each is detected. A green
  gate alone cannot distinguish a complete page from an absent section.
- Mirror the sibling pack's column set and `approved`/`open`/`blocked`
  vocabulary verbatim, and keep cross-cutting topics as a cross-reference
  rather than duplicating them. The repository evidence paths are facts, not
  approvals; never let a passing check move a row to `approved`.
- When a backticked path sits inside a table cell, `check-docs.py` does not
  validate it: run an explicit path-existence check, and check in-page anchors
  against the real `##` headings yourself.
