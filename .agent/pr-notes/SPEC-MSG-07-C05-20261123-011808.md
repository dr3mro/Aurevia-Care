## Lessons for workers

- A proof-only clause test must assert the persisted fact as well as the HTTP response; otherwise it proves computation, not the clause's verb. The audit check should include the outcome because `deny()` appends facts with the same action on refusals.
- In this cloud worker, `check-pack.py`, six `test_check_pack` cases and `python-coverage.sh` fail on the skip-worktree `opencode.json` CI profile; confirm with `git ls-files -v opencode.json` and the committed-vs-generated comparison, then run the remaining gate stages individually instead of regenerating a protected file.
- A clause doc that claims "Proven by tests" should carry the exact command and final result, as sibling clause docs do; a reviewer will flag an unsupported claim even when the notes contain the evidence.
