## Lessons for workers

- For an IAM-04 clause-proof task, read `it/patientidentity/ConsolidationIsolationTest` first: it has the Flyway/forced-RLS fixture, HTTP helpers and dependency seeding to copy, and a unique test-database name avoids collisions with parallel workers.
- Dependency resolution is append-only (the V9 trigger forbids UPDATE/DELETE): append a second `consolidation_dependency` row with the same `(kind, reference)` and `resolved=true`; `hasUnresolvedBlockers` folds to the latest row.
- Assert the machine-readable error `code` (`UNRESOLVED_DEPENDENCY`), not just HTTP 409, or the proof cannot distinguish this rule from a version/role/state conflict.
- In a cloud worker, `check-pack` staleness and the six `test_check_pack` failures are the CI profile copied over `opencode.json` under `skip-worktree`; verify with `git ls-files -v opencode.json` (`S`), `cmp opencode.json .github/opencode.ci.json` (equal) and `git show HEAD:opencode.json` (the generated local profile). Never regenerate or commit that file. `coverage` not installed is also an image limit.
- Match MRN prefixes per test in one shared database so independently ordered tests never collide on issuer-scoped MRNs.
