## Lessons for workers

- When a clause test needs to verify partner status before a retry, transmit with outcome
  `"ambiguous"`: verify-partner-status requires `State.AMBIGUOUS`, so a `"submitted"` transmit yields
  409 `INVALID_TRANSITION` before the retry can reuse the id.
- This Spring version's 422 enum constant is `HttpStatus.UNPROCESSABLE_CONTENT`, not
  `UNPROCESSABLE_ENTITY`; assert the numeric/code contract, and expect a test-side fix if the enum
  name differs.
- `-Pno-security` skips SpotBugs as well as OWASP; use the default profile with `-Dowasp.skip=true`
  and compiled classes for a non-vacuous SpotBugs check.
- A per-class test database name (not the flow test's fixed `smartclinic_rx02_it`) prevents parallel
  collisions; copy the seed/HTTP helpers but keep the proof narrow and clause-named.
- Assert both HTTP status and error code on every negative case; code-only assertions pass on an
  unexpected status that happens to share the code.
- Confirm-worktree `opencode.json` staleness once (`git ls-files -v` → `S`) and run later gate stages
  individually instead of editing the protected file or repeating the diagnosis.
