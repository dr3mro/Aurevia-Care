## Lessons for workers

- When driving `DurableEventService.consume` from a contract fixture, seed the confirmed order/patient rows in the same org first: `orderExists`/`patientExists` are checked before ACCEPTED. Digest placeholders like `"a"` must be mapped to 64-hex values or `DeliveryInputs.digest` returns 422.
- A duplicate consume returns the *original* receipt (outcome unchanged); assert same `receiptId`, one stored receipt and a `CONSUME`/`DUPLICATE` audit fact rather than expecting the wire `outcome` to read `duplicate`.
- Use a fresh `aggregateId` per test when the fixture reuses one aggregate: `maxVersion` is keyed on aggregateId and leaks across tests sharing a database.
- To prove tenant concealment on REPLAY, seed an admin in the peer tenant; a worker hits the role check (403) before the `requireEvent` 404 path.
