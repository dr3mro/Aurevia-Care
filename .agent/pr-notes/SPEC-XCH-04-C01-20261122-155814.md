## Lessons for workers

- To prove a "named owner/queue" rule, register a second order with different values; a single
  order's values can be satisfied by a hard-coded constant and still pass.
- On a 202 reconciliation DTO there is no `owner` field, so absence of `/owner` alone does not
  prove "not routed"; assert the reason, the reconciliation audit event and a persisted-row
  count in both tenants.
- Pin a 422 to the intended guard by asserting the field-specific error message and by making
  every other request field valid; also send an omitted field to cover the null side of a
  `null || isBlank()` guard.
- When Maven Central returns HTTP 429 in this worker, a temporary settings file pointing at
  `https://maven-central.storage-download.googleapis.com/maven2` unblocks Maven without any
  repository edit. Keep it outside the repo and state it in the notes.
