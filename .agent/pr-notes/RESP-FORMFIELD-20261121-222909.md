## Lessons for workers

- `.stack > *` in `apps/staff-web/src/theme/responsive.css` already supplies
  `min-inline-size: 0` and `overflow-wrap: anywhere`; label and error are direct
  children, so they wrap without a new class or inline style. Prefer the existing
  class over duplicating wrapping rules.
- Never set `direction: rtl` on a subtree: RTL mirroring comes from document
  `dir`/`lang` plus logical properties. For coarse targets use the existing
  `.touch` class rather than a JS-computed min-height.
- A prior worker's "check.sh is red" note can go stale on a fast-moving `main`.
  Re-run `bash apps/staff-web/check.sh` at the start of a re-attempt before
  assuming the old blocker still applies; here the generated-client drift had
  been fixed by `1ed17b2f` and the whole gate was green.
- `git grep` for conflict markers can surface pre-existing committed markers in
  unrelated files after a clean `Already up to date` merge. Confirm `git status`
  is clean and the merge did not stop with conflicts before treating them as your
  own; note them for the owning task rather than editing outside scope.
