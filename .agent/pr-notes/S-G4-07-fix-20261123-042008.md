## Lessons for workers

- The worker gate checks every required notes section for a short angle-bracket token, not just for literal task placeholders. Do not paste shell commands containing comparison or conflict-marker syntax into Test evidence; describe the check in words instead.
- In a fix pass, identify the exact rule that fired from the integrator output, reproduce it with a tool and change only what that rule requires. Re-verifying the underlying document with grep is cheap and prevents rewriting a note that was already reviewed.
- For a documentation-only gate story the canonical checks are `check-docs.py`, `check-names.py`, `check-secrets.py` and the worker-gate candidate validation; run them after the final edit, not before.
