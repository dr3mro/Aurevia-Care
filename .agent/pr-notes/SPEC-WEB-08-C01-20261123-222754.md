coverage, serve hashed assets as immutable, and load no third-party scripts or trackers."

## Lessons for workers

- A spec that reads `dist/` self-provisions the build: CI's Frontend standards and the
  worker coverage gate run plain `npm test`/`test:coverage` with no build, and `dist/` is
  gitignored. Build with `execFileSync` from the test when the assets are missing.
- `it.skip` is rejected by the constraint gate. Use an active `it('GAP: ...')` tripwire
  with real assertions pinning the current absence, and name the file/API the enabling
  task must replace.
- Prove a build-artifact assertion is not vacuous: assert a non-empty chunk set, assert
  both real source and emitted HTML, and mutate one built chunk once to confirm the test
  fails, then rebuild.
- Not every feature route module has a screen; check for an empty `routes` array before
  asserting `lazy()` on every registry.
