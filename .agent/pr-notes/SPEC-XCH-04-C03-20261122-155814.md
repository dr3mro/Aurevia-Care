## Lessons for workers

- For a clause-proof task where the rule is already built, a mocked repository stub cannot prove tenant
  concealment: only a two-tenant PostgreSQL HTTP test with real FORCE RLS can. Cite the real DB row counts.
- In a shared-DB integration class, create the entries inside the queue-read test and assert the **returned
  entry ids** are present; never rely on JUnit method order or on another test's state.
- Assert the `code` field rendered by `ApiErrorHandler` (`FORBIDDEN`, `INVALID_STATUS`) as well as the HTTP
  status, and pair every refusal with a "no row was written" count assertion.
