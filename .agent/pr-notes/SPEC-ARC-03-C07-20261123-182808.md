## Findings

- The advisor brief's SpotBugs command (`-Pno-security -DskipTests compile spotbugs:check`) is vacuous in this repository because `no-security` sets `spotbugs.skip=true`. The real check needs `-Dspotbugs.skip=false`; with that override SpotBugs ran and reported zero bugs. Brief corrected in evidence, not followed blindly.
- Six `test_check_pack` failures and the `worker-check.sh` stop are the documented skip-worktree CI-profile artifact (OPS-CW-003-01), verified from `git ls-files -v` and the HEAD blob comparison. No protected file was changed.
- The production rule compares `existing.draftId()` with the incoming draft; `PlacedOrderRequest.canonicalPayload()` is stored on the order but is not compared on replay. Distinct drafts are immutable payload snapshots, so the clause holds for this surface. The digest-comparison wording elsewhere in ARC-03 is a latent separate concern, not a defect in clause 7; no production change or task request is raised here.
- Plan-reviewer Optional suggestions were adopted: the conflict proof asserts the two payloads differ and that the first payload wins; the role and stale-version retries reuse the SAME key; the clause document names the actual mechanism.
- Code-reviewer Optional fix adopted: the 412 is attributed to `OrderPlacementService.requireVersion`, not to `IfMatch.parse` (which raises only 428/422).
- Test-engineer Optional fixes adopted: the clause document no longer claims the peer case proves caller scoping (it varies only the organization), and the sub-agents that wrote the notes disclose that "no second order" is inferred from the conflict path preceding every write plus the fresh-key/draft-consumption checks.
- The full integration suite reported six context-load errors in an unrelated class because a nested test class file was momentarily absent from `apps/api/target/test-classes` while other Maven commands were running against the same worktree. The class passes alone (6/6), and `db/check.sh` passes; no production or test file of this change is involved.

## Lessons for workers

- With `-Pno-security`, always add `-Dspotbugs.skip=false` to a `spotbugs:check` command; otherwise the profile skips the analysis and a green result proves nothing.
- A `check-pack`/`test_check_pack` failure in this cloud worker is the CI profile under skip-worktree. Confirm once with `git ls-files -v opencode.json` and the HEAD blob versus generator render, then run the other gate stages individually; never regenerate or commit `opencode.json`.
- For clause-proof documents, describe the implemented mechanism precisely. Saying "different payloads conflict" is accurate here only because each draft is an immutable payload snapshot; do not imply a digest comparison that the code does not perform.
- Do not run Maven commands concurrently against one worktree: a background integration run saw a transiently missing compiled nested class while targeted `mvn test` runs rebuilt `apps/api/target/test-classes`. Re-run the failing class alone before blaming the change.
