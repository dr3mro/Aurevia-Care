## Lessons for workers

- In a plain `.ts` Vitest spec, `I18nProvider` requires `children` in its props.
  `createElement(I18nProvider, { initialLocale: 'en' }, view)` fails TS2769, and
  putting `children` literally in the props object fails `react/no-children-prop`.
  Build a typed props object (`{ initialLocale: Locale; children: ReactNode }`)
  and pass it as the single props argument.
- For a spec-clause proof over behaviour already on `main`, there is no red
  phase: the missing acceptance evidence is the test itself. Make the negative
  refusal test the discriminating proof, and say plainly in notes that no
  production code changed.
