## Summary

Adds the ARC-07 clause 1 acceptance proof: one conversation is bound to exactly
one recipient care unit and one verified patient connection. A real-PostgreSQL
HTTP integration test drives the existing `POST /api/v1/conversations` and
`POST /api/v1/conversations/{id}/reply` routes with synthetic tenants, staff,
patients and connections, using the production JDBC messaging store (no
in-memory override). Positive and negative cases assert the stored binding and
the refusals for a wrong unit, another tenant, a revoked connection and a stale
version. A clause evidence document records the source survey, status and gap.

## Affected requirements

ARC-07 (clause 1). Adjacent: ARC-02, ARC-03, ARC-04, MSG-01, MSG-02, MSG-07, OPS-02.

## Lessons for workers

- A real JDBC connection fixture needs both the V33 `patient_link` fold and the
  V10 `patient_account` + `account_chart_link` event: `ConversationService` reads
  `patient_link_active`, while `CareUnitDirectoryService.verifiedCharts` reads
  `public.current_chart_links()`. Seeding only one yields 403/404 that looks like
  a production defect but is a fixture gap.
- The two existing conversation HTTP tests install a `@Primary InMemoryMessagingStore`.
  To prove tenant/connection rules under forced RLS, omit that override, seed
  `care_unit` / `eligible_relationship` / `patient_unit_connection` in SQL and
  assert `MessagingStore instanceof JdbcMessagingStore` in the test.
- Give every stateful test its own connection id and `context_reference`
  (V60's uniqueness key), and assert no-write with before/after row-count deltas:
  the shared database is not cleaned between tests and V33 triggers forbid
  deleting the append-only rows.
- To prove identities are server-derived, a positive assertion that echoes the
  request is not enough; add a negative where a valid caller uses another
  verified patient's connection (404), in addition to the wrong-unit case.
- Do not claim an unscoped clause status: for this clause the staff-caller path
  skips connection verification, so the honest status is `Partly proven` even
  though every written test is green.
