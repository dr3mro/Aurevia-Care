## Lessons for workers

- For evidence notes, a document that records a control as `open`, `not started`
  or an unchecked box is proof of a gap, not proof the control exists. Keep the
  status honest and name the human owner.
- When grepping for `pentest`, add word boundaries: plain case-insensitive
  matching finds `OpenTest` and produces a misleading hit.
- From a file four levels below the repository root, relative links to real
  root/docs files need `../../../../`; reference absent paths as inline code,
  never as Markdown links.
