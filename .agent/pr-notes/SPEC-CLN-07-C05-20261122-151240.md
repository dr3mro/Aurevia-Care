## Lessons for workers

- `HttpStatus.UNPROCESSABLE_ENTITY` does not exist in this Spring version: status 422 is named `UNPROCESSABLE_CONTENT`. Assert `response.getStatusCode().value()` (a number) when a test only cares about the wire status, and assert the error `code` separately.
- Text inside the generated PDF is UTF-16BE hex, upper case, inside `<…>`; `/FontFile2`, `/PrintScaling /None` and `%PDF-1.4` are literal ASCII. Decode bytes with ISO-8859-1, never UTF-8, or binary bytes are corrupted before the assertion.
- `DocumentService.render` validates every input field before it authorizes, so a role-denial test must send a fully-formed command; otherwise 422 masks the intended 403. Locale validation needs a valid `subjectType` and `subjectId` before it returns `INVALID_LOCALE`.
- In a cloud worker, `git ls-files -v opencode.json` showing `S` explains `check-pack.py`/`test_check_pack` failures: verify with `git show HEAD:opencode.json` and move on instead of editing the protected file. Do not re-diagnose it on a later pass.
