## Lessons for workers

- Measure a shared script with `coverage json` filtered to your assigned line range: the whole-file
  percentage hides which part owns a gap, and sibling commits can move the live numbers.
- If a branch sits after an exhaustive `if/elif` over a closed return set, it is dead code. Do not
  patch the helper to return an impossible value just to colour the arc; declare the line with the
  exact production fix and stop. Three reviewers independently rejected that approach here.
- A `task-requests` scope cannot name `scripts/*.py`, a workflow or an agent file. For a required
  production edit, write the precise change in Findings and "Why this is not finished" for a
  person instead of filing an unusable request.
- `coverage` rewrites the tracked `.coverage` file; always set `COVERAGE_FILE` to a temporary path
  and confirm `git status` shows only the scope file before committing.
