# BUILD-23 — Serve the OpenAPI contract from the API at /api/v1/openapi.yaml

## Summary

Added `GET /api/v1/openapi.yaml` returning the exact `contracts/openapi.yaml` bytes with `Content-Type: application/yaml`. The API serves a packaged classpath copy (`apps/api/src/main/resources/contract/openapi.yaml`); a build-time drift test fails when that copy differs from the authoritative repository file by even one byte. The route needs no sign-in, carries no tenant or patient data, and still passes the instance-local rate limiter and the browser-defence headers filter. Both production security chains permit the exact GET path; the tenant interceptor admits the route without a subject while retaining the limiter under a shared anonymous key.

Entry-point-to-test trace: `GET /api/v1/openapi.yaml` → `OpenApiContractController.contract()` → classpath `contract/openapi.yaml` → `OpenApiContractControllerTest.servesThePackagedContractAsYaml` and `OpenApiContractHttpTest.anonymousRequestReturnsAuthoritativeYamlWithSecurityHeaders`. Drift gate: `OpenApiContractDriftTest.packagedContractMatchesTheAuthoritativeSource`. Rate limit: `OpenApiContractHttpTest.publicContractRouteRemainsRateLimited`; OIDC-chain admission: `OpenApiContractHttpTest.bearerRequestIsAlsoPermitted`.

## Affected requirements

- SMARTCLINIC_V1_SPEC.md section 7 (generated OpenAPI client types): the API now publishes the authoritative contract over HTTP so generated clients can discover it; the drift test keeps the served copy identical to the source used for client generation.
- WEB-02 (security headers), WEB-04 (rate limiting), WEB-05 (unauthenticated exact routes) are preserved; no requirement ID was renamed or added as a code/package name.

## Authorization boundaries and audit events

- Security: `GET /api/v1/openapi.yaml` is the only newly permitted route, added as an exact GET matcher to both `SecurityConfiguration.oidcSecurityFilterChain` and `StaffWebLoginConfiguration.staffWebSecurityFilterChain`. No `/api/v1/**` wildcard was opened; the fixed-path nature is proven by `SecurityFilterChainHttpTest.protectedRouteStillRequiresAuthenticationWithBothChains` (regression batch green).
- Tenant boundary: `TenantContextInterceptor` short-circuits only this exact URI and binds no `TenantContext`; every other `/api/v1/**` request keeps the existing subject/organization validation.
- Rate limiting: the anonymous route consumes an allowance under the stable key `anonymous:openapi` (no identity or patient data), so the instance-local 600/minute default still applies; the HTTP test pins a 1-call limiter and proves 429 + `Retry-After: 60`.
- Audit events: none added; the route performs no state-changing operation.

## Lessons for workers

- Read the task's `scope` literally: the security chains and tenant interceptor were all inside `apps/api/src/main/java/com/aurevia/smartclinic/web`, so the route could be made genuinely public without touching anything else. Check the chain that matches non-bearer requests (`StaffWebLoginConfiguration`, `@Order(1)`) as well as the bearer chain — permitting only the OIDC chain leaves anonymous browsers redirected to login.
- A public route under `/api/v1/**` still meets `TenantContextInterceptor`. Excluding it entirely would silently drop rate limiting; keep the limiter in one place by admitting the exact URI early with an explicit, identity-free key.
- In a cloud worker, `opencode.json` is the CI profile under `skip-worktree`. Confirm with `git ls-files -v`, hash it against `.github/opencode.ci.json` and `git show HEAD:opencode.json`, then temporarily restore HEAD bytes for local gates and restore the CI bytes afterwards. Never regenerate or commit that file.
- Distinguish "my change is green" from "the repository gate is green": run the targeted tests and a touched-class JaCoCo report first, then record any full-suite failures with the exact assertion and prove they are unrelated (empty `git diff` on the files they read, history of the rule tests vs. the contract).
- A byte-for-byte `cp` plus `cmp`/sha256 is the simplest drift-proof package step; compare bytes, not strings, so line-ending changes cannot slip through.
