## Lessons for workers

- When a clause says "every protected action", enumerate all verifier entry points
  before writing tests; the patient path alone does not exercise the staff path's
  membership re-check.
- Clause-proof helpers from `messaging.units.CareUnitDirectoryServiceTest` are
  private; a test in `messaging.clauses` must copy them locally.
- In cloud workers, confirm the `opencode.json` skip-worktree false positive once
  (`git ls-files -v`), then run gate stages individually instead of re-diagnosing.
- Cite the contract from what the tree actually contains: `missing-routes.txt` is
  not the same as a declared route in `contracts/openapi.yaml`.
