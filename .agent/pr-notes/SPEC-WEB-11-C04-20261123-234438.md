## Lessons for workers

- For a docs-only evidence note, verify every relative link with `test -f` from the note's own directory: from `docs/spec/clauses/release/` a repo-root path needs four `../`. `scripts/check-docs.py` checks link resolution and structure but not the exact heading count or status token, so self-check those with `grep -n '^## '` and a status read.
- Separate "offline control exists" from "clause evidence exists" before choosing a status. Under rule 3, a checker plus a synthetic evaluator explicitly marked `final_evidence: false` does not make a cloud/human-gated release clause "Partly built"; name the human suppliers instead.
- Search beyond the brief's starting paths before writing "none found". Here the S-G5-07 handoff under `infra/delivery-safety/` and a domain default-off switch were both absent from the brief's read list; reporting them with their exact classification made the note honest without changing its status.
