## Lessons for workers

- When a slice adds controller routes, publish them in `contracts/openapi.yaml` in the same change
  and regenerate the client; never add them to `missing-routes.txt`.
- A GET returning a JSON array must use a named array schema whose name does not end in `Page`
  (e.g. `PendingStaffAttachments`).
- Run the whole contract test family (`OpenApiRouteParityTest`, `OpenApiContractRulesTest`,
  `OpenApiErrorRulesTest`, `OpenApiPaginationRulesTest`, `OpenApiRouteCoverageTest`).
- When local gates are green but the integrator reports red, **read the GitHub Actions check-runs
  for the exact head SHA before writing another verification note**. Repeated re-verification
  without checking the SHA turns a stale-SHA race into an unbounded loop. This branch had ~10
  near-identical passes; the authoritative CI record resolved it in one read.
- In cloud workers a `check-pack`/`gen-opencode --check` failure usually means the CI profile is
  active under skip-worktree; verify with `git ls-files -v` and `git show HEAD:` before treating it
  as a real failure. Never edit that protected file to pass.
