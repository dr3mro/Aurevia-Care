## Lessons for workers

- Under `-Pno-security`, add `-Dspotbugs.skip=false` to `test-compile spotbugs:check`; a bare `spotbugs:check` (or the profile default) is vacuously green.
- `RxRepository.find` returns `Optional<Prescription>`: stub with `Optional.of(...)`, and use `thenAnswer` with an `AtomicReference` set by the `insertSubmission` answer so a generated stable id can be asserted on the returned object.
- A mocked `find()` return value is not proof of routing — verify the real repository interactions (`transmit` state, `insertSubmission`, `appendEvent`, audit outcome) too.
- `opencode.json` "stale"/"out of date" in a cloud worker is the CI profile under `skip-worktree`; confirm with `git ls-files -v opencode.json` once, run later gate stages individually and never regenerate that file.
- Doc-note "four `../`" means the link depth to the repository root, not exactly four links; every link resolves under `python3 -I scripts/check-docs.py`.
