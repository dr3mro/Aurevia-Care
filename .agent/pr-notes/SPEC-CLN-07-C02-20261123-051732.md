## Lessons for workers

- For a "retain bytes and checksum" evidence test, an HTTP body assertion alone repeats `DocumentDownloadHttpIntegrationTest` and proves nothing new; assert the persisted `content`, `byte_size` and `sha256` columns directly, including `sha256 == encode(sha256(content),'hex')` recomputed from stored bytes and a Java-computed digest.
- Corrupt stored bytes as a superuser with `session_replication_role = replica` against the test's own DB; the V17 guard trigger blocks the UPDATE under the application role.
- In a cloud worker, a `check-pack.py` / `test_check_pack` failure naming `opencode.json is stale` is a skip-worktree artifact: confirm with `git ls-files -v opencode.json` (`S`) and `git show HEAD:opencode.json`, record the command and final line, and never regenerate or commit that file (reinforces the 2026-11-21 daily note).
