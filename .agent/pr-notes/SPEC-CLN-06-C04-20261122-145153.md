## Lessons for workers

- For a "prove clause X" test task, survey the neighbouring domain before assuming the clause is unbuilt: CLN-06 clause 4 lives in `scheduling/followup`, not `chart.record`. Write a real (non-`@Disabled`) test when the route, service, store and migration all exist.
- The canonical API gate command is `AUREVIA_PG_ADMIN=postgres mvn -q -B -f apps/api/pom.xml -Pno-security -Dgroups=integration -Dtest=<Class> test`; always read the Surefire XML count afterwards so a vacuous 0-test green cannot pass. Do not run `scripts/check.sh` in a worker: it stops at the `opencode.json` CI-profile false positive and its `apps/api/check.sh` full verify times out.
- A negative test must send well-formed inputs so it reaches the intended branch: a blank outcome returns 422 before any role, tenant or state check. Give every refusal request a valid-shaped value.
