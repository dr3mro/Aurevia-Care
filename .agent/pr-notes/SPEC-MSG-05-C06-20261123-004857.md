The new clause test adds three active tests in `apps/api/src/test/java/com/aurevia/messaging/clauses/UseGenericPushNotificationsRetrieveFullContentTest.java`:

- `genericAppointmentUpdateCarriesNoClinicalDetail` takes the dispatch path: stubs a linked patient, one active device and a delivering `PushGateway`; invokes `PatientAppointmentService.confirm` and `notifyStatusChange`; captures both `PushGateway.send` calls with `ArgumentCaptor<GenericPushNotice>` and asserts the payload equals `GenericPushNotice.appointmentUpdate()`, `reveals(...)` is false for synthetic patient/facility/clinician/time/status/detail, the body has no digits and the deep link has no appointment id.
- `unauthenticatedContentRetrievalIsRejectedBeforeAnyRead` takes the 401 path: two MockMvc requests without `X-Synthetic-Subject` assert HTTP 401 and `$.code == UNAUTHENTICATED`, which `TenantContextInterceptor.preHandle` raises before the controller or any store runs; `assertNull(TenantContext.current())` after each request confirms no tenant context was ever bound.
