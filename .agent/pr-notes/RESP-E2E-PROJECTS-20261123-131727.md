## Lessons for workers

- On a re-dispatch of an already-merged story, reconcile `git rev-list
  --left-right --count origin/main...HEAD` and the scoped `git diff` first: if
  both are empty, verify and document rather than re-adding. Re-adding
  Playwright projects collides on names and fails config load.
- Run `npx playwright test --config e2e/playwright.config.ts --list` from
  `apps/staff-web`; enumerate once before and once after `npx playwright
  install firefox webkit chromium` to cover both `existsSync` branches without
  a browser launch. State plainly that `--list` proves names/discovery, not
  `use` option values.
- `apps/staff-web/tsconfig.json` excludes `e2e/`, so `npm run typecheck` never
  type-checks the Playwright config; run a focused strict `tsc` with
  `--exactOptionalPropertyTypes` on that file.
- On this image `playwright install` succeeds but browsers cannot launch
  (`libglib-2.0.so.0` missing); do not treat that as a change defect, and remove
  the untracked `test-results/` artifact afterwards so the tree stays clean.
- A red module `check.sh` can be entirely pre-existing on a fast-moving main:
  reproduce each failing stage individually, name the exact final lines, point
  at the owning task, and do not edit protected or out-of-scope files to make a
  green result appear.
