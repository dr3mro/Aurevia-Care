## Findings

- Pre-existing, out-of-scope deviation: `apps/staff-web/tests/responsive/features-admin/AuditEventList.responsive.test.tsx:325-329` encodes that some Arabic `MixedScriptText` call sites pass `lang="en"`. - `.test.ts` path has no JSX, so React elements are built with `createElement`; `tsc` required `children` inside the props object (not a third argument) for `I18nProvider`.

## Lessons for workers

- For an already-built clause, write enabled tests through the real provider/format/component boundary and assert observable outcomes; a `Proven by tests` status still needs a bilingual assertion (compare the same message key in both locales) or the claim is untested.
- In a `.test.ts` (no JSX) file, pass `children` inside the `createElement` props object when the component types require it; a third `children` argument does not satisfy the props type under strict React 18 types.
- Keep `## Status` to exactly one of the three allowed strings and put scope qualifications and out-of-scope deviations in `## Evidence` / `## Gap`.
- The quality loop needs a notes file with a `## Review verdicts` section and GO lines from code-reviewer, coverage-auditor and devsecops as soon as any non-`.md` file changes; write it before the gate, not after.
