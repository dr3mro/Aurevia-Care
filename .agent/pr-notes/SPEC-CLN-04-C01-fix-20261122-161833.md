## Lessons for workers

- On a fix pass, first confirm whether the earlier "Why this is not finished"
  cause was already repaired on the base branch (`git merge-base --is-ancestor`
  plus a direct `grep` of the repaired lines). If it was, re-run the target test
  without any temporary exclusion instead of repeating the old workaround.
- "Do not finish cleanly" with no failing command in a cloud worker is usually
  the `check-pack.py` CI-profile `skip-worktree` false positive: confirm once,
  run the remaining stages individually, and never regenerate that protected file.
- A real-PostgreSQL test tagged `@Tag("integration")` is still a normal test for
  a targeted `-Dtest=...` run; the coverage auditor flags the tag only so it is
  not mistaken for a skip. Prove green with the exact Surefire counts.
- Write the notes file named in the prompt even when the source change was
  already committed in an earlier pass; a correctly named hand-off with all
  Review verdicts is part of "finished cleanly".
