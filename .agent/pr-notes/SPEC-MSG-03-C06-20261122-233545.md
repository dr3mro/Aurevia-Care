If disabled GAP tests are still wanted, step 3 must be reworded and the constraint rule changed by an owner task — a worker cannot edit protected `scripts/`.

No `replace` command exists; replacement is remove plus a fresh upload, which the enabled test proves.
- The plan reviewer referenced `PatientUploadAcceptanceTest.failedUploadIsVisibleToSenderAndNeverPublished`; no such file or method exists in this tree. The actual supporting test is `AttachmentAcceptanceTest` (methods listed in the clause note). No action needed.
