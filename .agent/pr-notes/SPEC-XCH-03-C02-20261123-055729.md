## Affected requirements

XCH-03 clause 2: "Changes after acceptance create a linked version or cancellation
request, and require recipient response."

Acceptance mapping (test → clause behavior):

| Test | Behavior |
|---|---|
| `linkedChangeCreatesRevisionTwoAndServesItOnlyAfterRecipientAcceptance` | linked revision 2 with `previousRevision=1`, revision-1 checksum stable and still served while pending, promotion and second retained copy only after recipient accept |
| `aRejectedChangeNeverBecomesTheRetrievableRevision` | the other recipient response keeps revision 1 current, adds no retained copy and is never served |
| `cancellationIsOnlyConfirmedByTheRecipient` | `cancellation_pending` → `cancelled` only on recipient confirm |
| `aDeclinedCancellationReturnsToAccepted` | recipient decline returns to `accepted` |
| `aRecipientCannotProposeAChange` | wrong role: recipient cannot issue a sender-only change (403) |
| `aPeerTenantCannotRespondToAnotherTenantsPendingChange` | peer tenant is concealed (404) and cannot consume the recipient gate |
| `aStaleVersionCannotProposeAChange` | stale `If-Match` refused (412), no revision inserted |
| `aChangeCannotBeProposedBeforeAcceptance` | forbidden `requested` state refused (409) |
| `aChangeRequiresAChangeSummary` | missing input refused (422), state unchanged |
| `aCancellationRequestRequiresAReason` | missing input refused (422), no cancellation event |

## Lessons for workers

- In this cloud worker, export `SMARTCLINIC_PG_ADMIN=postgres` for DB-backed Maven tests; `worker-check.sh` does it for you.
- Assert numeric `422`, not `HttpStatus.UNPROCESSABLE_ENTITY`: Spring Boot reports `UNPROCESSABLE_CONTENT` for the same code.
- Give each HTTP clause test its own seeded order and its own database name; append-only ledgers and optimistic versions leak between cases.
- `worker-check.sh` fails fast at the known `opencode.json` pack false positive; run the remaining stages individually and record the `git ls-files -v opencode.json` confirmation instead of editing the protected file.
- Wrong-role tests must send otherwise valid payloads, or input validation returns 422 before authorization and masks the intended 403.
