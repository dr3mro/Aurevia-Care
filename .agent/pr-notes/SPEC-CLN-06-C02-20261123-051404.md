## Lessons for workers

- For a test-only story, red-first is not applicable: the clause was already implemented, so the new test is green on its first run. Record that explicitly instead of implying a red phase.
- The `fast` Maven profile silently excludes `@Tag("integration")` even with `-Dgroups=integration`; use `-Pno-security -Dgroups=integration -Dtest=<Class>` and read the Surefire XML count.
- A per-class database name is essential when neighbouring HTTP integration tests exist; otherwise concurrent workers collide on the shared fixture database.
- In a cloud worker, a stale `opencode.json` in `check-pack.py`/`test_check_pack` is an environment artifact (`git ls-files -v opencode.json` = `S`); confirm once with `git show HEAD:opencode.json`, record the final line, run the other stages and do not regenerate the protected file.
