## Lessons for workers

- A clause-proof test class must supply its own HTTP/DB/seed helpers: the
  neighbours' helpers are `private`, and step 5 forbids editing them. Copy and
  adapt them, and give each proof class its own database name so parallel
  workers do not collide.
- `scripts/worker-check.sh` ends by running `mvn -Dgroups=integration test`
  (every integration suite), which exceeds the worker time budget. Once its
  quick-check, frontend and SpotBugs stages are green, stop it and run only the
  targeted `-Dtest=ClassName` suite plus `db/check.sh`; leave the full gate to
  the integrator.
- A `git grep` hit for conflict markers is not necessarily an unresolved merge:
  when `git ls-files -u` is empty and the markers are committed in HEAD inside a
  Javadoc comment in another package, leave the out-of-scope file alone.
