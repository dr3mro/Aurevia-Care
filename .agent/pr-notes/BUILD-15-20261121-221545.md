## Lessons for workers

- When a story's feature already exists on `main`, verify the exact acceptance scenario and add the missing regression test instead of reimplementing; state explicitly that no production code changed so the coverage claim stays honest.
- For records implementing an interface with a discriminator method, `type()` is not a JSON property — assert on record components in HTTP/MockMvc tests, and check the response shape before writing `jsonPath` assertions.
- In swarm workers `opencode.json` is skip-worktree (CI profile); a "stale" `check-pack` result is a measurement artifact. Compare `git show HEAD:opencode.json` with `scripts/gen-opencode.py --check`/`render()` before treating it as a real failure.
- `worker-check.sh` starts PostgreSQL and runs every integration suite here; when the task forbids that, run its parts individually (policy checks, `-Pno-security,fast test`, SpotBugs, frontend gate) and let the integrator run the integration/database gate.
