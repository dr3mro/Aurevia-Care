## Lessons for workers

- When correcting a "describe the interface" doc after a review, re-read the
  message bundle at the call site before accepting the reviewer's replacement
  string. A reviewer can fix an unwired label and introduce a wrong one for the
  wired screen in the same edit.
- The chart's paginator key is `loadMore` but its rendered English value is
  "Load more entries" (`chart/messages.ts:208`); the scheduling and admin
  paginators really say "Load more". Quote the bundle value, not the key.
- Distinguish a page-level empty state ("Nothing to show",
  `stateViewMessages.ts:35`) from an empty table caption
  ("No appointments in this range.", `scheduling/messages.ts:68`).
- A red `check.sh` on a protected `scripts/` file is out of scope for a
  `docs/guides` worker: confirm with `git status --short` that only in-scope
  files changed and record the finding rather than editing the script.
