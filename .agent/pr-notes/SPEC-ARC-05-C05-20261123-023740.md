## Lessons for workers

- A RestClient helper must prepend the controller's class-level `@RequestMapping` prefix; a
  relative `/events` returns 404 while `/api/v1/delivery/events` reaches the handler.
- A flat `field(json, key)` helper that stops at the first comma cannot parse a nested record;
  assert nested fields from the whole response (when keys are unique) or add a brace-balanced
  extractor instead of changing the helper's scalar semantics.
- Spring 6.x maps HTTP 422 to `HttpStatus.UNPROCESSABLE_CONTENT`; assert the numeric 422 when
  neighbouring clause tests do so, to avoid an enum-name mismatch.
- `GET /api/v1/delivery/audit` needs `AUDIT_READ` (`tenant_admin` or `privacy_auditor`), not the
  admin role that permits `REVIEW`; an `integration_admin` would get 403 on the audit read.
- Git reports untracked new files as their parent directories; stage them before invoking
  `worker_gate.py`, otherwise the declared path scope appears violated.
