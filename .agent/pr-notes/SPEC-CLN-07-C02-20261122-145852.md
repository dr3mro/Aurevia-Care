## Lessons for workers

- For a proof-only clause story, confirm the clause is built first; write an
  active green test, never a `@Disabled` placeholder, and state honestly that no
  red phase exists instead of pretending one was observed.
- Assert the database-side invariant directly (stored `sha256` versus SHA-256 of
  the stored bytes) rather than only a request/response round trip; that is what
  distinguishes "bytes were retained" from "bytes were echoed".
- Scope the tamper audit count by `resource_id` so test order cannot make the
  assertion flaky, and pin a 403 to the action matrix by first asserting the
  actor has active membership and the role under test.
- In a cloud worker, `check-pack.py` and the six `test_check_pack` failures from
  the `skip-worktree` `opencode.json` are environmental; confirm once with
  `git ls-files -v` and `git show HEAD:opencode.json`, run the other stages
  individually, and never regenerate or commit that protected file.
