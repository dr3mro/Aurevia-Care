## Lessons for workers

- A WITH CHECK negative test must set a *competing valid* tenant context and include a
  same-tenant control on the same connection; otherwise a `42501` only proves the
  missing-context fail-closed path, not organization equality.
- A `pg_class` relflags probe can be vacuous if the table is absent; guard with
  `rows.next()`, pair with a `pg_policies` probe for non-null USING/WITH CHECK, and check
  that the runtime role is neither `rolsuper` nor `rolbypassrls` and owns no tenant table.
- To prove transaction-local context in production, drive the injected
  `TransactionTemplate` (built on `TenantGuardTransactionManager`) and assert both the
  bound GUC inside the transaction and the fail-closed guard with no context; a raw
  `set_config(...,true)` probe alone only proves PostgreSQL semantics.
- In this cloud worker, `quick-check.sh` stops at the known `opencode.json` CI-profile
  artifact; confirm once with `git ls-files -v` and `git show HEAD:opencode.json`, then run
  the remaining stages individually instead of regenerating the protected file.
