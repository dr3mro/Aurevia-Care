## Summary

Added a self-contained staff-web `labrelease` feature: a side-by-side old/new revision comparison, a correction form that captures what changed and a mandatory reason, a withdrawal action with a mandatory reason and consequence text, a persistent withdrawn banner, and a release-status panel showing what the clinician and the patient can see. English and Arabic bundles, RTL isolation of the accession and subjects, synthetic fixtures only. No dependency added; route auto-registers through the existing feature-glob registry.

## Affected requirements

- LAB-02 — preliminary/final/corrected/withdrawn (entered-in-error) report states, revision comparison, correction and withdrawal with reasons.
- WEB-09 — empty/error states, typed work preserved when an action is blocked, a stale success cleared on edit, status announcements.

## Findings

- Pre-existing generated-client drift outside this task's scope: `contracts/openapi.yaml` contains print-handout paths absent from the committed `apps/staff-web/src/api/generated/openapi.d.ts`, so `bash apps/staff-web/check.sh` stops at `gen:api:check` on this branch regardless of this feature. Next worker with the right scope should run `npm run gen:api` in `apps/staff-web` and commit the regenerated types.
- Pre-existing pack drift outside this task's scope: `bash scripts/check.sh` stops at `check-pack: opencode.json is stale`. Worker scope excludes `opencode.json`, `.opencode/` and `scripts/`, so no regeneration was attempted here; the integrator or maintainer owns it.
- This feature has no transport layer by design (synthetic fixtures, presentational screen), matching the sibling `labresults` feature. WEB-09 transport-derived states (offline/forbidden/conflict/session-expired) are owned by shared `StateViews`; they are not newly introduced here. The explicit empty state, required-reason errors, preserved drafts and status announcements are covered.
- Coverage-log errors from the pre-existing ThemeProvider negative test are console noise, not failures.

## Lessons for workers

- Check `gen:api:check` before claiming a staff-web gate is green; it runs before typecheck in `check.sh`, and a stale generated client from another worker's contract change can block the whole script. Diagnose with a `--output` to a temp file plus `diff`, and stay inside scope rather than regenerating someone else's file.
- Testing Library normalises non-breaking spaces in `getByText`; assert `textContent` to verify the NBSP between a value and its unit.
- Interpolating an opaque identifier into a translated message string loses its LTR isolation; split the message on the placeholder and render the identifier in its own `<code dir="ltr">`, as done for the accession.
