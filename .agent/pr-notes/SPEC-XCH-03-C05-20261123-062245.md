## Lessons for workers

- Before planning "reuse the neighbouring test's helpers", check their visibility and package: a
  private helper in `it.exchangetask` cannot be called from `exchange.clauses`, and extracting it
  would edit an existing test outside scope.
- `assertFalse(node.asBoolean())` passes when the node is missing; assert `node.isBoolean()` first
  for every boolean false case.
- In a cloud worker, `opencode.json` is the skip-worktree CI profile. Six `test_check_pack` failures
  are a known false positive; verify with `git ls-files -v` and `git show HEAD:opencode.json` against
  the generator instead of editing the protected file or re-diagnosing it on a later pass.
- For clause-evidence docs, scope "Proven by tests" to the behaviour actually executed and put
  adjacent-requirement gaps (an unbuilt OPS-07 job, a missing contract path) under `## Gap`.
