## Summary

CLN-06 clause 2. The clause is already implemented in the chart neighbour package
`com.aurevia.smartclinic.scheduling.followup`; this story proves it through the
normal API entry points and records the evidence and the pre-existing contract gap.
No production code, existing test, contract, migration or tracker was changed.

## Findings

- Discovery: CLN-06 clause 2 is implemented in `scheduling/followup` (the chart
  neighbour), not in `chart` itself. `FollowUpService.suggest` builds the rule
  explanation and `FollowUpService.override` records `FollowUpOverride` provenance;
  `FollowUpController` exposes both routes; `JdbcFollowUpStore` persists to
  `public.follow_up_suggestion` (V74, RLS + FORCE RLS). The test exercises those
  production classes rather than duplicating their logic.
- Plan review: the first plan review answered NO-GO with three Required gaps. All
  were fixed before coding: (1) the confirmed/second-override tests now first create
  their precondition state (confirm at the current `If-Match` version as reception;
  one successful override) and assert it before expecting 409; (2) the evidence now
  records the Surefire XML counts and the PostgreSQL/`SMARTCLINIC_PG_ADMIN`
  prerequisite; (3) the clause document scopes "Proven by tests" to clause
  behaviour and records the pre-existing OpenAPI gap under `## Gap`.

## Lessons for workers

- For a clause-evidence story, find the feature in the domain that owns the
  requirement before assuming it is unbuilt: CLN-06 lives in `scheduling/followup`,
  while the clause test package is `chart/clauses` by tracker convention.
- When a terminal-state negative test expects 409, first drive and assert the
  precondition (confirm with `If-Match` at the current version, or apply one
  successful override); otherwise the result is 200/403/412 instead of the
  intended conflict.
- Scope "Proven by tests" to the clause behaviour. A missing OpenAPI path is a
  real but separate gap; record it under `## Gap` instead of claiming full
  contract coverage or editing `contracts/` outside the task scope.
