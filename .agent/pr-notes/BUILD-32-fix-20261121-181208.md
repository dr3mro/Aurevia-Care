## Data changes

`db/migrations/V86__recurrence_templates.sql` (reserved version V86, `Change: expand`): three
additive tables `recurrence_template`, `appointment_series`, `series_occurrence`. Each has
`organization_id`, a composite PK including it, `created_at`, ENABLE + FORCE RLS and a policy
`USING/WITH CHECK (organization_id = public.app_org())`. Append-only reject-mutation triggers for
`UPDATE`, `DELETE` and `TRUNCATE` cover every role including the migration owner; SELECT/INSERT are
granted only to `orevia_app`. `recurrence_template` enforces exactly one termination via
`CHECK ((occurrence_count IS NULL) <> (end_local_date IS NULL))`. No backfill, no UPDATE of existing
rows, no destructive DDL; brief ACCESS EXCLUSIVE locks bounded by table creation. Rollback is a
forward-fix migration; no capability is removed. No migration was added or edited in this pass.

## Lessons for workers

- Do not re-run the slow full `mvn verify` as a worker. The decisive coverage command is the 143-class
  unit suite plus `SeriesHttpIntegrationTest`, `AppointmentListIntegrationTest` and
  `SchedulingBookingTest`; a subset leaves `AppointmentService` below 100%. `SchedulingBookingTest`
  lives under `.../orevia/it/` and must be added explicitly — the `/it/` filter excludes it.
- JaCoCo counters print as `missed/covered`: `1/4` is a MISSED branch. Match exact JaCoCo names
  using `/` separators, list nested classes separately and treat an absent BRANCH counter as `n/a`.
- `check-pack.py` / `gen-opencode.py --check` staleness under `skip-worktree` is a known false
  positive: verify with `git ls-files -v opencode.json` and compare worktree/CI/HEAD hashes; do not
  regenerate it locally.
- `bash scripts/check.sh` uses `set -e` and stops at the first failing step; run each policy script
  individually to see all gate results. A masked later failure (`check-docs.py`) only appears once
  `check-pack` is clean — check it explicitly before declaring the gate green.
- `check-docs.py` counts unescaped `|` in table cells even inside code spans; in GFM tables escape a
  pipe inside a backtick span as `\|` so the rendered URL keeps the pipe but the validator sees one cell.
- Frontend `check.sh` scripts install pinned deps with `npm ci` and are safe to run even for a
  backend-only story when the prompt explicitly requires the frontend DoD; both modules are green
  here. Report the exact typecheck final lines rather than claiming them from memory.
