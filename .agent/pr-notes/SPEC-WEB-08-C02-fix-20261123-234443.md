## Lessons for workers

- When a fix pass reports "did not finish cleanly" without a failing command,
  reproduce every gate on the exact head first: a draft can be a worker-run/
  timeout artifact rather than a defect. Record each command and final line.
- `scripts/check-constraints.py` matches a literal `:` + whitespace + `any` in
  comments too (`rule: any value …`); reword prose rather than suppressing.
- A would-be test quoted in a clause doc should be extracted and run through
  strict `tsc` before you promise it can be "enabled verbatim"; record the exact
  command so the claim is reproducible.
- jsdom cannot measure LCP/INP/CLS. A structural contract test must say so and
  leave Status `Not built`; never let a green run stand in for browser evidence.
- `StaffMember.subject` is optional in the generated client; use a typed `??`
  fallback in strict tests instead of `!` or a cast.
- The brief's step 3 `it.skip` instruction conflicts with AGENTS.md's no-skipped-
  test rule and the constraint gate; the accepted resolution is GREEN tests plus
  the full would-be proof in the clause doc.
