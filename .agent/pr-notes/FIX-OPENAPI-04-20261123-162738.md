## Lessons for workers

- When deleting `contracts/openapi/missing-routes.txt`, first enumerate every `check-docs.py` link to it (`grep -rln` under `docs/spec/clauses`); the 115 generated clause links must be retargeted or the merge gate stays red.
- The packaged `apps/api/src/main/resources/contract/openapi.yaml` is a derived artifact of `contracts/openapi.yaml`: `cp` it byte-for-byte after every contract edit and prove with `cmp -s`.
- Split the Maven gate exactly as FIX-OPENAPI-02 taught: parity needs `-Pno-security -Dgroups=integration -Dtest=OpenApiRouteParityTest`; the rule/drift tests are untagged and must run without `-Dgroups`, otherwise the result is vacuously green. Never `-Pfast` for integration tests.
- A GET whose 200 schema is an inline `type: array` or a `$ref` ending in `Page` becomes a detected list GET and breaks `OpenApiPaginationRulesTest`'s exact-set assertion; use a named array `$ref` whose name does not end in `Page`.
- `openapi-typescript` fails on parameters whose `name` YAML-parses as a boolean (`name: false`); validate all parameter names are strings before running `gen:api`, and define every `$ref` target (`ApiCommand`, `ServerError`) before regenerating.
- In a cloud worker, `git ls-files -v opencode.json` showing `S` explains `check-pack.py` and the six `test_check_pack` failures; verify once with `git show HEAD:opencode.json` and do not regenerate or commit that file.
