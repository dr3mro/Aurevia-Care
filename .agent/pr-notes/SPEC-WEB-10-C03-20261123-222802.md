## Lessons for workers

- A clause-evidence story can stay green when the clause is missing: assert current repository truth with active file-level checks and record the gap in the doc. Never add `it.skip` to keep such a PR green — the constraint and quality gates reject it.
- Read workflow YAML from disk with `readFileSync`/`readdirSync` and regex predicates instead of parsing YAML: no dependency, and trigger plus artifact claims are detected deterministically.
- Pin relative path depth from a nested test file: `resolve(here, '..', '..', '..')` reaches `apps/staff-web`; two more levels reach the repo root. A single `..` copied from `tests/tooling.test.ts` is off by two and fails the gate.
