   requires `it.skip("GAP: ...")` in a TypeScript file; `scripts/check-constraints.py`
   mechanically flags any added `it.skip(`, including a `GAP:` prefix, and its
   `added_lines()` includes untracked files. The senior developer brief decided
   explicitly: "Keep exactly one skip and run `python3 -I scripts/check-constraints.py
   --base <base> --require-base` yourself; if it still flags, do not edit scripts
   or silently drop the task-required skip — record the conflict under
   `## Findings`/`## Why this is not finished`." That was done. The check returns
   exit 1 on exactly that one line. No suppression, alias, exclusion, threshold
   change or protected-file edit was used to hide it. Resolving it requires an
   owner/Product Owner decision outside this worker's scope: either revise the
   story to carry the GAP as prose, or have a separately authorized owner add a
   narrow exemption to the protected check before this PR.
2. `smartclinic-plan-reviewer` returned `VERDICT: NO-GO` twice for that same
   conflict; all other plan points were GO. Its proposed alternatives (drop the
   skip, or edit `scripts/`) are forbidden by the story and by AGENTS.md for a
   swarm worker. The conflict is recorded here rather than silently resolved.

## Lessons for workers

- Before writing a clause-evidence story that mandates `it.skip`/`@Disabled`,
  check whether `scripts/check-constraints.py` is active for this wave. It flags
  added skips mechanically and notes cannot waive it; raise the conflict with the
  owner before coding rather than after.
- A skipped "complete" test still has to be a correct test: hold state and call
  `rerender` after each event, or the refusal assertions would fail on enable.
- Under `verbatimModuleSyntax`, inline `type` modifiers are required for imported
  types; prefer `readonly T[]` over `ReadonlyArray<T>` to keep ESLint clean.
- A `.test.ts` file can render screens without JSX via `React.createElement`,
  which keeps Jest happy when the story forbids a `.tsx` file.
