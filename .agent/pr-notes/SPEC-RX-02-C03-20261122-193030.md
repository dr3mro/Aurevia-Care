## Lessons for workers

- For a clause-verification test against already-built behaviour, green-first is expected; do not add `@Disabled` or manufacture a red phase. Prove the behaviour by capturing the actual write arguments and deriving the read-back snapshot from them instead of asserting a plain mock stub.
- `parseChannel` runs before `execute`, so an unknown-channel test can prove "no transaction opened" with `verify(transactions, never()).execute(any())` plus `verifyNoInteractions(repository, audit)`; keep `TransactionTemplate` as a field for that verification.
- Ownership refusal is checked inside `lockedByPrescriber`, before version, state, entitlement and channel policy: omitting entitlement/channel stubs in that negative is itself evidence of the ordering, and a message assertion plus "no DENIED audit" distinguishes it from a role-based 403.
- For local-print transmitting, stub the read-back `find()` snapshot to `State.PRINTED` when the recorded channel is `PRINTABLE_LOCAL`; otherwise `LocalPrescriptionPrint.issue` fails with `PRINT_NOT_AVAILABLE` before the channel assertion. Supply an `ATTESTED` event as well.
