## Lessons for workers

- On a shared, fast-moving `main`, always re-run the targeted test **after** merging: a clean
  merge can still leave the tree uncompilable because a different worker changed a shared
  record. Report the exact failing command and identify the offending file by commit before
  claiming a regression belongs to this story.
- When an unrelated out-of-scope test breaks `testCompile`, `mvn -DskipTests compile` plus a
  direct `javac` of the scoped test into `target/test-classes`, followed by `mvn surefire:test`,
  proves the scoped behaviour without editing outside the declared scope. Record it as a
  targeted run, not as the canonical gate.
- The `*/clauses` packages are the fast, mocked, synthetic unit tier; mirror the owning
  service test and cite the existing HTTP test as the entry-point proof.
- Do not run `scripts/check.sh` or `scripts/worker-check.sh` from a swarm worker: they reach
  full `mvn verify` and time out. Run the targeted test, the individual policy scripts and
  compile-then-SpotBugs, then leave the full gate to the integrator.
- A clause-proof task that adds only tests and docs produces no new production coverage; say
  so explicitly instead of claiming an unmeasured JaCoCo number.
