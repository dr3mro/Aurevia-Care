## Lessons for workers

- When a story says `it.skip("GAP: ...")`, implement an ACTIVE tripwire that pins the current absence and fails when the gap is closed; skipped tests are rejected by the coverage gate.
- For a no-production-change evidence task, name tests after what they actually prove. Source-text pins plus synthetic gzip measurements are not behavioural proof of built chunks — attribute that proof to the existing unit suite and the real post-build gate, or the doc fabricates evidence.
- Scope a CI-gap tripwire to the specific job body and delegated command list with load-bearing exact-array assertions; a whole-file `not.toContain('npm run build')` can flip on unrelated jobs and can stay green if CI switches to another enforcing entry point.
- Resolve test paths with `dirname(fileURLToPath(import.meta.url))` and explicit `resolve` levels (3 `..` to `apps/staff-web`, 5 `..` to repo root from `tests/spec/platform`), not `new URL(...)` with `import.meta.url`.
- ESLint `no-regex-spaces`: write `/^ {2}/` instead of two literal spaces in a regex literal; fix the code, never disable the rule.
