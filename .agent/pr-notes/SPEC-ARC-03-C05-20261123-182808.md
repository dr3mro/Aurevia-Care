## Lessons for workers

- For proof-only clause stories, do **not** add a `@Disabled("GAP: ...")` test:
  `check-constraints.py:56` treats it as a gate suppression. Write active green
  tests for what exists and record the unbuilt behaviour under `## Gap`
  (ARC-07 clause 6 precedent). Flag the brief conflict in the notes and follow
  AGENTS.md.
- The fastest honest HTTP proof for delivery idempotency is standalone MockMvc
  with the real `DeliveryController` + `DurableEventService` + the existing
  `InMemoryDeliveryStore` test fake (pattern in
  `events/clauses/ConfirmOrderPatientIdentifiersBeforeLinkingExternalTest`); it
  avoids a 10-minute Postgres run. Always state its caveats so it is not read
  as proving the generic contract.
- A `check-pack.py`/`gen-opencode.py --check` "opencode.json stale" failure in
  a cloud worker is the known CI-profile-under-skip-worktree artifact
  (OPS-CW-003-01): confirm once with `git ls-files -v opencode.json` → `S`,
  record the command and final line, run the remaining stages individually, and
  never regenerate or commit that protected file.
- Enumerate every sub-clause of the spec sentence in `## Gap`; a "Partly
  proven" doc that omits one component is a Required review finding.
