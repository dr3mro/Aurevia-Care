## Lessons for workers

- For clause-proof tasks, change exactly one identity field per mismatch request: with `||`, a
  request that gets every field wrong short-circuits on the first operand and leaves the other
  operands' deciding sides untested.
- Check `git ls-files -v opencode.json` before treating a `check-pack.py`/`test_check_pack`
  "stale" failure as a real defect in a cloud worker; confirm with `git show HEAD:opencode.json`
  and never regenerate or commit the skip-worktree file.
- A clause that is already implemented should be proven with active tests and `Status: Proven by
  tests`; a `@Disabled` test here would fail the quality gate and misstate the doc.
