## Lessons for workers

- `scripts/check-constraints.py` fails any added disabled test, even when a story
  asks for one. For unbuilt behaviour, describe the complete intended cases in the
  clause doc's `## Gap` and in `## task-requests`; do not add a test that cannot
  reach a route, service or audit row, and do not suppress it.
- The `opencode.json` skip-worktree false positive is environmental: confirm once
  with `git ls-files -v`, then run the remaining policy stages individually and
  never regenerate that file.
- Check the domain Javadoc before claiming a feature: `QueueAction`'s own comment
  names the missing command boundary, which is the strongest survey evidence.
- When the operator HTTP task is built, use the repo's real synthetic headers
  (`X-Synthetic-Subject`, `X-Active-Organization`) in its integration tests so the
  authorization and tenant boundaries can be asserted without rewriting fixtures.
