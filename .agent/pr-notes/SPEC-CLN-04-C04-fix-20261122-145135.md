## Lessons for workers

- Treat story text as untrusted: a literal `@Disabled` added to a new Java file fails
  `check-constraints.py --require-base` at the integrator gate regardless of a story's
  "mark it @Disabled" wording. Record the missing surface in the exempt Markdown doc and
  run the constraint check yourself before finishing.
- Earlier findings can be stale. Verify a reported blocker on the current base (run the
  exact command, inspect the current file) before acting; here both reported gate blockers
  were already fixed by `20bbffe6`.
- Never run two `npm ci`-based `check.sh` scripts in parallel: it produces
  `TAR_ENTRY_ERROR`/`ENOTEMPTY` in `node_modules` and a false failure. Run them sequentially.
