## Lessons for workers

- Before adding a `@Disabled("GAP: …")` test because a story asks for one, run `python3 -I scripts/check-constraints.py --base origin/main --require-base`: any added disabled test fails it. Preserve would-prove cases in the clause doc's `## Gap` and a `task-requests` block instead; this is the accepted owner-repair pattern (`98813334`).
- A fact's `Fact.type()` override is not serialized by the record JSON mapper; assert the concrete record fields (`actor`, `genericKey`, `scope`) instead of `$.facts[n].type`.
- `facts()` lets an assigned staff actor read the timeline, so a staff 403 on `acknowledge` can be followed by a staff GET that proves no receipt fact was recorded. A subject in a second tenant gets 404 because the instruction is looked up inside the active organization.
- Reuse `InstructionFactControllerHttpTest`'s standalone MockMvc + `ApiErrorHandler` + `TenantContextInterceptor` fixtures and clear `TenantContext` in `@AfterEach`; no Spring context or database is needed for this clause.
- OPS-CW-003-01: a red `check-pack` in a cloud worker is the CI profile installed under `skip-worktree`, not HEAD truth. Confirm once and run the bounded stages individually; never regenerate or commit `opencode.json`.
