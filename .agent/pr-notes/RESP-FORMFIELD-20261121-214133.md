# RESP-FORMFIELD — Staff web: responsive `FormField` component

## Summary

Made the staff-web `FormField` responsive using only the existing shared responsive classes and breakpoint hooks. The field now uses `stack` (label above control, wrapping room for label/error), `field` (16px text, full inline size, logical padding and focus ring) and `touch` (24px general / 44px coarse-pointer target). The `useBreakpoint` and `usePointerCoarse` hooks expose the resolved layout class as `data-breakpoint` / `data-coarse-pointer`. No props, exported names, text, API calls, `inputmode` or `autocomplete` were changed. Added a dedicated responsive test file that mocks `matchMedia` at 320/360/390/768/820/1024/1280 and asserts structure, labels, roles, keyboard order and the RTL case.

## Affected requirements

- WEB-07 — supported clients / compact staff-web layout (320–1280 px).
- UX-01 — English + Arabic RTL, WCAG 2.2 AA; logical properties, wrapping, coarse-pointer targets.

Not fixed here because the generated file is outside the task scope.
2. **Style substitution (intended responsive change).** Removed inline `minHeight: 32px` and physical `padding` shorthand; applied `.touch` (24px general / 44px coarse) and `.field` (16px text, 100% inline size, logical padding) with logical `paddingBlock`/`paddingInline` keeping the token value. Functional behavior (label association, aria-invalid/describedby, onChange, `type`/`placeholder`) is unchanged.
3. **Safe-area insets** are mapped once at the shell boundary by `.page` / `.app-shell` in `responsive.css`; the component uses only logical properties and adds no per-component safe-area rule. No clinical field is hidden with `display: none`.
4. **No missing class was needed**, so no new CSS or inline workaround was added.

## Lessons for workers

- `.stack > *` in `apps/staff-web/src/theme/responsive.css` already supplies `min-inline-size: 0` and `overflow-wrap: anywhere`; label and error are direct children, so they wrap without a new class or inline style. Prefer the existing class over duplicating wrapping rules.
- Never set `direction: rtl` on a subtree: RTL mirroring comes from document `dir`/`lang` plus logical properties. For coarse targets use the existing `.touch` class rather than a JS-computed min-height.
- On this branch `bash apps/staff-web/check.sh` fails at `gen:api:check` because PRINT-02 changed the contract without regenerating the client. To validate your own scoped change, run the individual steps (typecheck, lint, build, bundle size, `test:coverage`) and record the drift; do not edit the generated file outside your scope.
