## Complete ready-to-enable GAP case

The following method is **intentionally not compiled into the `.java`**. A
later production task enables it by copying it into
`GenerateImmutableVersionedPdfsEnglishArabicEmbeddedTest` and deleting the
`@Disabled` line. Every assertion fails against today's

It reuses only existing fixtures and imports plus the one import noted below;
no new dependency is introduced.

```java
// ADD THIS IMPORT when the test is enabled (carry it in the exempt hand-off note):
// import org.junit.jupiter.api.Disabled;

/**
 * GAP evidence (disabled until production embeds a real font program and shapes
 * Arabic): the object-7 font file must be a genuine sfnt/OpenType program with a
 * matching real /Length1, and the Arabic title's Tj operand must carry shaped
 * glyph ids rather than the raw UTF-16BE code units of the title.
 *
 * <p>Drives the real HTTP POST /api/v1/documents/rendered and GET .../content
 * path against PostgreSQL. Fails today because PdfRenderer.FONT_HEX is 32 zero
 * bytes and visualOrder() only reorders word runs without shaping or subsetting.</p>
 */
@Test
@Disabled("GAP: no real font program or Arabic glyph shaping — PdfRenderer.FONT_HEX is 32 zero bytes")
void embedsARealFontProgramAndShapesArabicGlyphs() throws Exception {
    String chart = registerChart(ORG_A, "reception-a");
    String ar = render(ORG_A, "clinician-a", chart, "ar", TITLE_AR);
    ResponseEntity<byte[]> arResponse = content(ar, "clinician-a", ORG_A);
    assertEquals(HttpStatus.OK, arResponse.getStatusCode());
    byte[] arPdf = arResponse.getBody();

    // A real embedded font program, not the 32-byte zero placeholder.
    byte[] fontProgram = pdfStreamBytes(arPdf, 7);
    assertFalse(isAllZero(fontProgram),
            "the embedded font program is not a placeholder of 32 zero bytes");
    assertTrue(hasSfntSignature(fontProgram),
            "the embedded program starts with a real sfnt/OpenType signature (0x00010000, OTTO or true)");
    int declaredLength1 = pdfDictInt(arPdf, 7, "/Length1 ");
    assertTrue(declaredLength1 == fontProgram.length && declaredLength1 > 32,
            "the declared /Length1 describes a real font program, not the 32-byte placeholder");

    // Shaped Arabic glyph runs, not the original code units of the title.
    String titleOperand = firstShowTextOperand(arPdf, 5);
    assertNotEquals(utf16Hex(TITLE_AR), titleOperand,
            "the Arabic title is emitted as shaped glyph ids, not its raw UTF-16BE code units");

    // Subsetting marker expected of a real shaping/embedding renderer.
    assertTrue(pdfObjectText(arPdf, 4).matches("(?s).*/BaseFont /[A-Z]{6}\\+.*"),
            "the embedded TrueType font carries the six-letter PDF subset tag");
}

/** Return the exact payload bytes of a numbered PDF stream object, using its /Length. */
private static byte[] pdfStreamBytes(byte[] pdf, int objectNumber) {
    String ascii = asAscii(pdf);
    int object = ascii.indexOf(objectNumber + " 0 obj");
    assertTrue(object >= 0, "object " + objectNumber + " exists");
    int keyword = ascii.indexOf("stream\n", object);
    assertTrue(keyword > object, "object " + objectNumber + " has a stream");
    int start = keyword + "stream\n".length();
    int length = pdfDictInt(pdf, objectNumber, "/Length ");
    assertTrue(start + length <= pdf.length, "the stream length stays inside the PDF");
    return Arrays.copyOfRange(pdf, start, start + length);
}

/** Read an integer-valued dictionary key (e.g. "/Length1 ") from a numbered PDF object. */
private static int pdfDictInt(byte[] pdf, int objectNumber, String key) {
    String ascii = asAscii(pdf);
    int object = ascii.indexOf(objectNumber + " 0 obj");
    assertTrue(object >= 0, "object " + objectNumber + " exists");
    int keyAt = ascii.indexOf(key, object);
    assertTrue(keyAt > object, "object " + objectNumber + " declares " + key.trim());
    int start = keyAt + key.length();
    int end = start;
    while (end < ascii.length() && Character.isDigit(ascii.charAt(end))) {
        end++;
    }
    assertTrue(end > start, key.trim() + " has a numeric value");
    return Integer.parseInt(ascii.substring(start, end));
}

/** Return the ASCII text of a numbered non-stream PDF object up to, but excluding, endobj. */
private static String pdfObjectText(byte[] pdf, int objectNumber) {
    String ascii = asAscii(pdf);
    int start = ascii.indexOf(objectNumber + " 0 obj");
    assertTrue(start >= 0, "object " + objectNumber + " exists");
    int end = ascii.indexOf("endobj", start);
    assertTrue(end > start, "object " + objectNumber + " is closed");
    return ascii.substring(start, end);
}

/** Return the hex operand of the first show-text (Tj) operator in a page content stream. */
private static String firstShowTextOperand(byte[] pdf, int objectNumber) {
    String content = asAscii(pdfStreamBytes(pdf, objectNumber));
    int open = content.indexOf('<');
    assertTrue(open >= 0, "the page content stream contains a show-text operand");
    int close = content.indexOf('>', open + 1);
    assertTrue(close > open, "the show-text operand is closed");
    assertTrue(content.indexOf(" Tj", close + 1) > close, "the operand is used by a Tj operator");
    return content.substring(open + 1, close);
}

/** True only when every byte in the array is zero (the known placeholder value). */
private static boolean isAllZero(byte[] bytes) {
    for (byte value : bytes) {
        if (value != 0) {
            return false;
        }
    }
    return true;
}

/** True when the first four bytes are a standard TrueType/OpenType sfnt signature. */
private static boolean hasSfntSignature(byte[] font) {
    return font.length >= 4
            && ((font[0] == 0 && font[1] == 1 && font[2] == 0 && font[3] == 0)
                || (font[0] == 'O' && font[1] == 'T' && font[2] == 'T' && font[3] == 'O')
                || (font[0] == 't' && font[1] == 'r' && font[2] == 'u' && font[3] == 'e'));
}
```

Why each assertion fails today (tool evidence: `PdfRenderer.java:31,43,57-63,134-169`):

- Not-all-zero font — object 7 is exactly 32 zero bytes from `FONT_HEX`.
- sfnt signature — zeros are neither `00 01 00 00`, `OTTO` nor `true`.
- Real `/Length1` — declared as 32, so `> 32` is false.
- Shaped title glyphs — `visualOrder()` emits the raw UTF-16BE title code units.
- Subset tag — `/BaseFont /SmartclinicSans` has no six-letter PDF subset prefix.

## Lessons for workers

- When a story template asks for an `@Disabled("GAP: …")` test, do not put it in
  a `.java` file: `scripts/check-constraints.py` rejects any added `@Disabled`
  and AGENTS.md forbids skipped tests. Carry the complete, compilable case in
  the exempt hand-off note instead, with an explicit "not compiled" notice —
  house style in `docs/spec/clauses/therapy/version-outcome-scales-store-units.md`
  (lines 74-77) and `docs/spec/clauses/exchange/apply-law-policy-recipient-retention.md`
  (lines 70-73).
- In a cloud worker, the six `test_check_pack.py` failures plus a stale
  `opencode.json` are the CI profile under `skip-worktree`, not a defect of the
  change. Confirm with `git ls-files -v opencode.json` → `S` and
  `git show HEAD:opencode.json`, record it once, then run the remaining gate
  stages individually. Do not regenerate a protected file.
- Run the new `@Tag("integration")` class directly with `-Dtest=…` instead of
  every integration suite; it is faster and proves the exact entry point
  (lesson from `docs/archive/pr-notes/2026-11-20.md`, "Lessons for workers").
