## Lessons for workers

- For a forced-RLS proof, clone `ConversationFlowTest`'s two-organization fixture
  rather than `ConversationHttpSecurityTest`'s single-organization one, and give
  both organizations the **same** `patient_subject`. Then a cross-tenant 404
  cannot be explained by the patient-subject check in `requireAccess`, and the
  owning-org GET doubles as a control proving the row exists.
- Derive `If-Match` versions from the preceding response, never from a guess:
  `requireVersion` runs before `requireWritable`, so replying to a freshly closed
  thread with the pre-close version yields 412, not the intended 409.
- `worker-check.sh` runs every integration test at its final stage; a swarm
  worker should stop at the known early `check-pack.py` false positive, confirm
  it once, and run the individual policy stages plus a targeted `-Dtest=...`
  suite. The full gate and JaCoCo belong to the integrator on the exact SHA.
