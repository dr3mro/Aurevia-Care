## Lessons for workers

- When a clause is already implemented, write enabled tests that assert the model through the normal service entry point and name each negative after the exact refusal branch; Mockito's short-circuit rule means a "clinician and room" refusal needs two separate tests (the first false answer prevents the second check from running).
- Keep the clause note's `## Status` value exactly one of the three allowed strings; put scope qualifications and tracked follow-ups in `## Evidence` / `## Gap`, and record test counts after any test rename or addition.
- Confirm `opencode.json` staleness is the CI-profile `skip-worktree` artifact once (`git ls-files -v`, `git show HEAD:opencode.json`), then run the remaining gate stages individually instead of editing or regenerating the protected file.
- `mvn -Pno-security,fast test` gives a fast whole-suite regression signal without the forbidden full `mvn verify`; SpotBugs must be run after `compile` to avoid a vacuously green result.
