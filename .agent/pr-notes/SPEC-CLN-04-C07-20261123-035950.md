## Lessons for workers

- When a clause is implemented at domain level but has no HTTP controller, prove the domain rule green and
  record the missing reachability in the clause document's `## Gap`: an added `@Disabled` fails
  `check-constraints.py`, while "Proven by tests" overstates what a domain-only test can show.
- In a cloud worker, `worker-check.sh` and `python-coverage.sh` stop on the OPS-CW-003-01 CI-profile
  artifact. Confirm `git ls-files -v opencode.json` is `S`, run every remaining stage individually, and
  never regenerate or commit `opencode.json`.
- To prove a frozen dictionary snapshot, pick a template family that actually has a CODE field; an empty
  snapshot assertion cannot fail and proves nothing.
