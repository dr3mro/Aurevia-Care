- An evidence note for a signed human decision is `Not built` even when decision drafts and code hooks exist; check the pack's status line and blank approval record, not merely whether the file exists.

- Keep `## Findings` and `## Review verdicts` in the notes file only — a clause evidence note must contain exactly its five required headings.
