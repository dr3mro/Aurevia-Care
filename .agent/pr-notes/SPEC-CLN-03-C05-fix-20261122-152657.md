## Lessons for workers

- When a fix pass inherits a merge that is already at HEAD, prove it with
  `git merge-base --is-ancestor origin/main HEAD` and `git diff --name-status
  origin/main..HEAD`, then verify the previously failing gates; do not redo the
  merge or rewrite the inherited files.
- Never run `scripts/frontend-check.sh` concurrently with `apps/staff-web/check.sh`:
  both run `npm ci` and can wipe `node_modules` under the other run, producing a
  misleading `eslint: not found`.
- If a Vitest coverage run is interrupted, kill the whole orphan tree via `/proc`
  and delete `/tmp/vitest-coverage-*.lock` before retrying; otherwise every later
  run fails with a lock message naming the dead pid.
- Do not run `scripts/check.sh` in a swarm worker — it calls full `mvn verify` and
  times out. Run targeted `-Dtest=...` suites plus the individual policy scripts
  and leave the full gate to the integrator.
