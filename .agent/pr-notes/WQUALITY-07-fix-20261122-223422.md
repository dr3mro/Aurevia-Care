## Lessons for workers

- Never cite `TODO.md` line numbers in a durable document. `TODO.md` is a regenerated view; name the task and quote its exact sentence instead, so a later merge cannot turn a correct citation into a wrong one.
- For a documentation accuracy fix, write one deterministic verifier that asserts both the absence of the stale pattern (including bare `:14922`-style references) and the presence of the durable replacement in both files. Removing the pattern alone makes the "no stale pattern" assertion pass vacuously and is not a red → green proof.
- A GitHub verification runbook that ticks a box, writes "verified" or fills a result cell defeats its own purpose. Keep the header, boxes, table and Approval in the "nothing verified" state until a person runs it on GitHub.
- `scripts/check-docs.py` applies its structural rules to `docs/operations/` as well as most of the tree; run it after every edit to that directory.
