## Lessons for workers

- For a `clinical.templates` evidence test under FORCE RLS, bind `TenantContext` and wrap every `JdbcTemplateStore` call in the guarded `TransactionTemplate`; a direct store call without the transaction reads nothing even with `TenantContext.set(...)`.
- `FieldValue` is persisted as a record (`fieldKey`/`value`/`language`), so assert parsed JSON rather than a flat `"lmp":"…"` substring.
