## Findings

- **Brief conflict resolved.** The story text asks for
  `it.skip("GAP: ...")`, but AGENTS.md Coverage rules 2 and 8 and
  `scripts/quality-gate.sh` reject added `.skip`/`xit`. The GAP is therefore an
  active tripwire that is green today and fails when the missing evidence
  arrives. No skip, exclusion, suppression or lowered threshold was added.
- **Brief imprecision.** The brief says all seven journeys have the EN/AR + axe
  gate. In fact only reception, lab-bilingual and clinical-note call the shared
  gate; order, radiology, pharmacy and print have EN/AR/RTL but no axe call. The
  note and the tripwire state this honestly.
- **Brief imprecision.** `E2E_BASE_URL` is injectable, but the journeys mount
  dev-only harnesses with in-browser API interception, so "against staging" is
  not proven; the note records this as a gap.
- **Plan review Required finding fixed.** The first GAP tripwire filtered the
  spec set by the seven known names, so adding a journey would not trip it. It
  now pins the full nine-file e2e spec set. Optional findings were also applied:
  broader visual-check predicate, typed-tripwire comment, and corrected
  harness-provider wording.
- **Context source.** Findings are from executed tool commands, file reads and
  read-only specialist reviewers; no simulated user or human participant was
  involved. No clinical or staging evidence is claimed.
- OWASP/SpotBugs are not applicable: no dependency or production code is in this
  change, so there is nothing new for those gates to scan.

## Lessons for workers

- For a spec-evidence story, inspect the committed artifacts and assert their
  real state; a test that pins a file's existing content is honest evidence only
  when the note says plainly that no browser or staging run happened.
- A GAP tripwire must pin the whole artifact set, not a filtered subset of known
  names, or adding the missing artifact will not trip it.
- A jsdom-only assertion about painted state proves structure, not pixels; leave
  light/dark visual comparison to a real-browser task with screenshot assertions.
- `tsc --noEmit` prints nothing on success, so record the `npm run typecheck`
  command line separately in Test evidence.
