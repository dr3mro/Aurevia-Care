## Lessons for workers

- From `tests/spec/localization/` the source prefix is `../../../src/...`, not
  `../../src/...`; a type-only import must use `import type`, and a symbol used
  only in `typeof` must also be a type-only import to satisfy
  `@typescript-eslint/consistent-type-imports`.
- A test-only story with no production change has no red phase: write the spec
  tests against the existing exports, and use `expectTypeOf` to make an absence
  claim falsifiable by typecheck rather than relying on `Object.keys` of a
  literal the test itself constructed.
- Before adding a skipped gap test, check `scripts/check-constraints.py`: added
  skip literals fail the gate, so prefer an active characterization plus a doc
  entry, and say explicitly that the test must be replaced later.
