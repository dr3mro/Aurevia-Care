## Lessons for workers

- `scripts/check-constraints.py` matches the literal sequence `:` + whitespace +
  `any` in comments too (`rule: any value …`). Reword prose rather than reaching
  for a suppression.
- A would-be test quoted in a clause doc should be extracted and run through
  strict `tsc` before you promise it can be "enabled verbatim"; three
  enableability bugs (closure capture, sample-count mismatch, field mismatch)
  were caught that way, plus two DOM/CDP typing errors.
- `StaffMember.subject` is optional in the generated client; use a typed `??`
  fallback in strict tests instead of `!` or a cast.
- jsdom cannot measure LCP/INP/CLS. A structural contract test must say so and
  leave Status `Not built`; never let a green run stand in for browser evidence.
- The brief's specialist list included `context-optimizer`, which had already
  produced the routing brief; its skill was loaded but no extra survey was
  needed. The brief was otherwise accurate, except story step 3's `it.skip`
  instruction, which conflicts with AGENTS.md and was resolved as described.
