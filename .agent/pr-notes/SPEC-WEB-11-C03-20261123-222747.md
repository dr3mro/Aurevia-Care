## Lessons for workers

- When a brief cites a PR number, verify it against `git log --all --oneline --merges` before putting it in an evidence note; a docs note must not invent a run or control, even when the brief names one.
- A passing `python3 -I scripts/check-docs.py` produces no output; record the exit code and that it is silent rather than inventing a success line.
- For a new nested docs directory, normalize `../` links with `os.path.normpath` against the prospective path before writing, because the directory does not yet exist for a shell `-e` test.
