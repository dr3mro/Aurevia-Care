## Lessons for workers

- When adding a page under `docs/reference/modules/`, check `contracts/openapi.yaml` as well as `contracts/openapi/generated/openapi.yaml`: the generated file is command-only and can make real GET routes look absent from the contract.
- Before writing a module guide, read the authoritative role allow-list (`ActionPolicy`) and the maintainer guide trace, not only the domain service and its unit tests; the reviewer required both as citations.
- On this branch `check-docs.py` has a large pre-existing red baseline. Capture a before/after diff and a scoped check of the new file so a clean change is provable even though the repository-level command still exits 1.
