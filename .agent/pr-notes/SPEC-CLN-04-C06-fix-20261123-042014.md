## Lessons for workers

- On a "did not finish cleanly" fix attempt, verify the committed work is actually broken
  before rewriting it: re-run the focused test and the individual gate stages. Green work
  usually means the prior session ended early or used a non-fix notes filename.
- Write the hand-off at the exact `-fix-<timestamp>` path from the prompt; the first
  worker's differently-named file is not a substitute for the named deliverable.
- `scripts/check-constraints.py` rejects every newly added Java `@Disabled` with no GAP
  exemption. When a story mandates a skipped test for unbuilt behavior, record the complete
  test verbatim in an exempt Markdown note and say why the literal instruction was not
  followed; a skipped test fails the quality gate.
- Dictionary keys pass through `VersionStore.KEY` (2-32 lowercase chars/digits/underscore)
  before `ConfigurationService.validateKey` (3-64); a long descriptive key fails with 422.
  `Approval.approver` in the HTTP body is a `user_identity` UUID, not the synthetic subject.
