## Lessons for workers

- Before deleting a test-scoped SQL migration, grep Markdown for links to its path: `check-docs.py` fails on broken links and spec-clause notes link to evidence files. If the note is out of scope, neutralize the file to a comment-only pointer instead of deleting it, and remove it from every Flyway location.
- In a cloud worker, treat `check-pack.py`/`test_check_pack` "stale opencode.json" failures as the CI-profile/skip-worktree artifact. Verify with `git ls-files -v opencode.json` and a clean HEAD worktree, then run the downstream gates individually — do not edit the protected config.
- When asserting RLS concealment, seed a row in the owner tenant in the same session before counting as the foreign tenant; otherwise `count = 0` passes vacuously on an empty table.
