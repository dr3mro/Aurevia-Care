## Decisions and deviations

- **Cursor format**: canonical `Instant.toString()` of `created_at` plus the immutable row `id`, mirroring the approved READY-16/17 list pattern. A non-canonical or unparseable instant is rejected with `INVALID_CURSOR`. Ordering is `(created_at DESC, id DESC)` so paging is stable when two rows share a creation instant (exercised by the integration fixture).
- **Error codes**: the story fixes `INVALID_LIMIT` and `INVALID_CURSOR`. It names `status` but does not fix a code; chose `INVALID_STATUS` (consistent with the sibling order list). A malformed `patientId` reuses the existing `FinanceInputs.uuid(patientId, "patientId")`, so its stable code is `INVALID_PATIENTID`.
- **List rows carry no history**: `InvoicePage` items are `FinanceContract.View` as required, constructed with empty item and ledger lists on list reads. The single-record read `get` keeps ownership of the immutable trails, so neither its response shape nor behavior changed and a page stays bounded.
- **Authorization**: reused `FinanceActions.READ` and the existing `finance` / `tenant_admin` / `privacy_auditor` roles exactly as the single-record read; no new role or action key.
- **RLS**: repository relies on forced row-level security for tenant isolation (no manual organization predicate), with parameterised SQL only and real V45 column names.
- **Scope deviation (documented, as in READY-16/17)**: the story's explicit steps require an `it/` integration test (step 6) and contract regeneration (step 7). Those files are outside the literal `scope` prefixes: `apps/api/src/test/java/com/aurevia/smartclinic/it/finance/InvoiceListIntegrationTest.java` and `apps/staff-web/src/api/generated/openapi.d.ts`. The generated d.ts was produced with the pinned generator (never hand-edited) because the full gate enforces `gen:api:check`; `contracts/openapi/generated/openapi.yaml` (catalog-generated X-04 artifacts) is unchanged by a GET route, so `contracts/openapi/check.py` stays green. No tracker, workflow, POM, migration or dependency file was touched.
