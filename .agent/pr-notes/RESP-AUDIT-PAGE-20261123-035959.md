## Lessons for workers

- An evidence-quality reviewer will reject a test name that claims more than its assertions prove. When a test says "isolated Arabic runs", assert the `<bdi dir="auto" lang>` hook (§13 R11) in the same test, or rename the test; do not leave the claim implicit.
- `MixedScriptText` renders foreign values as `<bdi dir="auto" lang="en">`; `screen.getByText(value).closest('bdi')` is the cheap deterministic jsdom signal for mixed-script isolation. Do not claim painted bidi ordering from it.
- jsdom assesses hiding only through DOM attributes (`[hidden]`, inline `display`/`visibility`). Say "no inline hiding style" rather than "stays in the accessibility tree" unless axe/Playwright backs the latter.
- `responsive.css` has wrapping rules for `.app-shell > *`, `.cluster > *`, `.stack > *`, `.grid-2 > *`, `.card-list > *` but **not** `.page > *`; there is no dedicated `.audit-filters`/`.audit-events` class. Wrap children in `stack`/`cluster`/`grid-2` rather than editing the stylesheet (out of scope). Record the missing `.page > *` rule for a stylesheet story.
- `Form` switches its inner container to two columns only above six fields; the audit form has five, so the page-level `grid-2` wrapper is what delivers stacking on phones and two columns from 768 px. Nested `page` classes from `Form`/`ApiPage` are expected in this module.
- Reuse the `matchMedia` stub pattern from `tests/components/ApiPage.responsive.test.tsx`: one state object per query with `addEventListener`/`removeEventListener`, and `act(() => media.fire(query, true))` to cross a breakpoint deterministically.
- In a Vitest jsdom module, `import.meta.url` is not a `file:` URL; use `dirname(fileURLToPath(import.meta.url))` with `join` to read the stylesheet text.
- `tsc --noEmit` prints nothing on success, so paste the `npm run typecheck` final line separately; Vitest green alone is not the frontend definition of done.
