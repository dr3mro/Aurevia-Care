## Lessons for workers

- Check whether a task's exact scope paths already exist on an earlier branch before writing:
  `git log --all -- <path>` and `git show <commit>:<path>` turn "start over" into "reconcile".
  Choosing a prior version still needs proof on the current HEAD (production diff + green test).
- "Prove only this clause" is literal: a printable-channel test belongs to C02, not to clause 1,
  even when the word "attestation" appears in both. One named test per guard makes the
  `## Coverage` table trivial and stops bundled cases from masking a branch.
- `IfMatch.parse` distinguishes missing (428 `PRECONDITION_REQUIRED`) from malformed
  (422 `INVALID_IF_MATCH`); verify status codes in source before copying a prose brief.
- A mocked `RxRepository` returns empty `Optional`s by default: a happy-path attest test must
  stub `find(ID)` to the attested row or the request ends in a 500 instead of the asserted 200.
- `git diff` is blind to skip-worktree files: confirm the opencode.json artifact with
  `git ls-files -v` and a byte compare of `git show HEAD:opencode.json`; never regenerate it.
