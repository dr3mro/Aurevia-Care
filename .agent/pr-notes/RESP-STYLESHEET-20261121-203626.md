## Findings

- **Wiring is a separate task (reviewer HIGH, downgraded to follow-up).** `responsive.css` is referenced only by its own test; no `src/**` import and no `<link>` in `index.html`, so nothing is live yet. `RESP-MAIN` explicitly owns `import './theme/responsive.css'` in `src/main.tsx` and depends on this task. Out of this task's two-file scope; no wiring change was made.
- **Inline stylesheet in `index.html` conflicts when wiring lands (reviewer MEDIUM).** `index.html:12-21` still sets `:focus-visible { outline: 3px solid #ffbf47 }` and `.skip-link { left: -9999px } / .skip-link:focus { left: 8px; top: 8px }`. Under `dir="rtl"` those physical insets coexist with the new logical `inset-inline-start`, so a skip link could stretch across the viewport. Token contract §8.1 note 2 requires removing the amber ring literal. `index.html` is outside this scope; the `RESP-MAIN` / `RESP-SHELL` worker should delete that inline `<style>` block when the import is added.
- ADR-0004 is still `Proposed` and `PROJECT_V1_SPEC.md` WEB-07 still states the old 1280/768 floors. Code follows the decision as the story instructed; the owner amendment remains pending.
- The `useTheme must be used inside ThemeProvider` stack traces in the check output come from the pre-existing `tests/theme/ThemeProvider.test.tsx` negative path; they are logged errors from passing tests, not a regression.

## Lessons for workers

- A test placed under `tests/<area>/` is one directory deeper than a test at `tests/` root: resolve the module root with `resolve(here, '..', '..')`, not `resolve(here, '..')`, or `readFileSync` silently returns empty text.
- Guard a file-as-text gzip/size assertion with `expect(css.length).toBeGreaterThan(0)`; otherwise gzipping an empty (missing) file passes and the red phase is not red.
- When checking CSS token fallbacks, parse to the matching closing parenthesis and split on the first top-level comma: a regex like `([^)]+)` truncates `cubic-bezier(0.2, 0, 0.2, 1)`.
- Assert every `var(--sc-…, …)` pair against the contract light values rather than a sample; a sample lets a wrong colour or motion fallback through.
- Logical-property checks should cover block-axis sides and one-sided radii too, and should not exempt the skip link: a skip link can be hidden with `inset-inline-start` just as well as with `left`.
- Record an unconsumed stylesheet as a stylesheet check, not as painted-layout or runtime evidence; the import story owns the entry-point assertion.
