## Lessons for workers

- For a proof-only clause test, make refusals assert both the typed error instance (`toBeInstanceOf`) and the observable side effect (`fetchImpl` not called for a missing credential; called once with the scoped URL for a server refusal). A `toMatchObject({ name, kind })` check alone is weak because `name` is mutable.
- With `verbatimModuleSyntax`, a `jest.fn(async () => …)` mock has a zero-argument call tuple; give its parameters types (`(_url: string, _init: RequestInit)`) before indexing `mock.calls[0][0]` or `tsc` fails with TS2493.
- A swarm worker's "two new files" scope check must also account for the mandatory `.agent/pr-notes/<task-id>-<timestamp>.md` notes file; it is the PR description and its absence fails the quality gate.
