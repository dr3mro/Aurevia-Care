## Lessons for workers

- Copying a neighbouring integration test is not enough: derive the datasource URL from one constant and reuse it in the `@SpringBootTest` property, Flyway, seed, cleanup and pool. A separate side pool with `maximumPoolSize=1` proves manual `set_config` semantics, but only the application's own pool with `spring.datasource.hikari.maximum-pool-size=1` proves the guarded transaction manager leaves a reused connection clean — assert the same `pg_backend_pid()` after a real service transaction.
- To make a foreign-tenant read observably empty, seed a facility code that exists in only one organization; a shared `MAIN` code would return the reading tenant's own row and prove nothing.
