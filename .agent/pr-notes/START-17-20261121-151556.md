# START-17 — Docs: testing guide (every check, what it proves, how to run it)

## Summary

Added `docs/reference/testing-guide.md`: one table covering every check found in the
six named scripts and the files they call (name/owner, command, what it proves, how
long it takes, what a failure usually means, first thing to try), followed by a short
"which checks run where" section (developer machine, worker, pull request run,
integrator). Every fact is taken from a script and cites it by name. No script, config,
index or production code was changed.

## Affected requirements

- OPS-06 — the guide catalogues the synthetic-data, secret/PHI, migration-safety,
  dependency/static-security, coverage and image-smoke checks and where each runs.
- WEB-09 — the guide records the staff-web and patient-mobile check entry points and
  their 100% coverage/typecheck gates.

Acceptance mapping:
1. Read the six scripts and the files they call → done (check.sh, worker-check.sh,
   quick-check.sh, apps/{api,staff-web,patient-mobile}/check.sh, plus their callees:
   frontend-check.sh, db/check.sh, check-{pack,docs,secrets,names,wiring,migrations}.py,
   project-name.py, worker_gate.py, coverage-check.sh, frontend-typecheck-check.sh,
   integrator-gate.sh, repair-gate.sh, verify.sh, smoke-image.sh, docs.sh, the two
   module package.json/vite/jest configs and .github/workflows/delivery.yml).
2. Write the guide with the table and the where-it-runs section → done.
3. Facts from scripts, cite the script; change no script → done.
4. Do not edit docs/reference/index.md → respected (START-18 owns that line).
5. Run `python3 -I scripts/check-docs.py` and paste result → done, exit 0 (below).
6. Stop and write "Why this is not finished" if something is missing → nothing missing.

## Lessons for workers

- When documenting the checks, take every fact from the owning script and name it in
  the text; do not infer behavior or timings that no script states.
- A single docs task must not edit `docs/reference/index.md` — START-18 links every
  new page, so two tasks never touch the same index line.
- `check-docs.py` skips `.agent/` and `docs/archive/`, so notes files are not link-checked;
  keep real links in shipped docs valid instead.
