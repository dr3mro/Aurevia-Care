## Implementation summary
Self-contained feature module. Reuses `InterfaceHealth` from `partnerboard/domain` (precedent: `orderentry` imports `CodedEntry` from `chart/domain`), `useTheme`, and Latin-digit `Intl` formatting via a local `numberText`. The route self-registers through `import.meta.glob('../features/*/routes.ts')`, so no shared registry file was touched. All data is synthetic (`fixtures.ts`); no patient data, credentials or real identifiers. The overdue state is always carried by a word; colour is only an additional cue (WCAG 1.4.1).

## Findings
- Pre-existing, out-of-scope gate defect: `apps/staff-web/check.sh` step 1 `npm run gen:api:check` fails because the committed `contracts/openapi.yaml` contains printing-handout paths (`/api/v1/printing/handouts`, `/api/v1/printing/handouts/download`) that are absent from the committed `src/api/generated/openapi.d.ts`. Verified by generating to `/tmp/openapi-generated.d.ts` and diffing; `git diff HEAD` shows **no local changes** to either file, so this is committed-state drift unrelated to LABFLOW-09 (likely a concurrent contract change). Fixing it requires regenerating a file outside this story's scope, so it was not touched. Integrator: regenerate `src/api/generated/openapi.d.ts` from `contracts/openapi.yaml` in the owning contract/API change; this will unblock `check.sh` for every staff-web worker.
- The `useTheme must be used inside ThemeProvider` stack trace in the coverage log is expected console noise from the existing `tests/theme/ThemeProvider.test.tsx` negative test; that test file passed.

## Lessons for workers
- A staff-web feature can self-register its route via `features/*/routes.ts` and `import.meta.glob`; no shared route registry or navigation file needs editing for a contained board.
- Keep feature message bundles named `<feature>Messages.ts`, not `messages.ts`: the repo-wide parity registry discovers that exact name and cannot be edited from a feature scope. Enforce parity with a local test.
- Before claiming `check.sh` green, run `gen:api:check` first — contract/generated-type drift from a parallel worker can make the whole gate red for reasons unrelated to your change. Confirm with `git diff HEAD -- contracts/openapi.yaml apps/staff-web/src/api/generated/openapi.d.ts`.
