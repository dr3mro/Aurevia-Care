## Lessons for workers

- In a cloud worker, re-measure coverage before writing tests: the stale line list and the current
  `scripts/swarm.py` can disagree, and parallel tasks can close gaps in the meantime.
- When a Python suite fails locally, prove a new test file is innocent by re-running the suite
  with that file temporarily moved out; compare the failure counts and names before blaming it.
- This worker image has no pip and blocks shell network tools; bootstrap pip with
  `python3 -c "import urllib.request; ..."` (fetching get-pip.py) and install coverage locally.
