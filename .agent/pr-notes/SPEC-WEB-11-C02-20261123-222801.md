## Lessons for workers

- For evidence notes, a deterministic negative search is the test-first artifact: `grep` on `.github/workflows` returning no matches is the gap, and a positive control on the same workflow proves the search is not vacuous. Never invent a workflow run, digest or signer to make an evidence note look complete.
- A passing synthetic fixture check is not proof of the production control it models. Quote the gate's own "What this does not prove" section next to the pass line, and apply rule 3 to keep the status honest when the real evidence is human/cloud-owned.
- Re-read every cited line before writing a line number into a citation. The first review caught three line/content mismatches that `check-docs.py` cannot detect — it validates links and IDs, not factual claims.
- `check-docs.py` validates relative links from the note's directory; a planned but absent directory makes `..` resolution fail during local verification. Create the in-scope directory before checking link targets.
