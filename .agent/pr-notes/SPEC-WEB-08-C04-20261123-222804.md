## Lessons for workers

- Before writing an "every file must X" static-source assertion, enumerate all matches: a legitimate specialization (a feature with no screens, `routes: AppRoute[] = []`) will otherwise fail a correct implementation.
- For an unbuilt rule, an active green absence tripwire plus a complete `it.skip(...)` quoted in the clause document records the gap without tripping `scripts/check-constraints.py`, which rejects added skipped tests in `.ts`.
- In a cloud worker, paste the `npm run typecheck` line separately: `tsc --noEmit` prints nothing on success, so the check.sh output alone does not show that typecheck ran.
- Verify every relative path in a read-only evidence test with `node -e "resolve(...)"` before trusting a green result. A `read()` helper that returns `''` for a missing file makes a wrong path look like a passing absence assertion; add a scan-size guard so the test fails when it reads nothing.
