## Lessons for workers

- Verify every Arabic term in a bilingual document by machine against the actual bundles (`rglob('messages.ts')` plus `components/stateViewMessages.ts`) before calling it done. Plausible-looking forms like `الموظفون` and `الموعد` are not necessarily the strings the interface uses — only `الموظفين` and `المواعيد` appear in these files.
- When citing a DB table as a code name, confirm it with `grep 'CREATE TABLE' db/migrations/*.sql`; an intuitive name such as `chart_record` does not exist (the chart tables are `chart_association` and `clinical_note_revision`).
- "Copied verbatim" means the whole quoted bundle value, not a plausible prefix. Check with `("'" + term + "'") in message_blob`, which catches truncated forms such as «التكوين» (real value «التكوين والكتالوجات») and «تجربة جافة» (real value «تجربة جافة (لم يتغيّر أي بيانات)»).
- A code name must be an actual class or table, not a TypeScript type alias (`AuditOutcome`), a TS function (`dobReasonKey`), a Java package (`patient.consolidation`), a coded value (`not_known`), a DB function (`audit_verify_chain`) or a cross-domain near-match (`DryRunReport` for consolidation). Confirm each against the source file.
