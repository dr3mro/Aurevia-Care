## Lessons for workers

- For a scheduling HTTP integration test, pick UTC slots that stay inside the seeded local
  availability window across DST. For `09:00-12:00 America/New_York`, 15:00Z is 10:00 EST and
  11:00 EDT, so it is safe in both seasons; 13:00Z silently fails in winter.
- JDBC does not accept `TIMESTAMPTZ ?`; write `CAST(? AS timestamptz)` for bound instants.
- After a cancel moves the version to 2, a reschedule must send `If-Match: "2"`; using `"1"`
  only proves the stale-version guard, not the terminal-state guard.
- When the task forbids all-integration commands, do not start `check.sh`, `worker-check.sh` or
  `mvn verify`; run the targeted `-Dtest=...` test and the individual policy checks instead and
  say explicitly that the integrator owns the full gate.
