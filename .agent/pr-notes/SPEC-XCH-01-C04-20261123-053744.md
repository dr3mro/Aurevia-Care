## Lessons for workers

- In this cloud worker image `opencode.json` is the CI profile under `skip-worktree`. Confirm once
  with `git ls-files -v opencode.json` (`S`), record the failing command and final line, run the
  remaining gate stages individually and never regenerate or edit that protected file.
- A mocked-repository "API test" clause story must cite the real-PostgreSQL HTTP test as
  supplementary evidence and say explicitly that mocks do not prove RLS or HTTP reachability.
- Pre-arm the success path in negative role tests (stub the repository to succeed first). Without
  it a denial assertion can pass for the wrong reason, for example a 404 instead of a 403.
- Mirror private fixtures from neighbouring tests with receiver-specific values; do not try to
  import private helpers from another package.
