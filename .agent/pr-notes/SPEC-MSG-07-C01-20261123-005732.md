## Lessons for workers

- A bare `spotbugs:check` is vacuous in this repo: `spotbugs.skip` defaults to `true`. Always run `-Pno-security -Dspotbugs.skip=false -DskipTests compile spotbugs:check` and compile first.
- `MessagingGovernanceService.auditTrail` appends an `audit_read` fact *before* reading; the filtered read uses the filter as its `resource_id`, and the appended fact carries `unit_id = SYSTEM`. Scope audit-count assertions by `resource_id`/`outcome` and read counts with direct JDBC (`SET app.current_org`) instead of issuing two GETs, or the audit-of-read noise will make counts order-dependent.
- In MSG-07, 422 validation failures append no fact while 403 authorization denials append a DENIED fact. Assert the two behaviours separately; do not write a shared "every refusal appends a fact" assertion.
