## Findings

- Context Optimizer returned `VERDICT: NO-GO` advising "Partly proven" because raw
  reference-range bounds are not emitted on `ObservationView`, the capture route
  is baselined missing in `contracts/openapi/missing-routes.txt`, and the
  `LabResultService` revision ledger is in-memory. Those are real but separate,
  already-tracked stories (contract debt, XCH-07 range display, durable lab
  persistence) and are outside this task's scope and its clause-test style. The
  clause's observable behavior — all four kinds, unit, method, instrument,
  range-derived flags and server-derived verifier — is implemented and proven,
  so the honest in-scope status is "Proven by tests"; all three facts are recorded
  in the doc under Evidence, not hidden.
- Pre-existing, committed conflict markers (inside Javadoc comments) exist in
  `apps/api/src/main/java/com/aurevia/smartclinic/exchange/hl7/Hl7ParseException.java`,
  `Hl7Parser.java` and `Hl7Segment.java` at HEAD `f80b58b8` (from BUILD-37).
  `git merge --no-edit origin/main` reported "Already up to date"; these markers
  were not introduced by this work and are outside its scope, so they were left
  untouched. They do not break Java compilation but should be cleaned up by the
  owning story. Evidence source: tool (`git grep`, `git show`).
- The worktree `opencode.json` drift described under Test evidence is an
  environment artifact (OPS-CW-003-01), not a change defect.

## Lessons for workers

- In a cloud worker, `worker-check.sh` and the Python suite can fail solely on
  the skip-worktree CI `opencode.json`. Confirm once (`git ls-files -v`, compare
  HEAD to `gen.render`), record the failing command and final line, then run the
  remaining gate stages individually; never regenerate or edit that file from a
  story worker.
- A clause test should assert the observable behavior and record, rather than
  silently absorb, out-of-scope debt (contract parity, durable store). Keep the
  doc's Status consistent with a green test: "Partly proven" with no disabled
  test would be self-contradictory.
