## Lessons for workers

- Before writing a clause-test GAP, check `scripts/check-constraints.py`: a newly added `@Disabled` Java test fails the worker and integrator gates even when the task text asks for one. Preserve the complete intended method in the clause doc and request a follow-up task instead, and record the conflict explicitly.
- For a targeted PostgreSQL integration test in this worker image, set `AUREVIA_PG_ADMIN=postgres`; the default `user.name` role does not exist locally.
- When `worker-check.sh` stops on the skip-worktree `opencode.json` artifact, confirm once with `git ls-files -v`, then run its remaining stages individually and record each final line rather than re-diagnosing the artifact or editing the protected file.
