## Lessons for workers

- In a cloud worker, `check-pack` / `gen-opencode.py --check` judge the CI-profile
  `opencode.json` under `skip-worktree`. Confirm with `git ls-files -v` and
  `git show HEAD:opencode.json`, reconcile the worktree to HEAD if needed, and
  never edit or commit the protected file (MEMORY OPS-CW-003-01).
- Re-running a returned task first means re-verifying the committed code, not
  redoing it; read the prior notes and the commit diff before touching anything.
- Prove per-class 100% coverage with the targeted tagged test plus
  `mvn -Pno-security jacoco:report` and read `jacoco.xml`; do not run the
  ten-minute full verify as a worker.
- When an unrelated gate is red at HEAD, prove provenance with `git log -- <file>`
  and `git diff HEAD -- <file>`, record the exact fix location, and stay inside
  scope instead of silently fixing another worker's defect.
- `check-wiring.py` exit 0 with `is fixed` notes means stale baseline debt for
  the maintainer, not a failure; do not edit `scripts/` from a story task.
