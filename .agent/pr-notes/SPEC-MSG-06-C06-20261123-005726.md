## Lessons for workers

- Before writing a clause-GAP test, check `scripts/check-constraints.py` for a Java
  `@Disabled` rule: the story may mandate an annotation that the mechanical gate
  flags. Capture the senior developer's explicit exception verbatim and surface the
  conflict in notes instead of using a fully-qualified annotation to slip past the regex.
- A class-level `GAP` `@Disabled` keeps the "exactly one annotation" grant intact and
  makes Surefire report the tests as skipped (`tests=2 skipped=2`), which is honest
  evidence; do not claim a green runtime proof from a disabled class.
- The `fast` Maven profile sets `excludedGroups=integration`, so `-Pno-security,fast
  -Dgroups=integration` runs nothing. Use `-Pno-security -Dgroups=integration` and
  read the Surefire count.
- A bare `spotbugs:check` is vacuously green; run `-DskipTests compile spotbugs:check`.
